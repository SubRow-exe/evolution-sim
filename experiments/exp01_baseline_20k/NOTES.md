# Exp 01: ベースライン安定環境 20,000 tick (仕様書 Experiment 1)

- 日付: 2026-08-27
- seed: 42 / 既定Config / 再現: `python -m uv run python main.py --headless --ticks 20000 --seed 42`

## 目的

MVP実装の最初の検証。安定環境で個体群が成立し、適応度関数なしで自然選択が発生するかの確認。

## 結果

- 個体数: 100 → 725（資源律速の緩やかな成長。爆発も絶滅もなし）
- 出生 12,001 / 死亡 11,276（starvation 11,274・damage 2・predation 0）
- 世代: 最大29世代。系統: 100 → 81（19系統が自然絶滅）
- 実行速度: 約90–150 tick/s（個体数に依存して低下）

## 観察

1. **光利用能力に明確な方向性選択**: 平均 0.30 → 0.445（+48%）、終盤は加速傾向。
   この世界の主要エネルギー流入源が光であることへの適応。適応度関数なしで発生 → 設計原則の実証
2. 感覚範囲・繁殖投資・突然変異率がわずかに上昇。他の遺伝子は分散を広げながら漂流
   （選択圧のかかる形質だけが動く、進化として妥当な挙動）
3. 捕食死ゼロ: 初期値では攻撃力(0.05)が膜強度(0.5)を破れないため。
   捕食者の出現は未実現の創発余地として残っている
4. max_age = 20000（t=0から生存する個体あり）: 修復が損傷発生を上回る個体は
   捕食者不在の環境では実質不老になれる。仕様書§21「寿命克服」の初期観察

## 次の課題

- 100k tick超長期 + 複数seedで光利用上昇の再現性確認（Experiment 5相当）
- 環境の異質性（温度など）追加後に系統分化が起こるか
- 個体数増加時の実行速度（数千個体でのNumPy一括化検討）
