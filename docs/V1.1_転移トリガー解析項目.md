# V1.1 転移トリガー解析項目

更新: 2026-08-29

## 問い

なぜ、同じように小型・高光利用方向へ進化している複数系統のうち、ある1系統だけが急速に人口シェアを伸ばしてselective sweepへ入るのか。

## 有力仮説

繁殖に少し有利な組合せを獲得した系統が出生数を増やし、突然変異を試す回数そのものを増やすことで、さらに有利な変異を引きやすくなる正のフィードバックが存在する。

## 確認順序

転移tickを0とした相対時間で、少なくとも -5,000〜+2,000 tick を比較する。

### 1. 人口
- lineage population
- top lineage share

### 2. 繁殖
- lineage births / interval
- per-capita birth rate = lineage births / lineage population
- 世代更新速度

### 3. 形質
- body_size
- light_absorption
- reproduction_investment
- mutation_rate

### 4. 順序

確認したい因果順序:

```text
形質変化
→ 1個体あたり出生率上昇
→ lineage人口増加
→ 突然変異試行回数増加
→ 追加の有利変異
→ sweep
```

人口が増えた後で平均形質が変わっているだけなら、この仮説は弱くなる。

## 代表seed

- 早い転移: seed 20
- 典型: seed 4
- 遅い転移: seed 10〜12等から選定
- 非典型: seed 3
- 未転移/進行中: seed 19

## 終了条件

完全な因果証明は要求しない。

- 繁殖優位がsweepより先行するか
- その優位とbody_size/light_absorption等の変化が対応するか
- 複数seedで同じ順序が再現するか

を確認し、仮説を「支持 / 否定 / 不明」で記録すればV1.1終了条件を満たす。
