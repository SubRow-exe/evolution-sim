## 0. 総評

方向性は妥当。V1.4を「吸収の整合」で閉じ、V1.5を「異種刺激の比較可能化」だけに
限定し、Exp09を進化競争ではなく比較メカニズムの診断に絞る切り分けは、
1軸ずつという原則に合っている。

特に妥当と判断した点:

- `response(x,K) = x/(x+K)` という単調飽和型の第一近似
- **半飽和定数を実行時のfield最大値から再計算せずConfig固定にする** (仕様 §4)。
  環境を強くしたときに知覚まで自動で割り戻すと環境変化の効果を打ち消す、という
  理由づけは正しい
- 好み遺伝子をまだ追加せず、既存の `light_absorption` / `chemical_absorption` を
  反応性の第一近似として使う
- 単独sourceでの順位不変をテスト項目に入れている
- Phase 0 (決定論) → Phase A (人工arena) → Phase B (短時間混合) の順序
- 小型化を人工ペナルティで抑えない判断 (原則8に合致)

以下、**Exp09を回す前に決めておきたい点1件、テスト設計の穴2件、手順の整理1件**と
軽微な指摘。

## 1. 要検討 (最重要) — `chemical_stimulus_half` が「生物のいないvent」で校正されている

12.3 は無生物平衡 `(16/13)/0.10` である。しかし**実際に走っている世界のventは
その状態にない**。

Exp08 flux16 の実測 stock (世界合計中央値 26.4 / vent約52セル) は
**0.51 E/cell**、seed範囲で 0.19〜1.37。無生物平衡の約4%である。

| 状態 | stock [E/cell] | response |
|---|---:|---:|
| 無生物vent (校正点) | 12.3 | 0.500 |
| Exp08実測 中央値 | 0.51 | **0.040** |
| Exp08実測 範囲 | 0.19〜1.37 | 0.015〜0.100 |
| 光 最明部 / 暗部 (参考) | 1.2 / 0.36 | 0.500 / 0.231 |

**光はフローなので占有されても知覚値が下がらず、chemicalはstockなので占有された
瞬間に知覚が1桁落ちる。** この非対称が意図した設計かどうかを先に確定したい。

事前登録された診断表現型について、chemicalが選ばれるために必要な vent stock:

| 表現型 (light/chem) | 明部 L=1.2 | 中間 0.78 | 暗部 0.36 |
|---|---:|---:|---:|
| light specialist (2.0/0.3) | 到達不可 | 到達不可 | 到達不可 |
| chemical specialist (0.3/2.0) | **1.00** | 0.77 | 0.44 |
| generalist (1.0/1.0) | 12.30 | 8.00 | 3.69 |

(`chem_abs × s/(s+12.3) > light_abs × L/(L+1.2)` を s について解いた値)

- **chemical specialist の交差点 1.00 に対し実測 stock 中央値は 0.51**。
  明部では光へ引かれ、暗部 (交差点0.44) では chemical に留まる、という
  帯依存の挙動になる。実測範囲 0.19〜1.37 が交差点を跨ぐため、離脱→stock回復
  (時定数 ~10 tick) →再誘引という**チャタリング**も起こり得る
- **generalist は占有ventをほぼ選べない** (交差点 12.3 = 無生物平衡)。
  Exp09 §9 の期待「generalistは局所刺激条件に応じて選択が変わる」は、実質
  「ほぼ空のventに限り切り替わる」という意味になる

このままだと Phase B で vent滞在率が低く出たとき、**「設計どおり」なのか
「Kのスケールが合っていない」のかを区別できない**。

### 提案

1. Phase 0 に**上記の交差点テーブルを事前計算する項目を追加**する
   (算術なので事前登録の趣旨を壊さない)
2. その上で K を「無生物vent基準 (12.3)」のままにするか「占有時の実測stock基準」に
   するかを**Exp09の前に決める**。占有時基準にする場合、chemical specialist の
   交差点を 0.5 に置くなら `chemical_stimulus_half ≈ 6.2`、1.0 に置くなら
   現行の 12.3 がそのまま該当する
3. どちらを選んでも、Phase B の期待パターンを「vent滞在率が高い」ではなく
   **「交差点stockより上ではchemicalを選ぶ」という定量形で事前登録**する

## 2. 要検討 — 単独sourceの不変性は「順位一致」より強く検証できる

V1.5が light↔chemical の比較だけを変え、他刺激との比較にlegacy scoreを残すなら、
**light-only / chemical-only の世界では V1.5 は V1.4 とビット単位で一致するはず**。

`docs/Exp08_実験計画.md` の Phase A (光単独) / Phase B (chemical単独) の Config が
そのまま単独source世界なので、`tools/verify_vs_ref.py` を `v1.4-final` に対して
走らせれば「最良セルの順位が同じ」より遥かに強い検証になる。

**Exp09の停止条件へ「単独source Configで `v1.4-final` と完全一致」を追加することを
推奨**する。tie処理が単独sourceで誤って発火して乱数を消費するバグも同時に捕まる。

## 3. 要検討 — Phase A の表現型テストが片側しか検証していない

§1の表のとおり **light specialist (2.0/0.3) はどんな stock でも chemical を
選べない** (必要responseが1を超える)。したがって Exp09 §6 A4
「等価環境刺激ではlightを選ぶ」は、実装が「常にlightを返す」バグでも合格する。
A1 / A3 も同様に片側のみ。

**各表現型について「lightを選ぶ場合」と「chemicalを選ぶ場合」を1件ずつ**
入れることを推奨する。例えば light specialist なら光を 0.05 まで落とせば
交差点 stock ≈ 4.5 で切り替わるので、切替を確認できる。

## 4. 要検討 — `v1.4-final` と default変更の順序 / CI基準ref

現行手順 (`docs/V1.4_総括.md` §7 / `AGENTS.md`) は
「default反映 → test → `v1.4-final`保存 → V1.5実装」。

この順だと:

1. **`v1.4-final` に、V1.4のどの実験でも使われなかった default
   (`chem_vent_flux = 16`) が入る** (Exp08はPhase A/BともfluxをConfigで明示指定
   しているため、実測はどれもdefaultに依存していない)
2. `chem_vent_flux` の default 変更は `tools/golden.py` の CASES (default Config)
   の結果を変えるため `verify_vs_ref.py --ref 5aca88e` が落ちる。現行手順では
   **CI基準refを2回動かす**ことになる (default変更時 + V1.5実装時)

### 提案

**`v1.4-final` は現在のmain (Exp08を走らせたコード状態) で保存し、default変更を
V1.5境界の最初のコミットに含める。** CI基準refの移動は1回で済み、`v1.4-final` は
Exp08を正確に再現する。「V1.4保存前にV1.5行動則を混ぜない」という原則も守れる。

なお `tests/golden_state.json` は現在 `{}` (V1.4の指紋は未記録) なので、
手順4「旧fingerprintを履歴保存」に実体はない。必要な作業は
`.github/workflows/ci.yml` の `--ref` の張り替えだけである。

## 5. 軽微な指摘

1. **vent形状によるKのずれ**: 12.3は13セルventの前提。世界端で欠けたventは
   `16/9 = 1.78 E/tick/cell` → 平衡17.8 になり、同じKでも相対応答が変わる。
   仕様へ「典型13セルvent基準の固定値」と明記しておくと、Phase Bでvent間の
   滞在差が出たときに実装バグと誤認しない
2. **`stimulus_tie_eps` の与え方**: 大きすぎると弱刺激下 (両score≈0) がすべて
   tie判定になりrandom walkが支配する。相対許容差か十分小さい絶対値
   (1e-9程度) を推奨。V1.4も両score 0ならrandom walkなので、その場合に
   V1.4と同一挙動になる定義にする
3. **legacy scoreとの二重尺度**: 無次元比較で選んだ候補を corpse / predation と
   比べる際にlegacy score (`ability × raw値`) を使うと、chemicalは raw stock
   (無生物vent 12.3)、lightは raw 1.2 を持ち込むため、**同じ候補が比較相手によって
   約10倍違う尺度で評価される**。仕様 §6 で認識済みの限界だが、Phase Bに
   「Energy候補が corpse / predation に負けた回数」をsource別の観測項目として
   足しておくと、影響が出たときに気づける
4. **観測項目の追加は `stats.csv` のschema変更**: 選択回数・tie回数・random walk
   回数は列が増える。`_move_sum` と同様に観測専用 (RNG非消費・分岐に影響しない)
   であることをテストで固定する。既存summarizerは列名で読むので互換
5. **`light_stimulus_half = 1.2` は光の勾配を圧縮する** (明暗比 3.33倍 →
   応答比 2.17倍)。順位は保たれるので問題ないが、chemicalの応答が0.04付近である
   ことと合わせると、行動から見た世界は全体に平坦になる。明暗帯滞在率で追える
6. **chemicalが知覚・収支の両面で光より弱い状態になったことの明示**:
   `chem_uptake = 0.5` 据え置きにより chemical適応個体の吸収ceilingは
   0.862 E/tick (Exp08実測0.52)、光適応個体は明部で最大1.2 E/tick。そこへ §1 の
   知覚差が重なる。Exp09 (メカニズム診断) では問題ないが、**その次の
   「混合世界での長期進化」実験を組むときは、chemicalが二重に不利な初期条件から
   始まることを承知の上で条件設定する**必要がある
