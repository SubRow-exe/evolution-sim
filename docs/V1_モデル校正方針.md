# Ver.1 モデル校正方針

## 目的

Ver.1 の進化結果を「望む方向へ調整する」のではなく、現行世界がどの方向へ有利・不利に傾いているかを把握し、進化経路が数式や初期値によって不自然に塞がれていないか確認する。

## 基本原則

1. **多様性を増やすためだけの数値調整はしない**
2. **初期値と環境選択圧を分けて考える**
3. **能力値の微小変化が連続的に利益へつながるか確認する**
4. **閾値を超えないと利益がなく、途中段階がコストだけになる形質を検出する**
5. **能力を使うコストと、能力を保持するコストを区別する**
6. baselineの結果を残し、ルール変更後と比較できるようにする

## 初期値の校正

14遺伝子について初期値近傍の局所感度を測定する。

候補:
- -20%
- -10%
- baseline
- +10%
- +20%

観察する指標:
- Energy収支
- 生存率
- 平均 / 最大寿命
- 繁殖成功
- 資源獲得量
- 移動量
- Damage / repair
- 個体数
- 系統シェア

詳細は Issue #16。

## 特に疑うポイント

### 光利用
`light_absorption` は小幅上昇でもすぐ利益へ変換されるため、現在の安定した光環境では強い方向性選択を受けやすい。

### 捕食
初期 `predation_efficiency` では膜を破れない場合、能力が少し上昇しても利益がなく維持費だけ増える可能性がある。この場合「捕食が不利」ではなく「捕食へ至る進化経路が塞がれている」可能性を疑う。

### 移動
現在は実際に移動したときのEnergy・Damageコストはあるが、高い `movement_power` を保持すること自体の維持コストが弱い。そのため定着型が移動能力を失う選択圧が不足している可能性がある。詳細は Issue #17。

### body_size
小型化が維持費・繁殖条件・速度など複数経路で同時に有利になっていないか確認する。

## 環境側の考え方

初期値校正とは別に、現在の世界が安定した光を広く供給する比較的快適な環境であること自体が、小型・高光利用戦略を強くしている可能性がある。

将来の多様化は、能力値を均等に強くするのではなく、
- 空間的環境差
- 複数資源
- 温度・水分
- 資源変動
- 捕食圧
- 災害
などを通じて複数ニッチを作る方向を基本とする。

## 開発順序

1. 現行V1 baselineを固定したままExp03〜Exp07で解像度を上げる
2. 不自然な進化経路の断絶・二重有利・コスト欠落を特定する
3. 必要な箇所だけ生理・数式を修正する
4. その後、環境複雑化によって複数ニッチを作る

校正の目的は「全遺伝子を同じ強さにすること」ではなく、**進化可能な選択肢が不自然な実装都合で閉ざされていない世界にすること**である。
