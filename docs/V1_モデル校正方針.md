# Ver.1 モデル校正方針

更新: 2026-08-29

> 現在の具体的な実行順序は [次の実験計画.md](次の実験計画.md) を参照。
> V1.1の終了条件とVer.1.2への移行理由は [V1.1終了とVer1.2移行方針.md](V1.1終了とVer1.2移行方針.md) を参照。

## 目的

Ver.1 の進化結果を「望む方向へ調整する」のではなく、現行世界がどの方向へ有利・不利に傾いているかを把握し、
数式・初期値・環境条件による進化バイアスを理解する。

## 基本原則

1. **多様性を増やすためだけの数値調整はしない**
2. **初期値と環境選択圧を分けて考える**
3. 能力値の微小変化が連続的に利益へつながるか確認する
4. 閾値を超えないと利益がなく、途中段階がコストだけになる形質を疑う
5. 能力を使うコストと、能力を保持するコストを区別する
6. baselineの結果を残し、ルール変更後と比較可能にする
7. 全てを解明してから次へ進むのではなく、**次バージョンの設計判断に必要な解像度まで理解したら一区切りとする**

## Exp03までで分かったこと

### 小型・高光利用への方向性選択

現行V1.1では `body_size` が小さく、`light_absorption` が高い方向への強い選択圧がある。
これは一部seedだけの特殊現象ではなく、selective sweepが起きていないseedでも高光利用化が進む。

したがって、

- **生態型としての小型・高光利用への収斂**
- **単一祖先系統が人口の大半を占めるselective sweep（転移）**

は分けて扱う。

### selective sweep

Exp03では40,000 tickまでに13/20 seedが主判定 `top_lineage_frac >= 0.5` に到達した。
一方、未転移seedも高光利用方向へ進んでいたため、sweepには光利用方向の選択圧だけでは説明できない追加要因がある可能性が高い。

現在の有力仮説は、繁殖優位が突然変異の試行回数を増やし、その優位を自己強化する正のフィードバックである。
詳細は Issue #18。

## 14遺伝子局所感度解析（Issue #16）の扱い

14遺伝子 × ±10/20% の全面局所感度解析は有用だが、**Ver.1.1終了の必須条件から外す**。

理由:

- Exp03で現行世界の主要な方向性選択は十分に見えてきた
- 全面解析はrun数が多く、次の世界更新を大きく遅らせる
- Ver.1.2で新しい環境軸を入れた後、必要な遺伝子だけ局所感度を測る方が判断に直結する場合がある

Issue #16はBacklogとして残し、必要に応じて再開する。

## 特に疑うポイント

### 光利用

`light_absorption` は小幅上昇でも資源競争上の利益へ直接変換されるため、安定した光環境では強い方向性選択を受けやすい。
V1.1ではこの性質を「不具合」として抑制しない。

### body_size

小型化は、

- 維持コスト
- 繁殖に必要なmatter
- 同じ総物質で成立可能な個体数

など複数経路で有利になる可能性がある。
Exp04と転移トリガー解析で優先的に確認する。

### 捕食

初期 `predation_efficiency` では利益へ至るまでの進化経路が塞がれている可能性がある。
ただしV1.1終了前の必須解析とはせず、Ver.1.2以降の世界で必要に応じて再検討する。

### 移動

能力を保持するコストと実際に使うコストの分離不足は Issue #17 に残す。

## 環境側の考え方

V1.1は安定した光を広く供給する単純な世界であり、小型・高光利用戦略が強いこと自体は合理的である。

次のVer.1.2では、生物能力を均等化するのではなく、世界側の情報量を少し増やす。

候補:
- 時間的な光変動
- 温度場
- 資源の空間偏在/時間変動

**一度に1つの環境軸だけ追加し、V1.1との差を観察する。**

詳細: [Ver1.2_環境更新候補.md](Ver1.2_環境更新候補.md)

## 開発順序

```text
Exp03 完了
→ Exp04
→ 転移トリガー解析 (#18)
→ V1.1解析終了
→ Ver.1.2環境更新 (#19)
→ V1.1との比較
```

校正の目的は「全遺伝子を同じ強さにすること」ではない。
**どのルールがどの進化圧を作っているかを理解し、その上で世界を少しずつ豊かにすること**である。
