# 観察記録: 約40,000 tickでの個体急増

## 概要

Ver.1.1 MVPを約40,000 tickまで実行したところ、途中から個体数が急激に増加する現象を確認した。別seedでも約25,000 tick以降に類似傾向が見られており、単発の乱数イベントだけではなく、現行モデルに共通する進化的傾向の可能性がある。

## 観察された主な変化

個体急増と同時期に、以下の遺伝子・集団特性の変化が観察された。

- body_size: 小型化方向
- light_absorption: 上昇、一部個体は上限5付近
- sensory_range: 上昇
- reproduction_investment: 低下
- mutation_rate: 上昇
- 個体数: 数百規模から数千規模へ急増

一方でMatter cycleのTOTAL (conserved)はほぼ一定であり、個体数急増は物質が不正に生成された結果ではない。無機栄養が生体量へ移動し、同じ有限物質量がより多数の小型個体へ分割された可能性が高い。

## 現時点の仮説

### 1. 小型・高光利用・高繁殖回転戦略

現行モデルではbody_sizeが小さくなると、成熟に必要なMatterが減少し、維持コストも低下する。さらにreproduction_investmentが低い場合、親は一度の繁殖で失うEnergyを抑え、短い間隔で再繁殖できる。

このため、以下の組み合わせが強い可能性がある。

- 小さい身体
- 高いlight_absorption
- 低いreproduction_investment
- 高い増殖回転

これは現実の微生物的な戦略にも似るが、現行の繁殖条件がbody_sizeに強く依存しているため、モデル上の抜け道になっていないか検証が必要。

### 2. mutation_rateの上昇

mutation_rate自体が直接有利とは限らない。高mutation_rate系統から有利なlight_absorption等が出現し、その系統が無性生殖で増えることで、高mutation_rateも一緒に集団中で増える「ヒッチハイク」の可能性がある。

ただし高mutation_rateは不利な突然変異も増やすため、長期的には低下へ転じる可能性もある。長期・複数seedで確認する。

## 空間分布について

初期観察では、北側で光利用型が優勢、南側で死骸分解型が増えるという想定通りの傾向が見られた。一方、個体急増後は光利用型が南側にも多数広がり、世界中を移動する様子が見られた。

これは現行ルール上、必ずしも異常ではない。

理由候補:

1. 南側にもlight_floor=0.3により光が存在するため、高light_absorption系統なら生存可能。
2. 北側で人口密度が上がると、セル内の光を多数個体で分配するため1個体あたり取得量が減る。南側は光量が少なくても競争が弱ければ成立し得る。
3. 出生位置は親周辺のランダム方向であり、世代を重ねると分布が空間的に拡散する。
4. 現行behaviorは「実際に得られる光の取り分」ではなく「環境の光フラックス」を刺激として評価しているため、個体が認識する価値と実際の収益が一致していない。

したがって、南下が生態的な適応なのか、行動ルールによる漂流なのかを今後切り分ける必要がある。

## 次の検証

同一seedで以下のアブレーションを個別に実施する。

- body_size固定
- reproduction_investment固定
- mutation_rate固定
- light_absorption固定
- 災害なし

一度に複数条件を変更せず、個体急増の主要因を特定する。

また、空間分布を可視化するため、最新スナップショットから以下を出力する。

- 個体位置scatter
- RGB = 捕食 / 光利用 / 死骸分解
- 緯度(y)ごとの平均light_absorption
- 緯度(y)ごとの平均corpse_digestion
- 緯度(y)ごとの平均predation_efficiency

これにより「北は光利用、南は分解」という空間的ニッチ分化と、急増後の分布変化を定量的に確認する。

# 追記: 資源利用率の実測 (2026-08-27)

改善方針 Ver.1.2 §5 の資源利用率ログを実装し、初期状態での資源の余裕を実測した。

## 実測値 (seed 9, tick 800, 個体数 251)

| 項目 | 値 |
|---|---|
| 光: 供給累計 | 998,400 |
| 光: 利用累計 | 91,725 (**利用率 9.2%**) |
| 総物質 (保存量) | 3,280 |
| うち生体量 | 293 (**8.9%**) |
| うち無機栄養 | 2,981 (90.9%) |

**エネルギー・物質のどちらも約90%が未利用**であった。

## 個体急増の解釈

現行の世界の物質収容力は、平均身体量から逆算できる。

```
理論上限個体数 = 総物質 / 個体あたり平均身体量
```

| 平均身体量 | 理論上限個体数 |
|---|---|
| 現状 (1.17) | 約 2,800 |
| ×0.5 | 約 5,600 |
| ×0.25 | 約 11,200 |
| body_size下限 0.2 相当 | 約 14,000 |

初期個体数は100であるのに対し、収容力は数千規模である。
したがって**25k〜40k tickでの「急増」は、物質が不正生成された結果でも計算の破綻でもなく、
初期個体数が収容力を大きく下回っていた集団が、収容力へ向かってロジスティック的に増加した過程**
として説明できる可能性が高い(Matter cycleのTOTALが一定であることとも整合する)。

小型化は個体あたり物質量を下げるため収容力そのものを引き上げるが、
`body_size` の下限0.2により上限は約14,000個体で頭打ちになり、無限には発散しない。

## この解釈に対する留保

上記はあくまで**収容力の上限計算であり、急増の主要因を確定するものではない**。
以下は依然として未検証である。

1. 小型化が実際に主要因か (§3のアブレーション実験が必要)
2. 小型個体の維持コストは `s^0.75` により単位質量あたりでは増加するが、
   繁殖閾値が `body_size` に比例するため、小型化が繁殖回転を速める効果と釣り合っているか
3. 約14,000個体という上限が `body_size` のhard clamp (§8) に依存している点
   — この上限は生理的な必然ではなく人為的な設定値である

## 実装した安全装置

個体数が `max_population_halt` (既定20,000) に達した場合、自動保存して停止する。
**個体を殺す処理ではなく**、世界のルールには一切干渉しない。
計算が事実上停止する状態を避けつつ、個体数抑制を生態ルールへ持ち込まないための措置である。
