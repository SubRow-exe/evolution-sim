# 1. 今回ここで固定する判断

## 1.1 agentの意味

V1.9検証版では:

```text
1 agent = 1 cell
```

を維持する。

`cells_per_agent` / super-agent / clone cohort は導入しない。
理由:

- mutation / lineage / drift / innovation probability の意味を変えない
- V1.9の目的はまず生理・Energy仮説の検証であり、H2枯渇競争を無理に作ることではない
- Opus 5が指摘した「H2消費が供給より小さい」は重要な観測として残すが、Exp15の合否条件から資源枯渇競争を外す

将来、cell densityやbiofilm/colonyを扱う版で representative-agent 法を独立検討する。

## 1.2 Exp15で要求する環境圧

V1.9/Exp15では、H2競争ではなく以下を主要圧とする。

```text
H2-rich region
<->
H2-poor / net-Energy-negative region
```

個体が移動により正負のEnergy収支領域を経験することで:

- storage_capacity
- starvation_horizon
- reproduction_horizon

へ選択圧が生じるかを検証する。

H2 biological depletionは明示的に計算・記録するが、depletionが大きいことをExp15成功条件にはしない。

# 2. 時間スケール

正本:

```text
physical time unit = second [s]
biology dt          = 10 s
```

Config上は `/tick` を科学的意味として使わない。
step indexは内部実装として保持可。

```text
light_cycle_period_seconds = 86400   # 24 h
light_day_fraction         = 0.5
memory_tau_seconds         = 20
```

EMAは必ず:

```text
alpha = 1 - exp(-dt_seconds / memory_tau_seconds)
```

でstepごとに求める。

遺伝子:

```text
starvation_horizon_seconds
  initial = 1800 s
  range   = 60 .. 86400 s

reproduction_horizon_seconds
  initial = 3600 s
  range   = 300 .. 43200 s
```

既存gene名を互換のため保持する場合でも、意味・Recorder単位はsecondsとする。

# 5. H2 environment

## 5.1 field semantics

```text
world.h2 = dissolved H2 concentration [mol/m^3]
1 mM = 1 mol/m^3
```

H2 amountは:

```text
n_H2 = C_H2 * voxel_volume
```

で換算し、source / uptake / loss ledgerはmolで閉じる。

## 5.2 source

4 source、固定位置、非重複、edgeから十分内側。
検証版では source disk を拡げず **1 source = 1 grid cell** とする。

resolved-field source濃度:

```text
h2_source_concentration = 1.0 mol/m^3 = 1 mM
```

これは10 mM級vent fluidそのものではなく、0.5 mm gridで未解像のnear-field mixing後のsource-cell referenceと位置づける。

source cellは外部reservoirとのDirichlet boundaryとして扱う。
各H2 substepでsource cellを1 mMへ復元し、復元に必要だったmol量を `h2_source_in_cum` へ加える。
これにより外部流入を厳密に台帳化する。

## 5.3 diffusion / environmental exchange

```text
D_H2 = 5.0e-9 m^2/s
h2_exchange_tau_seconds = 900 s
```

exchangeは未解像のadvection/mixingによるbackgroundへの流出をcoarse-grainした一次sink:

```text
dC/dt |_exchange = -C / tau
```

これは化学分解ではない。

H2 diffusionはbiology dtと分離してsubcycleする。

```text
alpha = D_H2 * dt_sub / dx^2
alpha <= 0.20
```

を満たすよう自動で `n_sub = ceil(D*dt/(0.20*dx^2))` とし、`dt_sub=dt/n_sub`。
将来dtを変更してもCFL違反を起こさない。

boundaryはreflectingとする。

# 6. H2 uptake

Opus 5レビューの指摘を反映し、「600 µMをKとする」扱いはしない。

reference kinetics:

```text
q_max = 50 mmol H2 / (gDW h)
k_first_order = 19.36 L / (gDW h)
```

この2つを滑らかにつなぐMichaelis-Menten型を使う。

```text
K_m = q_max / k_first_order
    = 2.5826 mmol/L
    = 2.5826 mol/m^3

q_H2(C) = q_max * C / (K_m + C)
```

`chemical_absorption=1.0` はこのreference uptake能力のdimensionless multiplier。

個体uptake demand:

```text
J_H2 [mol/s]
 = q_H2(C) [mol/(kgDW s)]
 * current_dry_mass [kgDW]
 * chemical_absorption
 * uptake_factor
```

同一voxel内の総需要がavailable H2を超える場合のみfair-shareする。
実際に取得したmolをfieldから差し引く。

# 7. H2 -> usable Energy

reference:

```text
4 H2 + 2 CO2 -> acetate + 2 H2O
ATP gain = 0.3 mol ATP / mol acetate
ATP/H2   = 0.075 mol/mol
ATP free-energy reference = 50 kJ/mol
```

したがって:

```text
usable_energy_per_mol_H2 = 3750 J/mol
```

Energy state / ledgerの正本単位をJへ変更する。

```text
Energy gain = actual_H2_uptake_mol * 3750 J/mol
```

旧 `h2_energy_yield=1` / `h2_conversion_eff=0.60` はphysical baselineでは使用しない。

# 8. basal maintenance

reference coefficient:

```text
maintenance_ATP = 0.116 mmol ATP/(gDW h)
ATP energy      = 50 kJ/mol
```

reference phenotype/body_size=1のbasal powerは約:

```text
0.45 fW/cell
```

となる。

重要: 文献maintenanceを基準にしたtotal basalへ、旧organ/sense/membrane等をそのまま全加算しない。

検証版ではreference phenotypeで総basalが上記値になるよう、以下のnormalized decompositionを使う。

```text
core       0.60
organ      0.12
sense      0.08
membrane   0.10
resistance 0.05
storage    0.05
sum        1.00
```

各componentはreference genomeで重み1になるよう正規化し、geneがreferenceから変化した分だけ相対costを変える。
これによりreferenceで二重計上せず、形質costのtrade-offは残す。

`storage_capacity=1.0` のreference Energy capacityは:

```text
E_max_ref = reference basal power * 12 h
```

とし、

```text
E_max = E_max_ref * storage_capacity * (matter/body_size reference scaling)
```

を使う。
12 hは最終生物学定数ではなく、検証版のstorage scale reference。

# 9. growth / Matter assimilation

biomass synthesis Energy reference:

```text
Y_ATP = 10 gDW / mol ATP
ATP energy = 50 kJ/mol
```

したがって:

```text
growth_energy_cost = 5.0e6 J/kgDW
```

1 matter unit (0.28 pgDW)を新規合成するEnergy costは約1.4 nJ。

nutrient fieldはV1.9では「biomass precursor equivalent mass」とし、Energy源とはしない。

reference uptake capacityはEnergy側が律速になるよう:

```text
max precursor assimilation at nutrient-rich condition
= 0.20 matter unit/h * nutrient_absorption
```

初期 `nutrient_absorption=0.5` なら0.10 matter/h。
実際のMatter増加は:

```text
min(local precursor availability,
    physiological uptake capacity,
    available Energy / growth_energy_cost)
```

で決める。
Matterを増やした分だけgrowth Energyを必ず支払う。

初期nutrient amountは旧 `2 matter unit/voxel` を暫定維持し、総Matter台帳を閉じる。

# 10. movement

LUCAの速度を確定値とはしない。検証referenceとしてmoderate motile prokaryote級を置く。

```text
speed_coef_reference = 40 µm/s
baseline movement_power=0.5 -> vmax約20 µm/s
wander_speed_frac=0.6       -> baseline wander約12 µm/s
```

movement operational powerはStokes dragを基礎にmotor効率を含める。

```text
r = equivalent cell radius from volume/matter
P_mech = 6*pi*eta*r*v^2
eta_motor = 0.10
P_move = P_mech / eta_motor
```

水粘度:

```text
eta = 1.0e-3 Pa s
```

flagellar construction等の恒常コストはbasal側へ含まれるとみなし、別加算しない。
