# 3. V1.9 — chemical-first祖先からphototrophyを創発させる

## 3.1 問題意識

現在の `INITIAL_GENOME` は:

```text
light_absorption = 0.3
chemical_absorption = 0.3
```

で、祖先が最初から両方を利用できる。

LUCA-inspiredなmainstreamとしては、初期個体をchemical利用側へ置き、光を**未利用ニッチ**として世界に存在させる方が面白い。

## 3.2 重要な生物史の整理

「シアノバクテリアを取り込んで光合成生物になった」という話は、主に**真核生物のplastid（葉緑体）起源**である。

光合成・phototrophy自体はそれ以前の細菌ですでに成立していた。

したがってV1.9でchloroplastやcyanobacteria classを追加する必要はない。

参考:
- McFadden 2014, Origin and Evolution of Plastids and Photosynthesis in Eukaryotes
  https://pmc.ncbi.nlm.nih.gov/articles/PMC3970417/
- Keeling系統のplastid/endosymbiosis reviewとして、primary plastidはcyanobacterial endosymbiosisに由来するという整理を採用する

## 3.3 V1.9 provisional implementation

候補:

```text
INITIAL_GENOME.light_absorption: 0.3 -> 0.0
INITIAL_GENOME.chemical_absorption: 0.3 維持
```

重要: 現在のmutationには加算変異項があるため、親が `light_absorption=0` でも子で正値が再出現可能。

つまり新しい「photosynthesis unlocked=True」のような完成能力を追加せず:

```text
chemical-first ancestor
        ↓
mutation
        ↓
微弱なlight利用能力
        ↓
未利用lightからEnergy取得
        ↓
成立すればselectionで増大
```

という経路を現行遺伝機構だけで作れる可能性がある。

## 3.4 Exp14 provisional question

> chemical-first祖先から、未利用light nicheへ進出するphototrophic lineageは自然発生・定着するか？

見るもの:
- first positive light_absorption mutation
- actual light Energy flowを初めて得た個体/lineage
- establishment probability
- waiting time
- sweepか共存か
- phototrophのspatial range
- chemical依存が残るか
- replicate seed間の独立出現

「phototroph」は解析上の生態型名でありclassではない。

V1.9の詳細はV1.8/Exp13終了後に確定する。

# 4. V1.10候補 — Energy source自体を時間的に生きた環境へ

V1.8の昼夜は周期的だが、chemical sourceは永久に同じventから出続ける。

次の候補は:

- ventの有限寿命
- 新vent誕生
- vent fluxの増減
- spatial resource patch turnover
- day length変動

など。

狙い:

ただしV1.9のphototrophy創発とどちらを先にするかはExp13/14結果で再判断可能。

# 5. 原始的遺伝子交換 — HGT mainstream

単細胞・原核生物段階で重要な次の大機構としてhorizontal gene transferを候補にする。

完成したsexual reproductionは突然追加しない。

段階:

```text
HGT-1 接触時のDNA断片交換
HGT-2 組換え
HGT-3 二親性繁殖へ接続
```

特にV1.9で新しいEnergy利用能力が成立した後なら:

> metabolic innovationが系統内だけで継承される世界
vs
> HGTで別系統へ広がる世界

を比較できる。

観測:
- adaptation speed
- mutator hitchhiking
- selective sweep
- ecotype diversity
- metabolic trait spread

# 6. endosymbiosisへの長期経路

plastidを最初から器官として追加しない。

必要な前段階を順に作る。

## Stage E1 — phototrophic bacteria相当の生態型

V1.9で、独立生活するlight利用型が成立する。

## Stage E2 — engulfment / 捕食の拡張

現在のpredationは獲物からEnergy/Matterを取り出すだけ。

将来:
- engulfment
- 消化成功/失敗
- 一時的に生きたまま内部保持

などのmechanismを検討する。

## Stage E3 — facultative intracellular symbiosis

内部に残った相手が:
- hostから保護/資源を得る
- hostへEnergyや代謝産物を渡す

なら、双方に利益がある条件で共生が維持される可能性を作る。

この段階でも「chloroplast」とは呼ばず、生きたsymbiont。

## Stage E4 — obligate symbiosis / organelle-like integration

長期的に:
- symbiont単独生存能力低下
- host依存
- gene loss / host control

などを導入できる段階になって初めてplastid-like organelleを議論する。

primary plastidがcyanobacterial endosymbiosisに由来するという現実史はこの段階の参照になる。

# 7. oxygenic photosynthesis / 大気改変は別の大転換

現在の `light_absorption` はgeneric phototrophyであり、酸素発生型光合成を意味しない。

将来phototrophyが安定した後に:

```text
non-oxygenic phototrophy
        ↓
oxygenic photosynthesis innovation
        ↓
O2 environmental field
        ↓
酸化ストレス / 新しい代謝机会
        ↓
planet-scale ecological transition
```

というmainstream候補を置く。

これはGreat Oxidation Eventの再現を直接指定するものではなく、生命活動が環境を変え、その環境が生命へfeedbackする機構を作るもの。

# 8. 生態型・収斂進化の記録は並行インフラ

mainstream世界ルールとは別に、Seedを跨いだecotype分類は早めに整備したい。

理由:
- V1.9でphototrophが複数seedに独立出現したか判定

- endosymbiosis前駆体の反復出現確認

これは観測/解析であり適応度へ戻さない。

結果不変機能として適切なpatch versionで追加可能。

# 10. Ver.2への境界

Ver.1系は原則として単細胞/微生物世界。
