# 1. 長期目標

完成した生物種を設計者が直接追加せず:

```text
環境物理 + 化学 + 基礎生理 + 遺伝 + 変異 + 個体間相互作用
```

から、生命史に似た大転換が創発可能な世界を段階的に作る。

最終的には水中適応だけでなく、陸上進出・歩行・飛翔まで到達可能な進化空間を目指す。

地球史そのものの再演をfitness目標にはしない。

現実から借りる優先順位:

```text
構造・因果 > scaling > 比率/order > 絶対値 > 細部の歴史再現
```

---

# 2. LUCA fidelityの位置づけ

V1.9以降、iLUCAは今後のoriginとしてLUCA-likeな生理へ寄せる。

ただし:

> **完璧な歴史上のLUCA再現はmainstreamの完了条件ではない。**

LUCAらしさを上げる実装は、現在の結果を支配する欠落、次の進化圧に必要な生理、明らかな非生物学的挙動の修正を優先する。

分子詳細を全部実装するまで次へ進まない、という運用は禁止する。

Abiogenesis -> LUCAは別trackとして維持し、mainstreamをblockしない。

```text
 -> V1.3 chemical地質source + stock
 -> V1.4 表面積律速・公平吸収

 -> V1.8 light/chemical一次Energy非対称化 + day/night

```

V1.9では旧abstract chemicalをH2 substrateへ置き換え、物理time/space/Energyへ接続し、LUCA-like acetogen proxyとmaintenance-first growth allocationを導入した。

Exp15 Attempt 2ではfixed iLUCAが生存・成長・世代交代可能と確認。
Exp16ではH2濃度・拡散・loss・配置による自然な成立/不成立域を確認した。

# 4. 現在 — V1.9 Origin Lock

残作業:

```text
Exp15 Phase B
 -> storage_capacity / starvation_horizon / reproduction_horizon evolution

Origin Audit
 -> movement/chemotaxis, H2 uptake, maintenance, growth等の粗い感度

mutation / innovation audit
 -> phototrophy前の進化scale確認
```

これらが説明可能ならV1.9をcloseする。

LUCAのtemperature / explicit CO2 / pH / chemiosmosis /膜分子詳細までV1.9へ押し込まない。

# 5. 近未来 mainstream

V1.9後の優先候補:

```text
Phase 1  generic non-oxygenic phototrophyの創発
Phase 2  temperature / reaction kinetics
Phase 3  explicit carbon / Matter coupling
Phase 4  pH / ion gradient / chemiosmosis + membrane
Phase 5  dynamic hydrothermal environment / flow / vent turnover
Phase 6  microbial ecology / HGT / competition / predation
Phase 7  oxygenic innovation / O2 / redox feedback
```

各phaseは原則:

```text
mechanism
 -> fixed sanity
 -> evolution ON
 -> 最小interaction
 -> close
```

で進める。

精密なglobal optimumは通常探さない。

---

# 6. Phototrophy mainstream

V1.9でPHOTOTROPHY capabilityはstructural innovation gateとして準備済み。

次段階では:

```text
H2 chemical-first iLUCA
 -> generic non-oxygenic phototrophy innovation
 -> H2 / light / mixed strategy differentiation
```

を最優先候補とする。

V1.8 day/nightはphototrophy出現後に初めて主要Energy圧になる。

cyanobacteriaやchloroplastを直接追加しない。

---

# 7. Complexity mainstream

複数代謝・環境feedbackが成立した後:

```text
engulfment
 -> intracellular symbiosis
 -> organelle-like integration
 -> cell adhesion / multicellularity
 -> explicit morphology / body parts
```

へ進む候補とする。

この段階では通常のVer.1系より大きなdata model再設計が必要になる可能性が高い。

---

# 8. Land / Flight mainstream

形態モデル確立後:

```text
水中形態・運動
 -> depth / pressure / buoyancy / gravity
 -> water-land boundary / desiccation
 -> terrestrial support / locomotion
 -> walking
 -> aerodynamic morphology / flight
```

へ接続する。

歩行・飛翔をfitnessとして直接要求しない。

---

# 9. Parallel Abiogenesis Track

**DEFERRED / NOT ABANDONED**。

```text
prebiotic chemistry
 -> autocatalysis
 -> compartment/protocell
 -> heredity
 -> metabolic coupling
 -> LUCA-compatible interface
```

を現在のOrganismより下位の別layerとして将来設計する。

このtrackの失敗や遅延でLUCA以降のmainstreamを止めない。

---

# 10. 恒久開発原則

各phase開始時に確認:

```text
1. 直前実験で何が分かったか
2. 次機構が本当に必要か
3. 生物側に応答レバーがあるか
4. より単純な自然則で表現できないか
5. 結果を直接誘導していないか
6. LUCA fidelityを目的化していないか
```

遠未来ほど仮説であり、順序は直前結果で変更する。
