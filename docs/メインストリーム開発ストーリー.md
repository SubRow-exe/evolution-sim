# 3. V1.9 — chemical-first祖先からphototrophy創発

## 3.1 問題意識

現在の祖先は:

```text
light_absorption=0.3
chemical_absorption=0.3
```

で最初から両Energy routeを使える。

LUCA-inspired mainstreamでは、chemical-first ancestorから未利用light nicheへの進出を自然発生させる方が面白い。

候補:

```text
INITIAL_GENOME.light_absorption: 0.3 -> 0.0
INITIAL_GENOME.chemical_absorption: 0.3 維持
```

現在のmutationには加算項があるため0から正値へ再出現可能。

```text
chemical-first
 -> mutationで微弱light利用
 -> actual light Energy取得
 -> 正のselectionなら増大
```

phototrophは解析上の生態型名でありclassではない。

## 3.2 生物史の整理

「シアノバクテリアを取り込んで光合成生物になった」は主に真核生物plastid起源の話。

phototrophy自体はそれ以前の細菌で成立していた。

したがってV1.9でcyanobacteria/chloroplast classを追加しない。

## 3.3 Opus 5レビューで追加された重要注意

機構的には`light_absorption=0`から立ち上がれるが、最初の微小変異の利益は維持費に対して非常に小さく、**drift支配で立ち上がりが極端に遅い可能性**がある。

したがってExp14事前登録前に:

- 0から有意なlight利用（例: maintenanceの1%相当）までの期待世代数
- expected waiting timeに対するtick budget
- population size依存

を決定論/軽量simulationで検算する。

到達しない場合にmutation scale等を変えるかは**結果前に別途人間判断**する。Exp14結果を見て同じ実験内で救済値を追加しない。

## 3.4 Exp14 provisional question

> chemical-first祖先から未利用light nicheへ進出するphototrophic lineageは自然発生・定着するか？

見るもの:
- first positive mutation
- first actual light Energy flow
- establishment probability
- waiting time
- sweep/coexistence
- spatial range
- chemical依存残存
- seed間独立出現

V1.9詳細はExp13後に確定する。

V1.8のlightは周期的だがchemical ventは永久固定。

V1.9とどちらを先にするかはExp13/14で再判断。

# 5. HGT mainstream

原核生物段階の大機構としてhorizontal gene transferを候補にする。

完成したsexual reproductionを突然追加しない。

段階候補:

```text
HGT-1 接触時DNA断片交換
HGT-2 組換え
HGT-3 二親性繁殖へ接続
```

Energy利用innovationが成立した後なら、HGT有無でtrait spread / diversity / sweepを比較できる。

# 6. endosymbiosisへの長期経路

## E1 独立phototroph

V1.9で独立生活light利用型が成立。

## E2 engulfment

現在のpredationを拡張し:
- engulfment
- digestion success/failure
- live internal retention

を検討。

## E3 facultative intracellular symbiosis

内部相手がhostから保護/資源を得てhostへEnergy/代謝産物を渡す関係。

## E4 obligate / organelle-like integration

- symbiont単独能力低下
- host依存
- gene loss / host control

まで進んで初めてplastid-like organelleを議論。

### 実装規模の注意

**E2以降はV1.7/1.8のような式変更とは質的に異なる。**

「個体が個体を内包する」データモデルが必要になり:
- organism list
- Matter/Energy ledger
- spatial hash
- death/predation/reproduction
- snapshot schema

すべてへ影響する。

着手前に独立したarchitecture/design phaseを置く。通常の小さなV1.x変更として軽く見積もらない。

# 7. oxygenic photosynthesis / planetary feedback

現在の`light_absorption`はgeneric phototrophyでありoxygenic photosynthesisを意味しない。

将来:

```text
non-oxygenic phototrophy
 -> oxygenic innovation
 -> O2 environmental field
 -> oxidative stress / new metabolism
 -> planetary ecological transition
```

を候補にする。

Great Oxidation Eventを直接再演させるのでなく、生命が環境を変え、その環境が生命へfeedbackするmechanismを作る。
