# 1. 長期目標

完成した生物種を設計者が直接追加せず:

```text
環境物理 + 化学 + 基礎生理 + 遺伝 + 変異 + 個体間相互作用
```

から、生命史に似た大転換が創発可能な世界を段階的に作る。

最終的には水中適応だけでなく、陸上進出・歩行・飛翔まで到達可能な進化空間を目指す。

地球史そのものの再演をfitness目標にはしない。

現実から借りる優先順位:

```text
構造・因果 > scaling > 比率/order > 絶対値
```

# 3. V1.9 — realistic chemical-first iLUCA baseline

V1.9は元々の「chemical-first祖先からphototrophy創発」を維持しつつ、その前提となるiLUCA自体を再設計する。

中心構造:

```text
chemical-first ancestor
+ homeostasis
+ operational Energy / reserve
+ evolvable storage strategy
+ evolvable reproduction threshold
+ substrate -> Energy conversion
+ zero-start innovation capable mutation
```

初期祖先:

```text
light_absorption = 0
predation_efficiency = 0
```

V1.8 day/nightは残すが、chemical-first祖先には直接Energy影響を与えない。

将来mutationでphototrophyが出現すると初めて:

```text
day -> additional light opportunity
night -> light opportunity disappears
```

となり、reserve、chemical併用、homeostasis、繁殖戦略等へ自然な選択圧が生じる。

V1.9正本: `docs/V1.9_iLUCA再設計仕様.md`

# 4. V1.9後の近未来

V1.9でbaseline生理が成立した後、環境因子は一つずつ追加する。

有力候補:

```text
temperature / reaction kinetics
explicit carbon / CO2 cycling
resource turnover / dynamic vents
pH
pressure/depth
toxins/radiation
oxygen
```

順序は実験結果と必要な生理レバーを見て決める。

特にtemperatureはLUCAを一律「好熱性」と決め打ちするためではなく、反応速度・維持・膜安定等に選択圧を作る環境軸として検討する。

# 5. HGT mainstream

原核生物段階でhorizontal gene transferを候補とする。

完成したsexual reproductionを突然追加せず:

```text
HGT-1 接触時DNA断片交換
HGT-2 組換え
HGT-3 より高度な遺伝交換へ
```

と段階化する。

Energy利用innovationが成立した後なら、HGTによるtrait spread・diversity維持を評価できる。

# 6. phototrophyからendosymbiosisへ

```text
chemical-first
 -> generic non-oxygenic phototrophy
 -> phototrophic ecotype
 -> engulfment
 -> facultative intracellular symbiosis
 -> obligate integration
 -> organelle-like state
```

phototrophy自体をcyanobacteria/chloroplast classとして直接追加しない。

engulfment以降は個体が個体を内包するdata modelが必要になり、通常の小さな式変更とは別規模のarchitecture phaseを置く。

---

# 7. oxygenic phototrophy / planetary feedback

現在の`light_absorption`はgeneric phototrophyであり、oxygenic photosynthesisを意味しない。

将来候補:

```text
non-oxygenic phototrophy
 -> oxygenic innovation
 -> O2 field
 -> oxidative stress / aerobic metabolism
 -> planetary feedback
```

Great Oxidation Eventを直接再演させるのではなく、生命が環境を変え、その環境が再び生命へselectionを返す構造を目指す。

---

# 8. morphology / multicellularity

Ver.1系は原則として単細胞・微生物世界。

以下はVer.2候補:

- explicit body parts
- shape / symmetry
- movement organs
- sensory organs
- mouths / digestive structures
- multicellularity
- differentiated tissues

この段階から水中運動→陸上支持→歩行→飛翔へ接続する。

---

# 9. 恒久開発原則

各version開始時に確認:

```text
1. 直前実験で何が分かったか
2. 次機構が本当に必要か
3. 生物側にその環境へ応答できるレバーがあるか
4. より単純な自然則で表現できないか
5. 結果を直接誘導していないか
```

fixed ancestor failureとevolution failureを混同しない。

環境を生存側へ曲げる前に、生理・遺伝的accessibilityを確認する。
