## 3. これらから分かったこと

Exp02〜03により、少なくとも以下を確認した。

- 個体急増の実体は一部seedで起こる単一祖先系統のselective sweep
- 小型・高光利用への方向性選択はsweepが起きないseedでも進む
- よって「高光利用型への収斂」と「単一系統の一掃」は別現象として扱うべき
- mutation_rate上昇は少なくともExp02ではヒッチハイクで説明できる
- 未利用光の利用増加を伴うため、単純な繁殖条件バグだけでは説明できない

## 5. Ver.1.2との関係

観測性強化そのものを次の生態世界の目的とはしない。
Ver.1.2では、V1.1の観測基盤を利用しながら、**世界側の環境情報量を少し増やす**。

第一候補は時間的な光変動。
次候補として温度場、資源の空間偏在/時間変動を検討する。

多様性を直接保護するルールは入れず、環境条件を変えた結果として進化経路がどう変わるかを見る。

## 6. 性能方針

性能問題は生態ルールを歪めて解決しない。

優先順:
1. 計測
2. profilerでボトルネック特定
3. アルゴリズム改善
4. Seed単位の並列
5. 必要ならNumba / Rust / C++等

極端な個体数で自動保存して停止する安全装置は許容するが、性能のために個体を自動削減しない。
