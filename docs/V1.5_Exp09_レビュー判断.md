## 1. 総評

Claude Codeのレビューについて、V1.5を「異種一次Energy刺激の比較可能化」に限定し、Exp09を進化競争ではなく比較メカニズムの診断にするという基本方針は妥当と判断する。

以下の採否を確定する。

## 2. `chemical_stimulus_half = 12.3` は維持する

Claude Codeは、12.3が生物不在ventの平衡stockを基準にしており、Exp08で生物が占有したventの実測stock（中央値約0.51 E/cell）に対してはchemical受容器応答が約0.04まで下がることを指摘した。

この指摘自体は正しい。

しかし、現時点では `chemical_stimulus_half` を占有時stockへ合わせて引き下げない。

理由:

- 光は毎tick供給されるflow型で、生物が利用しても次tickの知覚値は基本的に回復する
- chemicalは局所stock型で、生物が利用するとその場のstock自体が減る
- したがって、利用によりchemical刺激が弱くなり、離脱するとstockが回復して再誘引されるという負のフィードバックは、両Energy源の物理的な違いとして自然
- V1.5の目的は光とchemicalを「同じ強さに感じさせる」ことではなく、異なる単位の刺激を有限な共通尺度へ変換して比較可能にすること
- Exp09はこの比較則の診断であり、光とchemicalの進化的公平性を保証する実験ではない

したがってV1.5初期defaultは維持する。

```text
light_stimulus_half = 1.2
chemical_stimulus_half = 12.3
```

ただし12.3は**典型的な完全13セルventの生物不在平衡を基準にした固定値**であり、占有時stockへ自動再校正しないことを明記する。

## 3. Claude Code提案のうち採用するもの

### 3.1 Phase 0へ交差点計算を追加

各診断表現型について、光量を固定したときに、どのchemical stockを超えるとchemical側のresponse scoreがlight側を上回るかを事前計算する。

これによりPhase Bでvent滞在率やsource選択率が低くても、設計どおりの閾値挙動か実装不備かを切り分ける。

Phase Bの期待は単純な「vent滞在率が高い」ではなく、

> **その時点のchemical stockが理論交差点を上回ればchemicalを選び、下回ればlightを選ぶ**

という定量条件を優先する。

### 3.2 単独sourceではV1.4と完全一致を要求

V1.5で変更するのは light vs chemical の異種比較だけである。

したがってlight-only / chemical-only世界では、V1.4とtarget順位が同じだけでなく、同一Config・同一seedなら**決定的に完全一致**することを停止条件へ追加する。

`v1.4-final`を基準に`verify_vs_ref.py`等で確認する。

### 3.3 各診断表現型で両方向の切替を確認

「light specialistがlightを選ぶ」だけでは、常にlightを返すバグを排除できない。

Phase Aでは各表現型について、刺激条件を調整して少なくとも:

- lightを選ぶケース
- chemicalを選ぶケース

を1件ずつ作り、理論scoreの交差をまたいで選択が反転することを確認する。

専門型でも反対側を選び得る極端な刺激条件を人工arenaで用意してよい。これは生態結果を作るためではなく関数の両側をテストするための診断条件である。

### 3.4 tie判定を厳密化

`stimulus_tie_eps`は大きな固定幅にしない。

推奨初期値:

```text
stimulus_tie_eps = 1e-9
```

または同等に十分小さい相対許容差とする。

弱刺激領域が広範囲にtie扱いとなりrandom walkへ落ちることを防ぐ。

両scoreが0のときはV1.4と同じくEnergy源による方向付けを行わない。

### 3.5 観測項目を追加

Exp09では最低限、既存の行動選択回数に加えて:

- その時点のlight response score
- chemical response score
- 選択時のchemical stock
- 理論交差点の上/下で選択が一致した回数
- Energy候補がcorpse / predation等の既存刺激に負けた回数（light由来 / chemical由来を区別）

を観測可能にする。

観測追加はRNGを消費せず、個体状態や分岐へフィードバックしない。

## 4. `v1.4-final`保存順序は当初方針を維持する

Claude Codeは、`v1.4-final`をExp08実行時mainのまま保存し、`chem_vent_flux=8→16`のdefault変更をV1.5最初のcommitへ含める案を提示した。

これは**採用しない**。

V1.4のExp08はV1.4吸収則の校正実験であり、その結果として恒久defaultを:

```text
light_uptake_coef = 2.0
chem_vent_flux = 16.0
chem_uptake = 0.5
```

と人間判断で確定した。

したがって `v1.4-final` は、**Exp08による校正結果まで反映した完成版V1.4** とする。

順序:

1. V1.4恒久defaultをコードへ反映
2. 暫定表記を更新
3. test / Energy / Matter / RNG / CI確認
4. 必要なCI基準更新を行う
5. その状態を `v1.4-final` として保存
6. その後V1.5の行動ルールを実装
7. V1.5最初の意図的結果変更commitを新しい基準refへ設定

CI基準refを余分に更新する技術的手間より、世界バージョンの意味と最終defaultを一致させることを優先する。

Exp08自体の再現性は実行commitと実験Configで保持されるため、`v1.4-final`のdefaultが16でも失われない。

## 5. 追加で明記する限界

### vent形状

`chemical_stimulus_half=12.3`は完全13セルvent基準。世界端などでventが欠ければ、同じ総供給量でも1セルあたりsource密度が上がる。

これは実装バグではなく幾何による差として記録・観測する。

### legacy scoreとの二重尺度

V1.5はlight vs chemicalだけを無次元化する。

一次Energy候補をnutrient / corpse / predation等と比較する段階ではV1.4由来のlegacy scoreを維持するため、全刺激が完全な共通尺度になったわけではない。

この限界は認識した上で、Exp09では影響を観測する。必要なら後の世界バージョンで全刺激比較則を再設計する。

### chemicalの知覚・収支差

`chem_uptake=0.5`を維持し、さらにoccupancyでchemical stockが低下するため、標準混合世界ではchemicalが光より知覚・収支の両面で弱く見える条件が存在する。

Exp09ではこれを「不公平だから補正する」のではなく、事前式から予測できる結果として扱う。

長期混合進化実験では、この初期条件を認識した上で結果を解釈する。
