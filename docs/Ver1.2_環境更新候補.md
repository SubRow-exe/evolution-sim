# Ver.1.2 環境更新候補

更新: 2026-08-29

## 目的

Ver.1.1で確認された「安定した光環境では小型・高光利用型へ強く収斂する」という性質を保存した上で、Ver.1.2では**世界側の情報量・環境差を増やしたとき進化経路がどう変わるか**を観察する。

目的は「必ず多様化させること」ではない。

---

## 設計原則

1. 多様性を直接増やすボーナス/保護ルールを入れない
2. 抽象的な `environment_penalty` のような一律負荷は避ける
3. 光・温度・資源など意味のある環境量として表現する
4. 一度に多数の環境軸を変えず、因果を追えるようにする
5. V1.1 baselineモードは再現可能なまま残す
6. 資源量を「望む結果」に合わせて調整しない

---

# Stage 0: 実装前の資源構造監査

以前は「時間的な光変動」を最初の実装候補としていたが、実装の小ささだけで第一手を決めない。
まず**現在の世界がどの資源をどの規模・空間範囲で提供しているか**を整理する。

## 現行Configの公称構造

- world: 40 × 40 = 1,600セル
- 光:
  - 全セルへ毎tick供給
  - `light_max = 1.2`
  - `light_floor = 0.3`
  - vertical勾配の平均は約0.78 E/tick/cell
  - 世界全体の公称供給は約 **1,248 E/tick**
- 化学:
  - 4噴出口
  - 半径2セル
  - `chem_capacity = 50`, `chem_regen = 0.05`
  - 重複/端欠け無しなら理論最大回復は約 **32.5 E/tick**
- 無機栄養:
  - 2.0 M/cell
  - 初期プール **3,200 M**
  - 再生なし、閉鎖物質循環

光は供給量だけでなく**世界全域で利用可能**なのに対し、化学は局所的かつ供給規模が小さい。
この非対称性は、高光利用戦略が構造的に強い理由の一部である可能性が高い。

ただし、これだけで設定ミスとは断定しない。

## 監査項目

Exp03/Exp04データから:

- 光・化学の公称供給量
- 実際の吸収量
- 未利用量
- 資源ごとの空間的な利用可能面積
- nutrient総量と生体量の移行
- 時期ごとの律速資源
- `light_absorption`固定時にchemical/corpse等へ代替が起きるか

## 資源量見直しの判断

変更してよい理由:
- 単位・スケールの整合が取れていない
- 想定していなかった資源が桁違いに支配している
- ある資源経路が実装上ほぼ利用不能

変更しない理由:
- 「光利用型ばかりでつまらない」から
- 「多様性を増やしたい」から

**世界として何を表現したいかに対して不整合なら直す。結果を誘導するためには直さない。**

# 候補A: 空間的なエネルギーニッチの強化【現第一候補】

最初のVer.1.2更新として現時点で最も有力。

## 狙い

V1.1では最低光量でも最大の30%があり、世界のほぼどこでも光利用が成立する。
そこで光利用戦略そのものを弱体化するのではなく、**場所によって利用できるエネルギー戦略が異なる世界**にする。

例:

```text
明所             → 光利用が有利
薄暗い領域       → 高効率光利用・移動が重要
ほぼ無光領域     → 光だけでは成立困難
化学噴出口周辺   → 化学利用の機会
```

### 最小実装案

- 現行vertical光勾配を拡張し、0に近い暗部を含められるようにする
- 光と化学の総供給規模はStage 0監査を踏まえて決める
- まず新しい遺伝子は増やさない
- 既存の
  - `light_absorption`
  - `chemical_absorption`
  - `movement_power/efficiency`
  - `sensory_range`
  で分化が生じるかを見る

### 観察

- 空間別の遺伝子平均
- 光/化学エネルギー利用比
- 各系統の生息域
- selective sweep
- 複数系統の長期共存
- 同じ生態型が別seedでも独立出現するか

---

# 候補B: 時間的な光変動

実装規模は小さく、依然として価値が高い。

- 昼夜
- 周期的光量変化
- ゆっくりした日照変動

ただしこれは、多様性を作る第一手というより

> **高光利用型が時間変動環境でも頑健か**

を調べる実験として位置づける。

全世界が同じ昼夜を経験するだけなら、新しい最適戦略へ再び全系統が収斂する可能性があるため、空間ニッチより多様性生成力は低いと予想する。

---

# 候補C: 資源の空間偏在・変動

- 化学噴出口の位置・量・寿命
- nutrientの初期分布
- 資源パッチの生成/枯渇
- 世界全体の総量を変えず配置だけ変える比較

空間ニッチAと連続したテーマ。

特に、化学エネルギー経路が現状ほぼ弱すぎるなら、単純な増量より
**局所的には強いが世界全体では限定された資源**として設計するとニッチとして意味を持ちやすい。

---

# 候補D: 温度場

新しい環境負荷を追加する候補。

- 空間的温度分布
- 適温からのずれを代謝効率・損傷等へ接続
- 直接 `if temp > X: die` のような死亡ルールは避ける
- 初期は温度耐性遺伝子を増やさず既存生理との接続から始める

光分布と温度分布が一致しない世界にすれば、明るい場所が必ずしも最適ではなくなる。

ただし新しい物理量と生理式を追加するため、空間エネルギーニッチより実装・校正規模は大きい。

---

# 候補E: 複数無機栄養素

長期的には非常に有望。

例:

```text
Matter-A: 構造材料
Matter-B: 膜/触媒等の材料
```

ただし全生物がA:Bを同じ比率で必要とするだけでは、単に新しい律速資源が一つ増える可能性が高い。

本当にニッチ分化へつなげるなら将来的に:

- 遺伝的な必要比率
- 吸収能力のトレードオフ
- 構造/能力と資源要求の接続
- 空間的なA/B分布差

などが必要になる。

そのため**Ver.1.2の最初の小規模アップデートではなく、資源化学を本格化する段階**で導入する方針を基本とする。

---

# 推奨順序

```text
V1.1 Exp04完了
  ↓
Stage 0: 現行資源構造を監査
  ↓
A. 空間的エネルギーニッチ
  ↓
V1.1と少数seed比較
  ↓
結果に応じて
  ├─ B. 時間的光変動
  ├─ C. 資源偏在/変動
  └─ D. 温度場
  ↓
E. 複数無機栄養素（より本格的な拡張）
```

順序は固定ではない。Stage 0と最初の比較結果で再評価する。

---

# 比較指標

最低限:

- population
- births / deaths / death causes
- mean age
- body_size
- light_absorption / chemical_absorption
- top_lineage_frac / n_lineages
- resource flows
- total_biomass / nutrient_total
- spatial distribution

さらに「多様性」を見る場合も単一の系統数だけでなく、**異なる資源利用戦略が同時に存在するか**を重視する。
