# 3. Opus 5 M-2への判断

H2消費がsource供給より小さく、V1.9規模ではH2 depletion competitionが弱い可能性は認める。

ただし今回:

```text
cells_per_agent / super-agent
```

は導入しない。

理由はpopulation genetics / mutation / lineage semanticsを変えるため。
Exp15はH2 competitionではなく、**H2-rich / H2-poor空間を移動することで生じるEnergy heterogeneity**を主要選択圧として検証する。

H2 biological depletion fractionはreadoutとして必ず保存する。
