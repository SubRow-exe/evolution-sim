# 5. Exp16 — fixed-iLUCA environment robustness

**55/55 runs完了、workflow success。**

iLUCAを固定し、H2 concentration / exchange-loss timescale / diffusion / source geometryだけを変更した。

主要結果:

```text
H2 1 mM  -> 5/5 extinction
H2 3 mM  -> 5/5 extinction
H2 6 mM  -> 5/5 survive, median final N 386, generation 2
H2 10 mM -> 5/5 survive, median final N 2981, generation 5
H2 15 mM -> 5/5 survive, median final N 4876, generation 6

low diffusion  -> extinction
high diffusion -> high growth
fast H2 loss   -> extinction
slow H2 loss   -> all seeds hit N=5000 simulation cap

square layout  -> robust growth
cross layout   -> 10-day persistence but population contraction
cluster layout -> local reproduction followed by extinction
```

中心的解釈:

> **iLUCA成立性はsource peak濃度だけでなく、H2-rich領域の面積・連結性・遭遇可能性に強く支配される。**

`h2_exchange_tau_s` は供給速度ではなくexchange/lossによるH2除去時定数。small tauほどH2 haloが狭い。

baseline referenceは当面維持:

```text
H2 source = 10 mM
D = 5e-9 m2/s
exchange/loss tau = 900 s
4-source square
```

Exp16結果を使ってbaselineを最適化し直さない。

重要な未解決点:

- biological H2 uptake / source influxはbaselineで約5.6e-6で、生物によるH2 depletionがほぼ無い
- 現在の主要圧はresource competitionよりH2-rich patchへのaccess
- rich環境ではMatter/growth側の別律速が見え始める
- 10日runはcarrying capacity / steady stateの測定ではない

詳細: `docs/Exp16_V1.9_結果考察.md`
