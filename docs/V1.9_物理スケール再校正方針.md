# 1. 再校正へ移る理由

PR #67では、旧implementation referenceをそのまま使うと、fixed iLUCAがvent直上・単独・繁殖停止でも約100〜150 tickで餓死した。

これは単に `h2_uptake_coef` を上げればよいという問題ではない。

```text
H2 uptake = 0.24 E/tick
maintenance = 0.43 E/tick
```

のような比較では、`E` と `tick` が現実量へ接続されていないため、

- H2供給が少なすぎるのか
- uptake能力が低すぎるのか
- maintenanceが高すぎるのか
- 1 tickが長すぎるのか

を科学的に判定できない。

今後、温度・水圧・重力・酸素・pH・放射線・陸上移動・飛翔まで扱うには、ここでphysical scaling layerを導入する方が長期的に一貫する。

原則:

> **生存する値を探すのではなく、現実のオーダーから供給・取得・支出を置き、結果として収支がどうなるかを見る。**

# 2. 確定した時間スケール

正本時間単位:

```text
physical time unit = second [s]
dt_seconds         = 10 s   # standard numerical timestep
```

`tick`を生物学的単位として使わない。
コード内部でstep indexは残してよいが、Config・gene meaning・Recorderでは原則として秒/分/時間へ意味を持たせる。

## 2.1 day/night

```text
light_cycle_period_seconds = 86,400 s  # 24 h
light_day_fraction         = 0.5       # 12 h day / 12 h night
```

標準dt=10 sなら 8,640 step/cycle。

## 2.2 chemotaxis memory

V1.6の `memory_tau=10 tick` をそのまま換算しない。
V1.9 physical reference:

```text
memory_tau_seconds = 20 s
```

これはflagellar run/tumbleを秒単位で直接解く値ではなく、現在のcoarse-grained temporal biased random walkの有効記憶時間。

## 2.3 starvation horizon

```text
starvation_horizon initial = 1,800 s   # 30 min
range                      = 60 .. 86,400 s
```

将来phototrophyが出現した際、12 h nightへの適応余地を初めからrange外にしない。
個体は昼夜周期を知らず、現在Energyと現在full-activity支出からrunwayを計算するだけ。

## 2.4 reproduction horizon

```text
reproduction_horizon initial = 3,600 s  # 1 h
range                        = 300 .. 43,200 s
```

これは倍加時間そのものではない。Matter蓄積条件と併せて繁殖可能性を決めるEnergy安全余裕。

## 2.5 iLUCA reference generation time

資源豊富・非ストレス条件でのreferenceとして:

```text
expected doubling-time order = 4–8 h
reference                     ≈ 6 h
```

LUCAの実測値を主張するものではない。
H2+CO2で増殖する現存acetogen（A. woodii等）のオーダーを、physical sanityのアンカーとして使う。
A. woodiiではH2+CO2条件のspecific growth rate 0.112 h^-1（倍加時間約6.2 h）の報告がある。

# 3. H2を物理量へ置き換える

V1.9ではH2 fieldをarbitrary stockではなく、原則として溶存H2濃度として扱う。

推奨正本単位:

```text
H2 concentration = mol / m^3
H2 amount        = mol
H2 flux          = mol / s
H2 uptake        = mol / s / organism
```

1 mM = 1 mol/m^3。

## 3.1 vent H2 reference

Lost City hydrothermal fieldではvent fluid H2が約1–15 mMと報告されている。
V1.9 source-fluid reference:

```text
vent_source_H2_reference ≈ 10 mM = 10 mol/m^3
```

HARD RULE:

- ventセル濃度を常時10 mMへ固定しない
- source fluid / source fluxとmixing・diffusion・consumptionからlocal concentrationを形成する
- background oceanは低H2とする

実際の `mol/s/vent` は空間体積・source geometry確定後に算出する。

## 3.2 H2 diffusion

水中H2のmolecular diffusion coefficientは25°C付近で概ね:

```text
D_H2 ≈ 5e-9 m^2/s
```

をphysical referenceとする。
温度依存はtemperature導入versionで扱う。

重要:

> `dt=10 s` とexplicit Laplacianの安定条件はcell lengthと連動する。

現行40x40 gridを維持する場合でも、cell physical lengthを決めるまで `h2_diffusion=0.05/tick` をFINAL値として扱わない。

## 3.3 H2 uptake kinetics

旧:

```text
J = arbitrary uptake_coef * H(C,K)
```

をphysical defaultにはしない。

現存acetogenの測定では、少なくとも溶存H2 450–600 µM付近までH2 consumptionは飽和を示さず、first-order kineticsに近いという報告がある。

V1.9候補式:

```text
q_H2_specific = min(k_H2 * C_H2, q_H2_max)
J_H2          = q_H2_specific * dry_mass * chemical_absorption
```

単位例:

```text
k_H2     : m^3 / (kgDW s)
q_H2_max : mol / (kgDW s)
dry_mass : kgDW
J_H2     : mol/s
```

`chemical_absorption=1.0` は**reference acetogen級のH2 uptake能力**を表すdimensionless multiplierへ意味を変更する。

candidate anchor:

```text
q_H2_max order ≈ 50 mmol/(gDW h)
```

A. woodiiのH2+CO2培養でH2 uptake約85 mmol/L/h、biomass 1.71 g/Lという報告から得られるオーダー。

`k_H2`の最終referenceはOpus 5レビューおよび元論文再確認後に固定する。

# 4. H2からusable Energyへの変換

acetogenic reference reaction:

```text
4 H2 + 2 CO2 -> acetate + 2 H2O
ΔG°' ≈ -95 kJ/mol acetate
```

したがってchemical free-energy scaleは約:

```text
23.8 kJ/mol H2
```

A. woodiiではH2+CO2からacetate生成時のATP gainが約0.3 mol ATP/mol acetateと報告されている。

したがって旧:

```text
h2_energy_yield = 1 arbitrary
h2_conversion_eff = 0.60
```

をそのまま使わない。

V1.9では最終的に:

```text
H2 uptake [mol/s]
 -> chemical free energy [J/s]
 -> biologically usable power [J/s]
```

へ変換する。

ATP hydrolysis free energyの採り方に依存するため、usable Energyは概ね数kJ/mol H2オーダーになる。
**具体的なJ/mol値はdry-mass/BMR scaleと同時に最終確定する。**

# 5. maintenance / BMRの見直し

旧 `bmr_core=0.15 E/tick` 等はphysical scaling後のFINAL値として使わない。

acetogenesis/methanogenesisの低成長系では、maintenance coefficientが約0.116 mmol ATP/(gDW h)以下という報告がある。
これはV1.9 iLUCAのmaintenance sanity anchorとして使える。

ただし:

- LUCAそのもののmaintenance実測値ではない
- resource-richで6 h程度のdoublingを出すgrowth-associated powerとは分ける
- movement / repair / sensing / membrane / storage upkeepを全て独立arbitrary E/tickで足し上げない

V1.9 physical modelでは、少なくともtotal basal maintenanceのオーダーを現実に接続したうえで、各機能costをその内訳または追加powerとして再定義する。

# 7. Exp15再開前にまだ決める必要がある事項

Energy収支問題は「原因不明の赤字」から「物理単位で再構築する問題」へ整理できたが、**まだ解決完了ではない**。

以下はExp15前の必須human decisions。

## S1. iLUCAの基準サイズ・dry mass

必要:

```text
reference cell diameter/radius [µm]
reference dry mass [pg or kgDW]
body_size / matter gene-stateとの対応
```

これがないとspecific H2 uptake [mol/(gDW h)]を1個体mol/sへ変換できない。

## S2. world長さ・grid cell長さ・有効voxel体積

必要:

```text
world physical width/height
cell physical length
2D modelのeffective depth
cell volume [m^3]
vent source area/volume
```

これがないと:

- H2 concentration <-> amount
- mol/s source flux
- physical diffusion

を閉じられない。

## S3. biomass/Matter scaleと成長energetics

必要:

```text
1 matter unit = ? kgDW
nutrient field = 何を表すか
matter assimilation / biomass synthesisのEnergy cost
```

reference doubling ≈6 hを**強制するのではなく**、現実オーダーのuptake/maintenance/growth costを置いた結果として4–8 h程度になるかsanity確認する。

## S4. movement physicalization

基準細胞サイズ確定後に:

```text
speed [µm/s]
movement power [W]
```

へ接続する。
現行movement costがtotal Energy budgetを不自然に支配しないことを確認する。

## S5. numerical timestep invariance

physical parameter化後は、少なくとも簡易系で:

```text
dt = 5 s / 10 s / 20 s
```

を比較し、dtを変えただけで生物学的結論が大きく変わらないことを確認する。
10 sはphysicsではなくstandard numerical timestepである。
