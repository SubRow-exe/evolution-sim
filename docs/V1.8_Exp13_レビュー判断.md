## 1. 結論

V1.8の設計思想は維持する。

```text
light
= 広域 / renewable flow / 低い平均収益 / day-night / 表面積・光強度依存

chemical
= 局所stock / 高い局所収益ポテンシャル / 消費で減る / 競争 / ventから再供給
```

光を弱くする直接penalty、chemicalへの固定bonus、完成した生態型classは追加しない。

Exp13は「一点を決め打つ校正」から、**広い生態地図を先に作り、その中から当面のworking referenceを選ぶ校正実験**へ変更する。

## 2. MUST FIX採否

### M-1 昼夜cycleで平均光量が低下する

**指摘の計算は正しいが、energy中立化提案は不採用。**

half-sine / day_fraction=0.5 の平均factorが約0.318であり、同じ`light_max`なら静的世界より一周期総光量が減ることは意図した性質とする。

理由:
- 今回の人間方針は「光は広く得られるが、夜があり平均的には薄い」
- 昼を3.14倍して静的世界と一日総量を揃えると、昼だけ極端に高密度となり狙いから外れる
- `light_max`自体をExp13で広く振り、成立域を実測する

したがってdaylight factorは0〜1の非正規化half-sineを維持する。

### M-2 / M-3 light候補・成立基準が弱い

**採用。**

旧`1.2 -> 1.5 -> 1.8 -> 2.4`逐次rescueを廃止し、最初から広いsweepを行う。

```text
light_max = 0.8, 1.2, 1.5, 1.8, 2.1, 2.4, 3.0, 4.0
```

初期個体の遺伝子を各光量へ合わせて救済しない。Phase Aは固定標準個体を使い、環境の厳しさを地図化する。

暫定working referenceは「最小の頑健成立水準」を事前規則で選ぶ。詳細はExp13正本。

### M-4 body_size=1.0だけで昼夜を検証している

**採用。**

Phase Aの固定個体校正は維持するが、Phase Bにbody_size診断を追加する。

- Exp12平衡付近`body_size≈0.246`固定個体のnight viability診断
- body_sizeのみ進化ONのlight-only診断

V1.8 ACCEPTのHARD GATEにはしない。昼夜が新しいbody-size選択圧を作る事実を記録し、V1.9前の再評価材料にする。

### M-5 BURST_RATIOの比較窓が非対称

**指摘採用。ただしBURST_RATIOを選定gateから削除する。**

V1.8の目的は「chemicalがlightの何倍か」を人工的に固定することではない。

選定は:
- 生存・繁殖継続
- population
- Energy収支
- vent stock depletion/recovery
- vent占有
- 密度競争
- mixed worldで両経路に実利用価値が残るか

を中心に行う。

同じ初期1,000 tick窓や単独個体理論取得速度は診断値として出してよいが、`BURST_RATIO >= X`をHARD GATEにしない。

### M-6 Exp12機械verdictの明記

**採用。**

Exp12の事前登録機械判定は:

```text
SCIENTIFIC_VERDICT = INVALID_OR_METHOD_REVIEW
reason = B2 method-control gate未達
```

だったことを履歴として明記する。

その上で人間判断として:

```text
METHOD CONTROL ASSUMPTION INVALID
```

すなわち「classifier失敗」ではなく「B2を既知stationary controlとした前提が不成立」と整理し、B1結果から`bmr_core=0.15`を採用したことを分離して記録する。

## 3. SHOULD FIX採否

### chemical_uptake_half=6.15

**固定採用を撤回し、Exp13でsweepする。**

候補:

```text
chemical_uptake_half = 0.5, 1.5, 3.0, 6.15
chem_uptake          = 0.5, 1.0, 2.0, 4.0
```

6.15は生物不在vent平衡12.3の半分から置いた暫定値で、生物占有時の実濃度帯に対して高すぎる可能性がある。

選定ではrealized `H(C,K)` 分布を必ず観測し、「ほぼ常時0」または「ほぼ常時1」になっていない組合せを優先する。

### density response × day/nightの分離

**採用。ただし長期runを増やさず軽量診断。**

Phase 0で2 feature flagの4組合せ:

```text
density OFF / cycle OFF
density ON  / cycle OFF
density OFF / cycle ON
density ON  / cycle ON
```

を短時間E2Eで確認する。各機構が独立に効き、OFF/OFFがV1.7へ回帰することを保証する。

### bmr_core=0.15境界

**値は維持。注記のみ採用。**

0.15は物理的相転移点ではなく、事前登録した0.23 sentinelを最初に超えた試験格子点。将来環境ルール変更後にbody_size平衡を再確認しうる。

### classifier陽性対照

**採用。**

今後classifier実装の正しさは既知形状の合成軌跡unit testで検証する。自然runを「既知stationary」と仮定してmethod positive controlにしない。

### workflow / feature flags / non-target resources

**採用。**

- light/chemical density responseをnutrient/corpse/predationへ適用しない
- daylight tick基準を一意化
- feature flag 4組合せtest
- candidate gridは一括manifest化し、人手複製禁止
- Phase A選定後のselected値をartifactとして固定
- artifact取得は多数artifact実績を踏まえ`gh run download`等の完全取得手段を使う

## 4. Exp13の考え方

Exp13は「絶対的な地球物理値を決める実験」ではない。

目的は:

1. 光量の低すぎる絶滅域から豊かすぎる域まで地図化する
2. chemical uptakeの濃度応答と処理速度を広く地図化する
3. 光のみ/chemicalのみ双方が成立できるworking referenceを選ぶ
4. mixed worldで片方が自動的に無意味になっていないか確認する
5. 将来温度・季節・source turnover等が入れば再校正可能な基準データを残す

したがってselected値は「永久の自然定数」ではなく、**現在の世界ルールにおけるworking reference**と明記する。
