# V1.1終了とVer.1.2移行方針

更新: 2026-08-29

## 1. 結論

Ver.1.1 baseline (`v1.1-baseline`) の詳細解析は無制限に続けない。

Exp03までで、現行世界には**小型化・高光利用化への強い方向性選択**があることが十分に確認された。一方、光利用型への収斂と、単一祖先系統が人口の過半を占める selective sweep（本プロジェクトで「転移」と呼ぶ現象）は同一ではない。

Issue #18の一次解析も完了し、sweep予定系統は早期から多産だが多死で相殺され、sweep時にその均衡が崩れることまで分かった。

したがって、**V1.1で残る必須本番はExp04のみ**とする。Exp04で主要4形質の依存性を切り分けたら、直接トリガーが完全未解明でもV1.1解析を一区切りとし、Ver.1.2へ進む。

---

## 2. V1.1で確定したこと

### 世界全体の方向性

- 小型化・高光利用化への強い方向性選択がある
- 40,000 tickまでに13/20 seedが主判定のsweepへ到達
- 未転移seedでも高光利用化が進む
- よって**生態型への収斂とlineage sweepは別現象**

### sweep前の系統動態 — Issue #18 完了

13転移seedの `events.csv` 再解析より:

- 支配予定系統はsweepの6,000〜2,000 tick前から出生率が集団平均の1.25倍（中央値）
- しかし死亡率も高く、純増余地は中央値1.02
- 多産であるだけでは人口増加へつながらず、**多産多死の高回転状態**で長く停滞する
- sweep時に出生/死亡の均衡が崩れる
- 均衡崩壊の内訳は一様でなく、死亡低下型と出生増大型がある

したがって当初の

```text
繁殖優位 → 人口増加 → 試行回数増加 → 追加適応 → sweep
```

は**部分的に支持、要修正**。

未解決なのは、**なぜ多産多死の均衡が破れるか**。
候補は内的要因（追加変異）と外的要因（局所資源・競合系統・空間配置）の両方。

この完全な因果同定はV1.1終了条件にはしない。

## 3. 最後の必須実験 — Exp04 / Issue #4

`body_size` / `light_absorption` / `reproduction_investment` / `mutation_rate` を1つずつ祖先初期値で固定し、Exp03と同じ20 seed × 40,000 tickで比較する。

目的は、各形質の初期値からの進化がsweepに対して

- 必須に近い
- 発生を促進する
- 非必須

のどれに近いかを大きく切り分けること。

### 重要な解釈

40,000 tickの打ち切り実験なので、0/20でも「永遠に必要」とは言わない。

- 固定条件で1例でもsweep → 厳密な必要条件ではない
- 0/20 → 40k以内のsweepに強く必要な候補
- 発生率低下/遅延 → 促進因子候補
- 同程度 → 主要な必要条件ではない

同じseedを使うため、baselineとfixedの対応2×2表も残す。

### 副解析

Exp04はV1.2の設計材料も取る。

- population / biomass / lineages
- births / deaths / death causes
- light / chemical / nutrient / corpse / predation利用
- 固定していない遺伝子の代償進化
- sweepが起きた条件では `analyze_trigger.py` で多産多死パターンを確認

特に `light_absorption` 固定時に化学・死骸利用へ逃げられるかは、現在の資源構造が代替ニッチを許しているかの直接的な手掛かりになる。

詳細: Issue #4 / `docs/次の実験計画.md`

## 6. Ver.1.2の目的

Ver.1.2では、生物側の能力を直接調整して多様性を作るのではなく、**世界側の情報量・環境差を増やす**。

V1.1は安定した光が広範囲に存在し、小型・高光利用型が非常に合理的な解になっている。これはバグとして抑制せず、V1.1の自然な結果として保存する。

### 原則

- 「多様性が欲しいから光を弱くする」のような結果合わせをしない
- 抽象的な一律ペナルティを避け、光・温度・資源等の意味ある環境量で表現する
- 一度に多数の環境軸を追加しない
- V1.1 baselineモードを残す
- 同一seed・同一数値実行環境で比較する

---

## 7. Ver.1.2実装前のStage 0 — 資源構造監査

以前は「時間的な光変動」を第一候補としていたが、実装規模だけで決めない。
まず現在の世界の資源構造そのものを監査する。

現行Configの公称値:

- 1,600セル
- 光: 全域・毎tick供給、最低でも最大値の30%
- 世界全体の平均光供給: 約 **1,248 E/tick**
- 化学: 4噴出口、理論最大再生でも重複/端欠け無しで約 **32.5 E/tick**
- 初期無機栄養: **3,200 M** の閉鎖プール

光と化学には供給規模・空間範囲とも大きな非対称がある。
これは意図した世界なら問題ないが、V1.2へ進む前に確認する。

監査項目:

- 公称供給/ストック
- 実利用量・未利用量
- 空間的利用可能範囲
- 時期ごとの律速資源
- Exp04のlight固定条件で代替資源利用が増えるか

資源量を変更する場合も、**多様性のための調整ではなく、意図しないスケール不整合の修正**として根拠を残す。

---

## 8. Ver.1.2の第一候補

Stage 0の監査後、現時点では**空間的なエネルギーニッチの強化**を第一候補とする。

例:

```text
明所             → 光利用が有利
薄暗い領域       → 高効率光利用または移動が必要
ほぼ無光領域     → 光だけでは成立しにくい
化学噴出口周辺   → 化学利用に機会
```

既存遺伝子だけで光利用型・化学利用型等が自然に分化する余地をまず作る。

### 時間的光変動

候補から外さないが、第一手ではなく**高光利用戦略の頑健性テスト**として位置づける。

### 複数無機栄養素

有望だが、全生物に同じ比率で2資源を要求するだけでは「新しい律速資源」が増えるだけになりやすい。
生物ごとの資源要求比・吸収戦略まで接続する段階で本格導入する方がよいため、V1.2最初の小規模更新より後段を基本とする。
