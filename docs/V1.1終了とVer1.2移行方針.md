# V1.1終了とVer.1.2移行方針

更新: 2026-08-29

## 1. 結論

Ver.1.1 baseline (`v1.1-baseline`) の詳細解析は無制限に続けない。
Exp03までで、現行世界には**小型化・高光利用化への強い方向性選択**があることが十分に確認された。
一方、光利用型への収斂と、単一祖先系統が人口の過半を占める selective sweep（本プロジェクトで「転移」と呼ぶ現象）は同一ではない。

Issue #18 の一次解析により、sweep予定系統は早い段階から**高回転（多産多死）**だが、出生優位が死亡不利で長期間相殺されることが分かった。sweep時にはこの均衡が崩れるが、その直接トリガーは未解明である。

Ver.1.1 は **Exp04を完了した時点で必須解析を終了**し、未解決点をBacklog化してVer.1.2へ進む。

Exp04の実行条件・事前チェック・解析ルールは `docs/Exp04_実行手順.md` を正本とする。

---

## 2. Ver.1.1で最後に確認すること

### A. 主要4形質の依存性 — Exp04 / Issue #4

`body_size` / `light_absorption` / `reproduction_investment` / `mutation_rate` を1つずつ初期値に固定し、Exp03 baseline（20 seed × 40,000 tick）と同じ転移定義で比較する。

目的は、40,000 tick以内のselective sweepに対して各形質の進化が

- 必須に近い
- 促進する
- 非必須

のどれに近いかを大きく切り分けること。

**過去に検討した「1条件だけ先に本番を回し、結果を見て残り条件の設計を変える案」は不採用。**
事前3 seed × 10k確認を終えたため、4条件×20 seed×40kを同じ事前固定設計で完遂する。

### B. 転移トリガー一次解析 — Issue #18 ✅ 完了

確認結果:

- sweep予定系統はsweepより前から高出生率
- しかし高死亡率も伴い、人口増加へ直結しない
- 13転移seedで高回転状態が再現
- sweep時には出生/死亡の均衡が崩れる
- 均衡崩壊の内訳はseedで異なり、死亡率低下だけが共通トリガーではない

当初の「繁殖優位 → そのまま人口増加 → 変異試行回数増加 → sweep」という仮説は**部分的に支持、要修正**。

未解決: **なぜ高回転状態の均衡が破れるか**。内的追加変異か、局所資源・競合・空間配置など外的要因かは未同定。

完全な因果同定はV1.1終了条件にしない。

### V1.1終了判定

1. [ ] Exp04で主要4形質の依存性を大まかに切り分ける
2. [x] sweep前に特定系統の繁殖優位が先行することを確認
3. [x] 正のフィードバック仮説を「部分的支持・要修正」と記録
4. [ ] Exp04後に未解決点をBacklogへ整理

**Exp04完了でV1.1の必須解析は終了する。**

## 4. Ver.1.2の目的

Ver.1.2では、生物側の能力を直接調整して多様性を作るのではなく、**世界側の情報量・環境差を少し増やす**。

現在のV1.1は、安定した光が広範囲に存在し、小型・高光利用型が非常に合理的な解になっている。
これはバグとして抑制せず、Ver.1.1の自然な結果として保存する。

Ver.1.2では「一種類の戦略だけで世界全体を最適利用しにくい」条件を、具体的な環境変数から作る。

### 原則

- 「環境負荷」という抽象的な一律ペナルティはなるべく置かない
- 温度、光量、資源量、時間変動など**意味のある環境量**に分解する
- 特定の生態型を有利にするためのボーナスを入れない
- 1回の更新で多数のルールを追加しない
- V1.1 baselineと同じseedで比較可能な実験を用意する

---

## 5. Ver.1.2 Stage 0 — 資源構造監査

機能追加より先に、V1.1の資源構造を数値で監査する。

確認するもの:
- 光・化学・無機栄養の公称供給量/ストック量
- 実際の利用量と未利用量
- 空間的な利用可能範囲
- 時期ごとの律速資源
- Exp04 `light_absorption`固定時の代替資源利用

資源量を変更する場合も「多様性を増やすため」ではなく、**意図しないスケール不整合を修正する場合のみ**とする。

---

## 6. Ver.1.2の現第一候補

Stage 0監査後の第一候補は**空間的なエネルギーニッチの強化**。

例:

```text
明所             → 光利用が有利
薄暗い領域       → 高効率光利用/移動が重要
ほぼ無光領域     → 光だけでは成立困難
化学噴出口周辺   → 化学利用の機会
```

最初は新しい遺伝子を増やさず、既存の `light_absorption` / `chemical_absorption` / movement / sensory_range で分化が創発するかを見る。

時間的な光変動は候補から外さないが、第一手ではなく**高光利用戦略の頑健性テスト**として位置づける。

複数無機栄養素は有望だが、生物側の要求比率・吸収トレードオフまで設計しないと単なる新しい律速資源になりやすいため、より本格的な資源化学拡張へ回す。

## 7. 再現性

V1.1とVer.1.2を比較する実験群は、同一マシン・同一数値実行環境で行う。
`meta.json` にOS / architecture / Python / NumPy / git SHA等を記録し、`tools/check_env.py` で照合する。
