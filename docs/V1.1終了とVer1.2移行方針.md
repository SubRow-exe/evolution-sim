# V1.1終了とVer.1.2移行方針

更新: 2026-08-30

## 1. 状態

**Ver.1.1の必須解析は完了。V1.1をクローズし、Ver.1.2の設計検討へ移行する。**

正式な総括は [`V1.1_総括.md`](V1.1_総括.md) を参照。

Ver.1.1で確定した主要知見:

- 現行世界には**小型化・高光利用化への強い方向性選択**がある
- 生態型への収斂と、単一祖先系統によるselective sweepは別現象
- sweep予定系統は、sweep前に**多産多死の高回転状態**を経る
- 高回転状態では出生優位と死亡不利が長期間ほぼ相殺される
- sweepは単一形質のスイッチではなく、複数形質が異なる強さで発生ハザードを上げる**多因子現象**と考えるのが最も整合的
- Exp04では `mutation_rate` 固定が最も強くsweepを抑制したが、1/40ではsweepしたため絶対条件ではない
- 小型化・高光利用化には部分的な代償経路がある

---

## 2. Exp04最終結果

GitHub Actions / Ubuntu 24.04、同一コード・同一数値実行環境で、
5条件 × 40 seed × 40,000 tick = **200 run** を実行。

主判定 `top_lineage_frac >= 0.5`:

| 条件 | 40kまでのsweep |
|---|---:|
| baseline | **28/40 (70.0%)** |
| reproduction_investment固定 | **20/40 (50.0%)** |
| light_absorption固定 | **15/40 (37.5%)** |
| body_size固定 | **9/40 (22.5%)** |
| mutation_rate固定 | **1/40 (2.5%)** |

全固定条件で少なくとも1 seedはsweepしたため、今回の4形質のどれも単独の絶対必要条件ではない。

40k内sweepを抑える強さの暫定順序:

```text
mutation_rate ≫ body_size > light_absorption > reproduction_investment
```

これはVer.1.1世界・40,000 tickという条件下での効果であり、一般的な重要度ランキングではない。

詳細: [`V1.1_総括.md`](V1.1_総括.md)

## 5. Ver.1.2の目的

Ver.1.2では、生物側の能力を直接調整して多様性を作るのではなく、**世界側の情報量・環境差・資源差を増やす**。

原則:

- 多様性を直接保護しない
- 特定生態型へのボーナスを置かない
- 抽象的な一律ペナルティより、光・資源・空間・時間など意味のある環境量を使う
- 一度に多数の環境軸を追加しない
- V1.1 baselineを保存し、同じ観測法で比較できるようにする

---

## 6. Ver.1.2開始前に確定している準備

### A. 空間可視化基盤 — Issue #23

環境差を追加する前に、以下を観測できるようにする。

- 一定tickごとの空間分布PNG
- 環境ヒートマップ + 個体分布
- PNG連番からGIF生成
- 系統ごとの占有セル数
- 系統重心
- 平均移動距離 / tick
- 分布幅

観測ON/OFFで乱数系列・シミュレーション結果を変えないことを必須とする。

### B. 現行資源構造監査 — Issue #19

V1.1世界について以下を数値化する。

- 光・化学・無機栄養の供給/ストック
- 実利用量と未利用量
- 空間的利用可能範囲
- 時期ごとの律速資源
- Exp04 `light_absorption`固定群から得られる代替資源利用の示唆

## 7. Ver.1.2の追加要素

以前は「空間的エネルギーニッチ」を第一候補としていたが、**V1.1終了後に改めて候補を比較して決定する。**

候補には少なくとも以下を含める。

- 光・化学エネルギーの空間分布強化
- 資源量/供給スケールの見直し
- 無機栄養素の構成・分布の複雑化
- 時間的な光変動
- その他、V1.1の単一優位戦略を世界側の構造から分岐させる要素

次の作業は、**V1.2追加要素の比較検討と最小実装範囲の決定**とする。
