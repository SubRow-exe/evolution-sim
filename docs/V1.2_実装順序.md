## V1.2確定仕様

```text
light_pattern = high_contrast_vertical
light_hc_bright_frac = 0.50
light_hc_transition_frac = 0.30
light_hc_dark_floor = 0.0
```

40×40、`light_max=1.2`:

```text
Control vertical        = 1,248 E/tick

```

Treatmentの40行:
- 北20行: full light
- 中12行: linear transition
- 南8行: zero light

総量を変えず、空間配置だけを変更する。

## Pilotの用途

Pilotで確認するのは実装健全性のみ。

- crashなし
- 光総量一致
- zone境界正しい
- snapshot/env/空間指標出力
- PNG/GIF生成
- 観測ON/OFF科学状態不変

大量死・暗部無人化等が正しいモデル帰結なら、望む見た目に合わせて調整しない。

## Exp05 Gate

本番へ進む条件:
- #19 completed
- #23 completed
- pytest Green
- observation invariance Green
- pilot 6 runの欠損なし
- Control/Treatment光総量一致
- GitHub Actionsで同一数値実行環境を使える

## 原則

- パイロットで生態系を好みに調整しない
- 一度に複数世界ルールを追加しない
- Exp05結果を見る前に評価項目を固定する
- 多様性増加そのものを成功条件にしない
