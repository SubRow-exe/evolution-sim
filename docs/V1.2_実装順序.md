## V1.2

世界ルール変更。

Treatment:

```text
light_pattern = high_contrast_vertical
light_hc_bright_frac = 0.20
light_hc_transition_frac = 0.50
light_hc_dark_floor = 0.0
light_hc_total_scale = 1.0
```

既定40×40では8行明部・20行遷移・12行完全暗部。
総光量はControl `vertical` と同じ1,248 E/tickへ正規化する。

`light_hc_total_scale` は将来、同じshapeのまま総光量だけを変える実験に使う。Exp05では1.0固定。

## Exp05後の原則

V1.2以降しばらくは光環境を小刻みに振り、原因を切り分ける。

1. まずExp05: **総光量固定・空間偏在を強化**
2. 次に結果を見てどちらか一方だけ変更
   - 総光量固定のままさらに偏在を強化
   - shape固定のまま総光量を増減
3. shapeと総量を同時変更しない

多様性増加を成功条件にせず、暗部無人化なども結果として受け入れる。
