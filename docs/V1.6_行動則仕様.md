# V1.6 行動則仕様 — temporal biased random walk

更新: 2026-08-31
状態: **人間判断済み / 実装待ち**
実装担当: **Claude Code または Codex**

## 1. 目的

V1.5 / Exp09 では light と chemical の無次元比較則は Green となったが、追加監査で現行個体は `sensory_range` と `cell_size` の関係からほぼ移動していないことが判明した。また light / chemical field はセル内一定なので、単純な時間差 `ΔQ` は約96%の tick で 0 になる。

V1.6では一次Energyに対する行動を、周囲の最良セルへ直接向かう方式から、**現在位置で感じる刺激の時間変化によって既存random walkの曲がり方だけを変える方式**へ変更する。

V1.6は以下2変更を不可分に含む。

1. light / chemical の**知覚のみ連続化**する
2. temporal sensing により random walk を偏らせる

吸収・供給・消費などの物理は変更しない。

## 2. V1.6実装内容

### 2.1 light / chemical知覚の連続化

light / chemical の知覚値は、個体の連続座標 `(x, y)` に対して隣接セル値を**双線形補間**して得る。

- 補間するのは知覚のみ
- light吸収、chemical吸収、chemical供給・損失、セル構造はV1.5以前のまま
- 境界ではworld内へclampし、数値的に連続な知覚値を返す
- セル中心では元のfield値と一致することをテストする

一次Energy知覚では周囲セルを走査して最良地点を探さない。`sensory_range` は light / chemical の temporal sensing には使用しない。

### 2.2 無次元受容器応答

V1.5の式を維持する。

```text
R_light = light / (light + light_stimulus_half)
R_chem  = chemical / (chemical + chemical_stimulus_half)
```

### 2.3 統合環境評価値 Q

能力値そのものが走性の強さを倍増させないよう、単純加算ではなく**能力加重平均**とする。

```text
aL = light_absorption
aC = chemical_absorption

Q = (aL * R_light + aC * R_chem) / (aL + aC)
```

能力が無効閾値未満の項は分母・分子から除外する。両方無効なら `Q = 0`。

意味:
- abilityは「どの刺激を重視するか」を決める
- 全abilityを同率で2倍してもQは変化しない
- Qは原則 `0 <= Q < 1`

専門化コスト・受容体コストはV1.6では導入しない。

### 2.4 短期記憶

個体は一次Energy知覚用に内部状態 `Q_memory` を1個持つ。

初回は人工的な差分を作らないよう:

```text
Q_memory = Q_now
ΔQ = 0
```

以後:

```text
ΔQ = Q_now - Q_memory
alpha = 1 - exp(-1 / memory_tau)
Q_memory <- Q_memory + alpha * (Q_now - Q_memory)
```

`memory_tau` は Exp10 で校正する。

### 2.5 移動則

新しいturnイベント機構は追加しない。既存random walkの

```text
heading += Normal(0, wander_turn_sigma)
```

を、`ΔQ` によって変調する。

推奨する確定式:

```text
turn_factor = 2 / (1 + exp(response_gain * ΔQ))
sigma_eff   = wander_turn_sigma * turn_factor
heading    += Normal(0, sigma_eff)
```

性質:
- `ΔQ = 0` → `turn_factor = 1` → 現行baseline
- `ΔQ > 0` → `turn_factor < 1` → 直進しやすい
- `ΔQ < 0` → `turn_factor > 1` → 曲がりやすい
- factorは `(0, 2)` に収まり数値的に暴走しない
- `response_gain = 0` → 常にbaseline random walk

移動速度は既存 `v_max * wander_speed_frac` を維持し、V1.6では速度そのものを刺激で変えない。

### 2.6 停止条件

現行の「現在セルが最良だから停止する `stay=True`」を一次Energyについて廃止する。

一方、既存の満腹時停止:

```text
energy >= satiety_energy_frac * e_max
AND
matter >= target_size
```

は維持する。

### 2.7 nutrient / corpse / predation

V1.6の対象は**light / chemical の一次Energy行動のみ**とする。

nutrient / corpse / predation の直接ターゲティングは既知の非対称として当面維持する。これらの全刺激統合は別バージョンの独立軸とし、Exp10では主効果の混同を避けるため診断表現型・synthetic arenaでは原則無効化する。

実装では既存legacy行動を壊さないこと。一次EnergyのWTAターゲティングだけを廃止する。

## 3. V1.5保存

V1.6コード変更の前に必ず:

1. 現行確定状態を `v1.5-final` として保存
2. V1.5の再現手段を残す
3. V1.6最初の確定実装commitを新しいCI回帰基準へ移す

V1.6は移動原理を変えるためV1.5とのbit一致は要求しない。ただしlight / chemical吸収物理、Matter / Energy保存、seed固定時のV1.6内部決定論は必須。

## 4. 実装時の必須観測

RNGを消費せず行動へフィードバックしない観測として最低限:

- `Q_now`
- `Q_memory`
- `delta_q`
- `delta_q_light` / `delta_q_chemical` または同等の寄与分解
- `sigma_eff` / `turn_factor`
- 実移動量
- vent中心からの距離帯

を集計可能にする。

## 5. Exp10で校正する値

V1.6コードに仮固定して本番defaultとしないもの:

```text
memory_tau
response_gain
```

`wander_turn_sigma`、移動速度、吸収パラメータは今回の校正軸にしない。

候補範囲は Exp10 計画書を正本とする。
