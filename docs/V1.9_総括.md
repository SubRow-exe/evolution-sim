# V1.9 総括 — iLUCA Origin Lock / physical chemical-first baseline

更新: 2026-09-07  
状態: **CLOSED by human decision**

V1.9は、V1.8で昼夜・光・chemicalを同時に扱った際に露出した「祖先生理と世界スケールの不整合」を受け、今後の進化の起点として使える iLUCA を再構築するversionである。

V1.9の完了条件は「歴史上のLUCAを完全再現すること」ではない。

> **今後の進化を始めるために、物理量・Energy収支・資源取得・成長・繁殖が十分に解釈可能で、固定iLUCAが現実的orderの環境で成立すること。**

この条件を満たしたため、未解決事項を明示した上でV1.9をcloseする。

# 1. V1.8からの方針転換

V1.8までは、旧 `chemical` field を一次Energy源として扱い、資源吸収量がほぼ直接Energyへ変換されていた。

昼夜導入後のExp13–15初期検討では、夜を越せない問題に対し環境側を調整する方向へ寄りすぎた。しかしレビューにより、問題の一部は「祖先側に進化可能な恒常性・貯蔵・繁殖戦略が不足していたこと」と「world/organismの単位がarbitraryであったこと」にあると整理された。

そこでV1.9では、環境をiLUCAへ合わせ込むのではなく、まず生物・環境双方を物理的に解釈可能な形へ再設計した。

- 1-pool Energyを維持
- `storage_capacity` gene追加

## 2.2 chemical -> H2 substrate

旧 `chemical` の意味を廃止し、physical modeでは明示的な H2 substrate とした。

- H2はEnergyそのものではない
- H2 uptake -> metabolism -> usable Energy の順でEnergyを得る
- H2濃度を mol/m3 で保持
- H2 diffusionを物理係数で扱う
- exchange/lossを環境からの除去timescaleとして扱う
- biological uptakeをmol/sへ接続
- sourceは現状Dirichlet concentration boundary

CO2はV1.9ではimplicit abundant co-substrate。

## 2.4 LUCA-like proxy

- phototrophy OFF at origin
- predation OFF at origin

数値は主に現生acetogenのorder/scalingを使い、LUCAの測定値とは扱わない。

## 2.5 structural innovation

continuous mutationと「能力そのものの起源」を分離。

- phototrophy = structural innovation gated

# 4. Exp16 — fixed-iLUCA H2 environment robustness

11 conditions x 5 seeds x 10 days = 55/55 runs complete。

iLUCAを固定し、H2 concentration / diffusion / exchange-loss timescale / source geometryだけを変更した。

主要結果:

```text
H2 1 mM   -> 5/5 extinction
H2 3 mM   -> 5/5 extinction
H2 6 mM   -> persistence / slow growth
H2 10 mM  -> robust growth
H2 15 mM  -> high growth

low diffusion       -> extinction
high diffusion      -> high growth
fast H2 loss        -> extinction
slow H2 loss        -> high growth
square source       -> robust growth
cross source        -> persistence / contraction
cluster source      -> local reproduction then extinction
```

重要な解釈:

1. source peak H2濃度だけでは成立性は決まらない
2. H2-rich regionの面積・連結性・遭遇可能性が強く効く
3. biological H2 uptake / source influxは1e-6–1e-5 orderで、現在はH2 depletion competitionよりpatch accessが主要圧
4. baselineは最適化し直さずreferenceとして保持

Opus5再解析では、reference iLUCAのmaintenanceを賄えるH2濃度は約248 µMであり、その濃度以上のworld面積割合（habitability fraction）がExp16の生存/絶滅を非常によく分離した。

この指標は今後の環境追加時のcheap pre-screenとして利用する。

# 6. V1.9で得た主要な教訓

## 6.1 環境を生物へ合わせすぎない

固定祖先が崩壊したこと自体は、環境が不適切とは限らない。
適応可能な生理レバーが欠けている可能性を先に疑う。

## 6.2 単位系を閉じないと「バランス調整」の意味が弱い

時間・空間・Energy・substrateをphysical scaleへ接続したことで、growth / maintenance / uptake間の不整合を定量的に診断できるようになった。

## 6.3 代償なき形質は境界へ張り付きやすい

storage / starvation / activity等の進化形質は、benefitだけでなくcostまたは環境依存のtrade-offが必要。

## 6.4 fixed phenotype sanityとevolution testを分ける

固定iLUCAが生きられるかと、進化がその環境を解けるかは別問題。

## 6.5 実験結果からbaselineを最適化し直さない

成立範囲を見つけても「最も生存しやすい値」へ寄せない。
robustnessを確認したらworking referenceを置いて次へ進む。

## 6.6 LUCA再現度を目的化しない

LUCA-like physiologyはoriginの品質管理のために使う。
分子詳細の完全再現をmainstreamのblockerにしない。
