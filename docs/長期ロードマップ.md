# 長期ロードマップ — iLUCAから陸上・飛翔まで

更新: 2026-09-07  
状態: **方向性採用 / 近未来ほど具体、遠未来ほど仮説**

この文書は将来仕様を固定するものではない。各versionを長期目標へ接続しつつ、直前実験の結果に応じて順序を更新するためのロードマップである。

---

# 0. 最上位方針

長期目標は、完成した生物種を設計者が追加するのではなく、

```text
環境物理 + 化学 + 基礎生理 + 遺伝 + 変異 + 個体間相互作用
```

から、LUCA-likeな単細胞を起点として代謝多様化・複雑化・陸上進出・歩行・飛翔まで到達可能な進化空間を段階的に作ることである。

## 0.1 LUCA再現は目的ではなく出発点の品質管理

**完全な歴史上のLUCA再現を完了条件にしない。**

採用優先順位:

```text
高信頼の因果構造
> 次の進化圧に重要な生理
> 現生proxyで妥当なorder/scaling
> 細部の歴史的再現度
```

LUCAらしさを上げる変更は、原則として以下のどれかを満たす場合に優先する。

1. 現在の結果を支配する欠落である
2. 次の進化実験に必要な応答レバーである
3. 現仕様が明らかに非生物学的な挙動を生む
4. 保存則・物理scale・解釈可能性を大きく改善する

逆に、結果へほぼ影響せず実装コストだけ大きい分子詳細は後回しにする。

# 1. 開発ペース

原則として **1つの新しいworld-rule軸を1段階ずつ追加**する。

1 phase / world-rule軸の標準形:

```text
A. mechanism implementation + tests
B. fixed ancestor / fixed phenotype sanity
C. evolution ONでadaptive accessibility確認
D. 既存主要因子との最小限interaction確認
E. working referenceを置いて次へ進む
```

通常は1軸あたり1〜3 experiment程度を目安とし、成立域がknife-edgeでない限り細かなglobal optimum探索をしない。

version番号は事前に遠未来まで予約しない。world ruleが変わるたびに次version境界を切り、単なるConfig sweepは同version内experimentとして扱う。

# 2. Phase 0 — V1.9 Origin Lock【現在】

目的:

> **iLUCAを「完璧なLUCA」ではなく、今後の進化を始めるのに十分妥当でロバストなoriginとして固定する。**

現在まで:

- physical H2 substrate / diffusion / loss
- LUCA-like H2/CO2 acetogen proxy
- 1-pool Energy / homeostasis
- maintenance-first growth allocation
- Exp15 fixed-iLUCA成立確認
- Exp16 H2環境robustness

まで成立。

## 残作業

### Exp15 Phase B

進化ON:

```text
storage_capacity
starvation_horizon
reproduction_horizon
```

のみを解禁し、baseline環境でこれらが実際に選択されるか確認する。

### Origin Audit（Exp17候補）

17形質を:

```text
A. LUCA/原核生物として根拠が比較的強い
B. 現生proxyから置いた値
C. 旧モデルから暫定継承
```

に分類する。

特に結果へ効きやすい以下だけ粗い感度確認を行う。

- movement / chemotaxis
- H2 uptake
- maintenance
- growth synthesis cost / growth ceiling
- storage / starvation / reproduction strategy

3〜5水準の粗い感度または低/基準/高程度で十分。最適値探索はしない。

### mutation / innovation audit

phototrophy実験前に:

- continuous mutation scale
- structural innovation probability
- capability loss probability

が「実験時間内にほぼ必ず出る」「ほぼ絶対に出ない」のどちらにも固定されていないことを確認する。

現実の1塩基変異率への厳密変換は必須ではない。進化モデル上の意味と時間scaleを明文化する。

## Phase 0 close条件

- baseline iLUCAが生存・成長・世代交代できる
- H2環境に自然な成立/不成立域がある
- 主要legacy parameter 1個だけが結果を完全支配していない
- 進化ONで少なくともV1.9追加3形質が変異・選択可能
- mutation/innovationのscaleが説明可能

ここまででV1.9をcloseする。LUCA分子機構の追加を理由にcloseを無期限延期しない。

# 3. Phase 1 — Energy Strategy Diversification / Phototrophy

V1.9後の最優先候補。

目的:

> H2依存chemical-first祖先から、設計者がphototrophを直接置かずにgeneric non-oxygenic phototrophyが創発・維持されるかを見る。

導入/利用:

- V1.8由来のday/night + light field
- V1.9のPHOTOTROPHY structural innovation gate
- H2 routeとの併存

### 実験候補

1. innovation OFF control
2. innovation ON複数seed
3. phototrophy出現後の系統追跡
4. 必要ならday/night有無またはlight量の最小interaction試験

見るもの:

- phototrophyが出現可能か
- 出現しても常に固定勝利しないか
- H2-specialist / mixed strategy / phototrophの分化余地
- 夜にstorage/homeostasisが選択圧として働くか

close条件:

phototrophyが「出すために確率を調整した能力」ではなく、環境条件に応じて増減する進化可能なstrategyになっている。

---

# 4. Phase 2 — Temperature / Reaction Kinetics

目的:

> LUCAを好熱性と決め打ちするのではなく、温度が代謝速度・維持費・膜安定・拡散へ自然な選択圧を作る世界にする。

導入候補:

- temperature field [K or °C]
- H2 uptake / metabolic reaction rateのtemperature dependence
- maintenance / damageへのtemperature effect
- 必要なら膜安定性とのtrade-off

### 実験候補

1. fixed iLUCAのtemperature response curve
2. spatial temperature gradientでevolution ON
3. H2 fieldとの最小interaction

精密なLUCA最適温度決定は目的にしない。

---

# 5. Phase 3 — Explicit Carbon / Matter Coupling

目的:

> 現在暗黙に無限としているCO2とgeneric nutrientを、最低限のcarbon mass balanceへ接続する。

導入候補:

```text
CO2 / dissolved inorganic carbon field
H2 + CO2 -> fixed carbon / biomass precursor
Matter productionとのcarbon conservation
```

### 実験候補

1. carbon unlimited limitが旧baselineを再現するか
2. carbon-limited conditionで成長律速が切り替わるか
3. H2-rich / C-poor vs H2-poor / C-rich spatial niche

分子レベルのWood–Ljungdahl全反応は不要。

---

# 6. Phase 4 — pH / Ion Gradient / Chemiosmosis + Membrane

目的:

> H2からEnergyへ直接変換する現在のcoarse-grainを一段だけ現実側へ進め、膜を挟んだH+/Na+勾配とATP生成の関係を進化圧へする。

導入候補:

- pH fieldまたはion-gradient potential
- membrane permeability / retention
- gradient利用効率
- ATP/usable Energy conversionとの接続

### 実験候補

1. fixed iLUCAがgradient有無でどう変わるか
2. membrane retention vs upkeep trade-off
3. pH/ion gradientのある空間でevolution ON

ATP/ADP分子を1個ずつ追う必要はない。

---

# 7. Phase 5 — Dynamic Hydrothermal Environment

目的:

> 「良いH2 patchを見つければ永久に勝ち」から、探索・分散・休眠が意味を持つ環境へ進める。

導入候補:

- explicit advection / flow
- vent flux fluctuation
- vent finite lifetime / birth / death
- resource patch turnover
- 必要に応じてdepth / pressure

現在のH2 loss tauは、この段階で流れを明示化できれば再評価する。

### 実験候補

1. static vs dynamic vent
2. dispersal / chemotaxis / starvation strategyの進化
3. local extinction + recolonization

# 8. Phase 6 — Microbial Ecology / Gene Exchange

複数代謝strategyが存在してから導入する。

候補:

- HGT（horizontal gene transfer）
- finite resource competition / carrying capacity
- corpse/detritus利用の高度化
- predation capability unlock
- metabolic byproducts / cross-feeding

### 実験候補

- HGT OFF/ONでtrait spreadとdiversity比較
- predation innovationの成立条件
- specialist/coexistenceの持続

H2 depletionが現状ほぼ無い問題も、この段階までに必要性を再評価する。

# 9. Phase 7 — Oxygen / Redox Feedback

generic phototrophyが成立した後の大きな転換候補。

```text
non-oxygenic phototrophy
 -> oxygenic innovation
 -> O2 field
 -> oxidative stress
 -> aerobic respiration / detoxification
 -> life-environment feedback
```

### 実験候補

1. O2生成なしcontrol
2. oxygenic innovation emergence
3. O2-sensitive / O2-tolerant / aerobic strategy分化

地球史のGreat Oxidation Eventを再現すること自体は目標にしない。

# 12. Phase 10 — Flight

長期到達点。

必要候補:

- 3Dまたは実質的な高度自由度

# 14. Parallel Track — Abiogenesis -> LUCA

**DEFERRED / NOT ABANDONED / mainstreamをblockしない。**

現在のOrganismより下位に別layerを作る。

候補段階:

```text
prebiotic chemistry
 -> autocatalytic network
 -> compartment / protocell
 -> heredity / replication
 -> metabolic coupling
 -> LUCA-compatible organism interface
```

mainstreamのiLUCAモデルが安定しているほど、「どの状態をLUCA到達とみなすか」のinterfaceを定義しやすくなる。

このtrackは将来独立experimentとして再開し、成功しなければmainstream全体を止めない。
