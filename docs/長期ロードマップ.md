# 0. 最上位方針

長期目標は、完成した生物種を設計者が追加するのではなく、

```text
環境物理 + 化学 + 基礎生理 + 遺伝 + 変異 + 個体間相互作用
```

から、LUCA-likeな単細胞を起点として代謝多様化・複雑化・陸上進出・歩行・飛翔まで到達可能な進化空間を段階的に作ることである。

## LUCA再現は目的ではなく出発点の品質管理

**完全な歴史上のLUCA再現を完了条件にしない。**

優先順位:

```text
高信頼の因果構造
> 次の進化圧に重要な生理
> 現生proxyで妥当なorder/scaling
> 細部の歴史的再現度
```

# 1. 開発ペース

原則 **1つの新しいworld-rule軸を1段階ずつ追加**する。

```text
A. mechanism implementation + tests
B. fixed ancestor sanity
C. evolution ONでadaptive accessibility確認
D. 既存主要因子との最小interaction確認
E. working referenceを置いて次へ
```

通常1軸1〜3 experiment。knife-edgeでなければ細かなglobal optimum探索をしない。

# 5. Phase 3 — V1.12 Physical Phototrophy / Energy Strategy Diversification

V1.8由来day/night + light fieldを再利用するが、**旧light arbitrary unitをそのまま使用しない。**

前提:

- light fluxをphysical unit (W/m2またはphoton flux)へ接続
- absorption / conversionをJ/sへ接続
- H2-rich hydrothermal habitatと光が同時に存在できるhabitat geometryを定義

候補:

- shallow hydrothermal / coastal geothermal habitat
- depth/light gradient
- deep H2 habitatとshallow light habitatを空間的に分けるworld

目的:

> H2 chemical-first ancestryから、phototrophを直接置かずにgeneric non-oxygenic phototrophyが創発・維持されるかを見る。

実験候補:

1. innovation OFF control
2. innovation supply arm
3. rare phototroph establishment arm
4. day/night・H2との最小interaction
