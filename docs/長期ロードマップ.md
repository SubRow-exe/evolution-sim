# 0. 最上位方針

長期目標は、完成した生物種を設計者が追加するのではなく、

```text
環境物理 + 化学 + 基礎生理 + 遺伝 + 変異 + 個体間相互作用
```

から、LUCA-like単細胞を起点として代謝多様化・複雑化・陸上進出・歩行・飛翔まで到達可能な進化空間を段階的に作ること。

**歴史上のLUCA完全再現は目的化しない。**

優先順位:

```text
高信頼の因果構造
> 次の進化圧に重要な生理
> 現生proxyで妥当なorder/scaling
> 細部の歴史的再現度
```

Abiogenesis -> LUCAはparallel trackとして維持するがmainstreamをblockしない。
