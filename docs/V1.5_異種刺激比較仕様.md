## 1. V1.5の目的

V1.4で一次Energyの**吸収**は整合したが、行動側では光とchemicalを

```text
score = absorption能力 × raw field value
```

で直接比較している。

光はそのtickのフロー量、chemicalはセル内stockであり、単位と数値範囲が違う。このためraw値の大小だけでどちらに引かれるかが決まり、光+chemical同居世界では比較原理として不適切。

V1.5では、光とchemicalをそれぞれ**0〜1の無次元受容器応答**へ変換してから個体能力を掛け、現在感じる刺激として比較する。

V1.5は「賢い最適行動」を追加するものではない。

> 現在感じる刺激への反射的な走光性・走化性を、異なる種類の刺激でも比較可能にする。

## 2. 絶対原則

導入しないもの:

- 候補セルで将来得られるEnergy量の予測
- 移動コスト込みの将来収益最大化
- 生存確率・繁殖成功率の計算
- 光かchemicalのどちらかへ世界側から固定ボーナスを与えること
- 「種」や行動タイプの固定クラス

維持するもの:

- その瞬間の局所刺激だけを見る
- 個体差は遺伝形質から生じる
- 同じ環境でも個体によって異なる資源へ反応できる
- 想定外の戦略を許容する

## 3. 無次元受容器応答

刺激量`x >= 0`、半飽和定数`K > 0`に対して:

```text
response(x, K) = x / (x + K)
```

とする。

意味:
- x=0 → 0
- x=K → 0.5
- xが増えるほど応答は増える
- 非常に強い刺激では1へ漸近し、raw値が巨大だから無制限に強く感じることを防ぐ

これは単純な飽和型受容器応答の第一近似であり、未来Energy収益ではない。

## 4. V1.5 defaultの受容器スケール

### 光

```text
light_stimulus_half = 1.2
```

現在の標準光場の最大セル光量`light_max=1.2 E/tick/cell`を半飽和点とする。

したがって標準世界の最大光で無次元応答0.5、暗部0.36では約0.23となる。

### chemical

V1.4最終default:

```text
chem_vent_flux = 16 E/tick/vent
chem_loss_frac = 0.10 /tick
vent_radius_cells = 2
```

典型的な完全13セルventで、1セルあたりsourceは約`16/13 = 1.23 E/tick`。

生物不在平衡stockは

```text
(16 / 13) / 0.10 ≈ 12.3 E/cell
```

なので:

```text
chemical_stimulus_half = 12.3
```

をhalf-responseの基準とする。

### Claudeレビュー後の確定判断

Exp08で生物が占有したflux16 ventのstockは、典型的には生物不在平衡より大幅に低い。したがって`K=12.3`では、占有中のchemical responseが小さくなる。

これは認識した上で**12.3を維持する**。

理由:
- 光はflow型で、利用しても次tickに供給される
- chemicalはstock型で、利用するとその場のstockと知覚刺激が同時に低下する
- 利用→刺激低下→離脱→stock回復→再誘引という負のフィードバックは、stock型資源の自然な性質として残す
- V1.5の目的は両Energy源を同じ強さに感じさせることではなく、異なる単位の刺激を有限な共通尺度へ写して比較可能にすること

したがって`chemical_stimulus_half`をExp08の占有時stockへ合わせて引き下げない。

12.3は**典型的な完全13セルventの生物不在平衡を基準にした固定値**である。世界端などでventが欠ければ1セルあたりsource密度が変わるため、vent間のresponse差が出ても直ちに実装バグとは扱わない。

### 重要

`light_stimulus_half` / `chemical_stimulus_half`は**実行中のfield最大値や現在のfluxから毎回再計算しない**。

環境を強くしたときに知覚まで自動的に割り戻すと、環境変化の効果を打ち消してしまうため。

Configに明示的な固定パラメータとして保持する。

## 5. 個体固有の反応性

V1.5では新しい「光好き」「chemical好き」遺伝子はまだ追加しない。

既存の

- `light_absorption`
- `chemical_absorption`

を、利用能力とその資源への実効反応性を結ぶ第一近似として使う。

```text
light_response_score
= light_absorption
× response(light, light_stimulus_half)

chemical_response_score
= chemical_absorption
× response(chemical_stock, chemical_stimulus_half)
```

これにより同じ環境でも:

- light_absorptionが高い個体 → 光へ強く反応しやすい
- chemical_absorptionが高い個体 → chemicalへ強く反応しやすい
- 両方高い個体 → 局所刺激によって選択が変わる

将来、利用能力と感覚選好を独立進化させる必要性が実測から出た場合のみ、走光性/走化性の独立遺伝子を追加検討する。

## 6. 行動実装の最小スコープ

V1.5で全面的な行動モデル再設計はしない。

対象は**light vs chemicalという一次Energy源同士の比較だけ**。

実装方針:

1. 感覚範囲内で最良lightセルを従来どおり探す
2. 感覚範囲内で最良chemicalセルを従来どおり探す
3. 各候補について上記の無次元response scoreを計算
4. light/chemicalの両候補が存在する場合はresponse scoreでどちらを一次Energy候補にするか決める
5. 片方しか存在しない場合はその候補を従来どおり使う
6. nutrient / corpse / predationとの比較原理はV1.5では原則変更しない

これにより、V1.5の因果を「異種一次Energy刺激の比較」に限定する。

### 単独sourceの不変性

`response(x,K)`は単調増加なので、同じsource内で最も強いセルの順位はraw値と変わらない。

ただしテストは順位一致だけでは不足とする。

light-only / chemical-onlyでは、同一Config・同一seedで**`v1.4-final`と決定的に完全一致**することを要求する。

これによりtie処理の誤発火や不要なRNG消費も検出する。

### 他刺激との統合

一次Energy候補をlight/chemicalから無次元比較で1つ選んだ後、nutrient / corpse / predationとの既存比較へ渡す際は、V1.4との不要な差分を最小化する実装を選ぶ。

具体的には、選ばれたEnergy候補については従来のlegacy score（`ability × raw field value`）も保持し、他刺激との比較には原則それを使う。

これは**全刺激が完全な共通尺度になったわけではない**という既知の限界を持つ。

Exp09では、light/chemicalの一次Energy候補がcorpse / predation等に負けた回数をsource別に観測し、この二重尺度の影響を把握する。

V1.5では「全刺激を完全に共通尺度へ変換する」ことまでは行わない。必要性が出れば別の世界バージョンで扱う。

## 7. tie（同点）の扱い

lightとchemicalの無次元response scoreが実質同じ場合、fieldの走査順だけでlight/chemicalのどちらかが常に勝つような隠れbiasを作らない。

実装要件:

- `stimulus_tie_eps`は`1e-9`程度の十分小さい絶対値、または同等に厳しい相対許容差
- 同点時にsource種類を固定優先しない
- 追加の未来予測はしない
- RNG系列への不要な影響を避ける
- 両score=0ならEnergy源による方向付けを行わず、V1.4と同じ挙動へ戻す

推奨:

- tied candidateの一方が現在セルならstay
- どちらも別セルならEnergy源による方向付けを行わず、他刺激がなければ従来のrandom walkへ戻す

このtie処理もExp09でテストする。

## 8. 交差点による診断

ある光量・個体能力で:

```text
light_response_score = chemical_response_score
```

となるchemical stockを**交差点stock**と呼ぶ。

Exp09 Phase 0では、診断表現型と代表光量ごとにこの値を事前計算する。

Phase Aでは各表現型について、刺激条件を交差点の両側へ置き:

- lightを選ぶケース
- chemicalを選ぶケース

の双方を必ず確認する。

Phase Bでも単純なvent滞在率ではなく、その時点のchemical stockが交差点の上/下にあることと実際のsource選択が一致するかを主要判定とする。

stock消費→離脱→回復→再誘引の反復が生じても、この交差点式と整合するなら直ちに異常扱いしない。

## 10. V1.4→V1.5世界境界

行動結果が変わるため世界ルール変更。

Claude Codeは実装前に:

1. `docs/V1.4_総括.md`のdefault判断をコードへ反映
2. `light_uptake_coef=2.0` / `chem_vent_flux=16.0` / `chem_uptake=0.5`をV1.4恒久defaultとして確定
3. V1.4 test / Energy / Matter / RNG / CIを確認
4. **default反映済みのV1.4最終状態を`v1.4-final` branchへ保存**
5. その後V1.5実装
6. V1.5最初の意図的結果変更commitを新しいCI基準refへ設定

Claudeレビューの「Exp08実行時mainをそのままv1.4-finalとし、default変更をV1.5境界へ送る」案は採用しない。

## 11. V1.5ではまだ結論しないこと

- 光とchemicalの進化的優劣
- specialist/generalistの長期進化
- chemical bootstrapが成立するか
- nutrient/corpse/predationを含む全刺激の完全無次元化
- 神経系・学習・記憶

`chem_uptake=0.5`を維持し、chemicalはstock消費で知覚も低下するため、混合世界ではchemicalが光より知覚・収支の両面で弱く見える条件が存在する。

Exp09ではこれを補正せず、事前式から予測可能な結果として扱う。長期混合進化実験では初期条件として明示して解釈する。

V1.5実装の妥当性はExp09で診断し、その後に進化実験へ進む。
