# LUCA-inspired 参照モデル方針

更新: 2026-09-01
状態: **設計原則として採用 / 個別パラメータ・次バージョン仕様は未確定**

## 1. 目的

本プロジェクトは、当面の長期目標として、単純な物理・化学・遺伝ルールから
**地球で実際に起きた生命進化に似た大きな流れが創発しうる世界**を作る。

そのため、祖先個体・基準個体の生物学的な意味を完全な架空生物のままにせず、
今後の世界ルールやパラメータを検討するときの共通の物差しとして
**LUCA（Last Universal Common Ancestor）を参考にした基準生物**を置く。

ただし、これは **LUCAの再現ではない**。

本プロジェクトで使う呼称は以下とする。

> **LUCA-inspired reference organism（LUCAを参考にした参照生物）**

## 2. 「モデル」と「再現」を明確に分ける

LUCAは全現生細胞生命の最終共通祖先を指す概念であり、その形態・代謝・生息環境を
直接観測することはできない。復元結果は系統解析・比較ゲノム・地球化学的証拠に依存し、
研究間・解析手法間で不確実性が残る。

したがって本シミュレーションでは、LUCAについて現在比較的支持される特徴を
**設計上のアンカー**として利用するが、以下は行わない。

- LUCAのゲノム、代謝経路、細胞構造を1対1で再現する
- 特定の研究のLUCA像を唯一の正解として固定する
- 現実のJoule、kg、秒などを、校正なしにシミュレーションの `Energy` / `Matter` / tickへ直結する
- 「LUCAらしさ」を適応度ボーナスとして与える
- 後の進化方向を地球史どおりになるよう直接誘導する

目標は、**初期条件と基礎ルールに現実的な根拠を持たせた上で、その後の進化は
シミュレーション内の自然選択に任せること**である。

## 3. 現在の研究から採用できる大まかなLUCA像

LUCA像には不確実性があるが、少なくとも「極端に単純な無構造の生命前駆体」より、
**原核生物級の複雑さを持つ嫌気性の細胞生物**として扱う方が、近年の復元研究には整合的である。

Moody et al. (2024) は、LUCAを約42億年前に位置づけ、少なくとも約2.5 Mbのゲノムと
約2,600のタンパク質コード遺伝子を持つ、modern prokaryotesに比較可能な
**prokaryote-grade anaerobic acetogen** と推定した。またLUCAは孤立していたのではなく、
すでに存在する微生物生態系の一員だった可能性を示している。

Weiss et al. (2016) の別の復元では、LUCAは嫌気性、CO2固定、H2依存、
Wood–Ljungdahl pathway、Fe-S chemistryと関係し、地球化学的に活発な環境との結びつきが
示唆された。熱水環境・好熱性などの詳細には議論が残るため、これらは固定条件ではなく
候補的な背景仮説として扱う。

このため当面の参照像は、次の程度に留める。

- 単細胞・原核生物級
- 嫌気的な初期地球環境に成立可能
- 外部の化学自由Energyを利用できる化学合成的生活様式を基礎に置ける
- 膜、代謝、修復、遺伝・翻訳など、生命維持に不可欠な基礎機構を持つ
- 完全な孤立個体ではなく、資源循環を伴う生態系の中で存在しうる

これは「最初から光合成を持つ」「熱水噴出口に必ず住む」などを意味しない。
個々の能力の初期値や環境構成は、別途その目的に応じて検証する。

## 4. 今後のパラメータ設計への使い方

LUCA-inspired reference organism は、今後以下のような値を決める際の
**現実世界側の参照点**として使う。

- 基礎代謝・最低維持Energy
- body size と表面積・体積のスケーリング
- Energy / Matter の貯蔵容量
- 膜維持・損傷・修復
- 化学Energy利用
- 温度・熱損失を将来導入するときの基準
- 繁殖コストや世代時間を解釈するときの基準

ただし、シミュレーションの `Energy` と `Matter` は現時点でSI単位へ校正されていない。
したがって現実の生物から借りる優先順位は、原則として

1. **構造・因果関係**（何にコストが掛かるか）
2. **スケーリング則**（サイズに対してどう増減するか）
3. **比率・オーダー**（維持費が総代謝のどの程度か等）
4. 絶対値

の順とする。絶対値を直接移植するのは、単位系を明示的に校正した場合に限る。

例えば微生物には、増殖に使われない生命維持のための maintenance metabolism / basal power
requirement が存在し、極端な低Energy条件でも生命を維持するための最低限のpowerが議論されている。
この種の知見は「サイズを小さくすれば生命維持コストが無限にゼロへ近づく」と仮定してよいかを
検討する根拠にはなるが、具体的なシミュレーション値は別の事前検討・実験で決める。

## 5. 現行シミュレーションとの関係

この文書は**設計上の参照方針だけを決める**。

- 現行の `INITIAL_GENOME`、`body_size`、代謝式、Energy/Matter単位を変更しない
- V1.6 / Exp10 の結果を変更・再解釈しない
- 次バージョンの仕様をここでは決めない
- 次実験の条件・候補値・停止条件をここでは事前登録しない

今後、新しい物理・生理ルールを追加するときに、まず「LUCA-inspiredな基準生物として
どの程度の根拠を置けるか」を確認し、そのうえでシミュレーション内の整合性と
創発性を損なわない最小限の実装を選ぶ。

## 7. 要約

> 地球生命進化を参考にするため、今後の祖先・基準生物はLUCAそのものではなく
> **LUCA-inspired reference organism** として解釈する。
> 現実からは主に構造、スケーリング、比率を借り、進化結果そのものは指定しない。
> LUCA復元の不確実性を残したまま、世界ルールへ現実的な根拠を与えるための参照モデルとする。
