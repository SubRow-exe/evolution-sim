# 環境因子追加・校正方針

更新: 2026-09-04
状態: **プロジェクト全体の恒久方針**

この文書は今後の環境因子追加・parameter校正・実験設計に共通して適用する。
目的は個別experimentの最適化ではなく、LUCA-inspired祖先から多様な生物戦略・陸上移動・飛翔まで創発可能な世界を段階的に構築すること。

---

# 1. 最上位原則

```text
自然に妥当な環境・基礎生理
> 長期進化が継続できる
> 複数戦略が競合できる余地
> robustな成立域
> 数値の細かな最適性
```

**生物を生かすために環境を都合よく曲げない。**

新環境で祖先が崩壊した場合、環境parameterを調整する前に必ず:

> その環境が要求する応答を、生物側が現在または進化によって原理的に実現できるか

を確認する。

必要な応答レバーが生物モデルに存在しない場合は、まず基礎生理・遺伝構造の欠落を疑う。

---

# 2. 長期目標

今後の環境候補:

- 昼夜 / 光
- 気温
- 重力
- 水深 / 水圧
- 酸素
- pH
- 放射線
- 毒物
- その他の化学・地質環境

少数因子だけの段階で厳密なglobal optimumへ合わせても、後続環境追加で再調整が必要になる。

したがって各versionで求めるのは自然界の唯一値ではなく、次へ進めるworking reference / 実用域である。

---

# 3. 校正の基本原則

## 3.1 真の最適値を通常は探さない

必要以上の細かなthreshold探索・局所最適化・長大なparameter sweepを行わない。

## 3.2 原因分離と最適化を分ける

複数機構で問題が起きた場合はまずON/OFF等で:

- 何が効いているか
- 単独でどう働くか
- 相互作用があるか

を確認する。

原因診断をそのままparameter最適化へ拡張しない。

## 3.3 fixed ancestorとevolution ONを分ける

今後の成立確認は可能な限り:

```text
A. fixed ancestor
   -> baseline / mechanism sanity

B. evolution ON
   -> adaptive rescue / selection pressure / evolutionary accessibility
```

を分離する。

固定祖先が崩壊しても、evolution ONで適応し安定化するなら、それは環境失敗ではなく「適応を要求する環境」であり得る。

逆に、必要な応答が遺伝的に不可能なら、長期runを増やしても進化では解けない。

## 3.4 予測と恒常性を区別する

禁止するのは未来情報を使う特別扱い。

```text
NG: あと20 tickで夜だからEnergyを貯める
OK: 現在のEnergyが低いので活動を抑える
```

現在の内部状態へ反応するhomeostasisは、生物側の自然な基礎生理として扱える。

---

# 4. working referenceの最低条件

新規環境因子・生理機構では少なくとも:

1. 数値実装・保存則・決定性が正しい
2. baselineが意図した機構を実際に持つ
3. fixed祖先での挙動が説明可能
4. evolution ONで必要な形質が実際に変異・選択可能
5. 新機構が観測可能な選択圧を作る
6. その1因子だけが全てを決めるほど過度に支配的でない
7. 極端な一点だけのknife-edgeでない

ことを確認する。

「fixed祖先が必ず長期生存する」は絶対条件ではない。

---

# 5. 新環境因子追加の標準手順

```text
1. 自然性・因果構造を定義
2. 生物側に応答可能な生理/遺伝レバーがあるか確認
3. 単独機構として導入
4. fixed baselineでmechanism sanity
5. evolution ONでadaptive accessibility確認
6. 即死/無影響の両極端を避ける粗い成立域を探す
7. working referenceを暫定採用
8. 既存因子との最小限interaction確認
9. 次の環境因子へ進む
10. 多因子化後に全体balance再調整
```

---

# 6. 精密校正を行う場合

以下の場合だけ通常より深く調べる。

- 成立域が極端に狭い
- 一因子が他の進化圧を消す
- 後続機構を検証できない
- 数値/物理モデル妥当性に境界値が必要
- version final acceptanceに必要
- 長期目標への明確なbottleneck

---

# 7. V1.8から得た教訓

V1.8ではday/nightでlight-dependent fixed phenotypeが崩壊した。
当初はnight length / light_max / energy capacity等の環境・world parameter調整へ進みかけた。

しかし後に、現行iLUCAには:

- Energy状態依存の活動調節がない
- storage容量が遺伝形質でない
- reproduction thresholdが遺伝形質でない

ことが確認された。

したがって環境を生存側へ寄せる前に祖先モデルを再設計する方針へ転換し、V1.8を閉じた。

詳細: `docs/V1.8_総括.md`

---

# 8. Versionとの関係

同じ数式・同じ世界ルール内のworking parameter調整は同version内で行える。

一方:

- 新環境因子
- 新生理機構
- 新遺伝子
- 保存則/相互作用変更

は新しいworld versionとして扱う。

V1.9ではiLUCAのhomeostasis / reserve / reproduction strategy / chemical substrate conversionを世界ルールとして再設計する。

---

# 9. 将来の再調整

現在のworking referenceは将来の温度・酸素・pH・圧力等追加後に再評価してよい。

「今の少数環境で最も美しい値」へ過剰適合させず、自然な機構・進化可能性・robustnessを優先する。
