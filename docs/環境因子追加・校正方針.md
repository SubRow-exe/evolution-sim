# 環境因子追加・校正方針

更新: 2026-09-04
状態: **プロジェクト全体の恒久方針**

この文書は、今後の環境因子追加・parameter校正・実験設計に共通して適用する。
個別experimentの最適化より、LUCA-inspiredな祖先から多様な生物戦略・陸上移動・飛翔まで進化可能な世界を段階的に構築することを優先する。

---

# 1. 長期目標

本プロジェクトの目的は、現在のiLUCA（LUCA-inspired）を出発点として、環境と生物側の形質を段階的に増やしながら、最終的に:

- 多様な一次Energy戦略
- 水中での適応
- 陸上への進出
- 歩行などの移動様式
- 飛翔

まで創発的に到達し得る進化シミュレーションを作ること。

今後の環境候補には少なくとも:

- 昼夜 / 光
- 気温変化
- 重力
- 水深 / 水圧
- 酸素
- pH
- 放射線量
- 毒物
- その他の化学・地質環境

がある。

したがって、初期段階の少数環境因子だけを前提にparameterを極端に精密校正しても、後続環境を追加した時点で再調整が必要になる可能性が高い。

---

# 2. 校正の基本原則

## 2.1 各段階で「真の最適値」を探さない

各version / experimentで求めるのは、自然界の普遍定数や唯一の最適値ではなく、次の開発段階へ進める**working reference / 実用域**である。

必要以上の細かいthreshold探索・局所最適化・長大なparameter sweepは原則行わない。

## 2.2 最低限必要な成立条件を満たせば先へ進む

新規環境因子や新規生理機構は、少なくとも以下を確認する。

1. iLUCA集団が即座に必然的絶滅しない
2. 複数世代の世代交代が成立する
3. 新機構が観測可能な選択圧・生態差を作る
4. ただしその1因子だけでほぼ全個体の生死が決まるほど支配的ではない
5. 極端に狭い一点だけで成立するknife-edgeではなく、ある程度のparameter幅で挙動が成立する
6. Matter / Energy / RNG / 決定性など既存のHARD RULEを壊さない

これを満たす代表点を暫定採用し、先へ進む。

## 2.3 原因の切り分けと最適化を分ける

複数の新機構を同時導入して問題が起きた場合は、まず各機構をON/OFFして寄与を切り分ける。

目的は:

- 何が壊しているか
- 単独では成立するか
- 組み合わせで相互作用があるか

を知ること。

原因が判明した後は、必要最低限の粗調整でworking referenceを決める。
原因切り分けexperimentを、そのまま精密な最適値探索へ拡張しない。

---

# 3. 新しい環境因子を追加するときの標準手順

```text
1. 単独機構として導入
2. 既存baselineに対する寄与を切り分け
3. 即死/無影響の両極端を避ける粗い成立域を探索
4. working referenceを暫定採用
5. 既存環境因子との最小限のinteraction確認
6. 次の環境因子へ進む
7. 多数の環境因子が揃った段階で全体balanceを再調整
```

新しい環境因子ごとに、毎回完全なglobal optimumを求めない。

---

# 4. 精密校正を行うべき場合

以下の場合は、通常より深い校正を行ってよい。

- 成立域が極端に狭く、少しの変化で必ず崩壊する
- 1因子が他の進化圧をほぼ消してしまう
- 後続機構の検証ができないほど挙動が不安定
- 数値・物理モデルそのものの妥当性判断にparameter境界が必要
- version final acceptance前の全体balance確認
- 長期目標へ進むために明確なbottleneckになっている

それ以外では、開発速度と将来の再調整余地を優先する。

# 5. V1.8への適用

V1.8ではday/nightと一次Energy density responseを同時導入したため、Exp14で両者を含む条件が崩壊した。

次の診断ではまず:

```text
cycle OFF / density OFF
cycle OFF / density ON
cycle ON  / density OFF
cycle ON  / density ON
```

を比較して寄与を切り分ける。

その後は、昼夜とdensity responseについて唯一の厳密最適値を探索するのではなく、V1.8として:

- 継続世代交代できる
- 両機構が意味のある圧として働く
- どちらか一方が過度に支配しない
- 後続のchemical / mixed evolution検証へ進める

範囲のworking referenceを選ぶ。

---

# 6. Versionとの関係

parameter校正と世界ルール変更を区別する。

現在のversionで事前に導入済みの同一数式・同一機構について、working parameterを決めるための調整は、そのversionのfinalization作業として扱う。

一方で:

- 新しい環境因子そのものを追加する
- 数式・相互作用・保存則など世界ルールを変更する
- 新形質や新生理機構を追加する

場合は`docs/バージョニング方針.md`に従って新しい世界versionを検討する。

V1.8では、day/nightとdensity responseのworking reference決定まではV1.8内で行う。
V1.9は現ロードマップ上、chemical-first ancestorからphototrophy創発を扱う段階であり、V1.8校正の途中で前倒ししない。

---

# 7. 判断時の優先順位

parameter選定時は次を優先する。

```text
機構として正しい
> 長期進化が継続できる
> 複数戦略が競合できる余地
> robustな成立域
> 数値の細かな最適性
```

「現時点の少数環境だけで最もきれいな結果になる値」へ過度に合わせない。

将来の環境追加によって再調整することを前提とする。
