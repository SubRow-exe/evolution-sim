# 0. 先に自己訂正

前回チャットで私は

> vent の H2 濃度を 10 mM から 100–300 µM へ下げれば、枯渇と競争が復活する

と述べた。**これは誤りである。** 検算して確認した。

低濃度域（`C << K`）では:

```text
消費 ∝ N · q_max · m_dry · C / K
供給 ∝ λ · V_vent · C
```

で、**両辺に C が入るため約分される。**

```text
消費/供給 = N · q_max · m_dry / (K · λ · V_vent)
```

実際に vent 濃度だけを振ると比はほぼ動かない。

| vent 濃度 | H(C,K) | 消費/供給 |
|---|---|---|
| 10,000 µM | 0.943 | 2.03e-04 |
| 300 µM | 0.333 | 2.39e-03 |
| 200 µM | 0.250 | 2.69e-03 |
| 100 µM | 0.143 | 3.08e-03 |

濃度を100倍下げても、枯渇には**15倍しか近づかない**（しかもそのほとんどは飽和が外れた効果で、桁は変わらない）。

濃度が実際に効くのは **H(C,K) の飽和**（走化性の勾配が知覚できるか / density response が定数化しないか）のほうだけであり、**枯渇・競争の成否は濃度ではなく `N·q_max·m_dry / (K·λ·V_vent)` が決める。**

私の前回の因果は間違っていた。以下 §2 M-2 に正しい分析を置く。

# 1. 総評

方針転換そのものは**正しい**。

「生存する値を探すのではなく、現実のオーダーから供給・取得・支出を置き、結果として収支がどうなるかを見る」（方針書 §1）は、V1.7〜V1.8 で繰り返し発生した「パラメータを触って生存させる」ループを構造的に断つ唯一の方法である。PR #67 を機構実装 checkpoint として保持し、physical scaling patch を重ねてから V1.9 final 判定する運びも妥当。

一方で、SI 単位で実際にチェーンを閉じてみると、**方針書が並べているアンカーは相互に整合していない**。

アンカーは全部で 3 系統ある。

```text
(a) q_H2_max ≈ 50 mmol/(gDW h)          … 取り込み能力
(b) ATP yield ≈ 0.3 mol ATP/mol acetate … エネルギー変換
(c) doubling time ≈ 6 h (µ=0.112 /h)    … 増殖速度
```

**この3つは同時には成立しない。** (a)+(b) から増殖速度を導くと 18.5 h になり、(c) の 6.2 h と 2.99 倍ずれる。

さらに、SI で閉じた結果として次が判明した。

```text
維持代謝 0.45 fW/cell      … 文献オーダーと一致 (良い)
usable   3.75 kJ/mol H2    … ΔG°' の 15.8%
損益分岐 19.2 µM / 飽和 600 µM
dx >= 0.447 mm  (dt=10 s, 陽解法)
遊泳 25 µm/s -> 1日で world を横断
遊泳の物理仕事 = 維持代謝の 1.6%
消費/供給 = 1e-4 〜 1e-3
```

つまり **PR #67 の「餓死する」問題は単位ミスマッチだけではない。** 単位を正しく閉じた先に、
「生存はできるが、資源が枯渇せず、競争が起きず、空間構造も残らない」
という**別の失敗モード**が待っている。Exp15 を dispatch する前にここを潰す必要がある。

分類:

```text
MUST FIX   5件   physical scaling patch 実装前に決着が必要
SHOULD FIX 6件   Exp15 formal 前に決着が望ましい
OPTIONAL   4件   将来改善
```

# 2. MUST FIX

## M-1. 3つのアンカーが相互に矛盾している（µ が 2.99× ずれる）

方針書 §2.5 / §3.3 / §4 のアンカーから素直に増殖速度を導く。

```text
q_H2_max      = 50 mmol/(gDW h)
ATP/H2        = 0.3 / 4 = 0.075 mol ATP / mol H2
Y_ATP         = 10 gDW/mol ATP  (古典値。方針書には未記載)

mu = 50e-3 * 0.075 * 10 = 0.0375 /h  ->  倍加 18.5 h
```

方針書の引用値は `µ = 0.112 /h`（倍加 6.2 h）。**2.99 倍の乖離。**

逆算すると、µ=0.112/h を出すには `q_H2 ≈ 149 mmol/(gDW h)` が必要で、これはアンカー (a) の 3 倍である。

原因の候補:

1. `Y_ATP` を方針書が明示していない。10 gDW/mol ATP は好気系寄りの古典値で、acetogen のような低エネルギー生物では 2〜6 の報告もある。ここを下げるとむしろ乖離は**拡大**する（倍加がさらに長くなる）。
2. `q_H2_max ≈ 50 mmol/(gDW h)` の導出（85 mmol/L/h ÷ 1.71 gDW/L = 49.7）は**平均バイオマスでの平均取り込み**であり、指数増殖期のピーク比速度ではない可能性が高い。ピーク値は通常これより大きい。
3. **引用元の問題**: 方針書 §10 が µ=0.112/h の出典として挙げている PMCID: PMC4551271 は **"CO Metabolism in the Acetogen Acetobacterium woodii"**、すなわち CO 代謝の論文である。H2+CO2 独立栄養条件の比増殖速度としてそのまま採るのは危うい。A. woodii の H2+CO2 倍加時間は条件（pH、Na+、CO2 分圧、バッチ/連続）で大きく変わる。

**変更提案**:

> 3つのアンカーのうち**2つだけを独立に固定し、3つ目は導出値として観測する**。

推奨は **(a) uptake と (b) ATP yield を固定し、(c) doubling time は導出値**。理由:

- (a)(b) は「生理の能力」であり、機構としてコードに直接入る量。
- (c) は「その能力と環境が与える結果」であり、方針書 §7 S3 自身が「6h を強制するのではなく、結果として 4–8h 程度になるか sanity 確認する」と書いている。**(c) を固定すると、その方針書自身のルールに反する。**

そして 18.5 h が出た事実は隠さず記録する。「アンカー (a)(b) からは 18.5 h が出る。文献の 6.2 h との差は Y_ATP と q_max ピーク値の不確かさ 3 倍以内であり、sanity anchor 4–8 h の外側だが同一オーダーである」という形で正直に書けばよい。**18.5 h を 6 h に合わせるために q_max を 3 倍する操作は、まさに方針書が禁じた「生存する値を探す」行為である。**

必須の追加作業:

- `Y_ATP` を方針書へ明示的に書く（未記載のまま導出できない）
- µ=0.112/h の出典を H2+CO2 条件の論文へ差し替えるか、CO 代謝論文由来であることを明記する

## M-2. 枯渇も競争も起きない（消費/供給 = 1e-4〜1e-3）

これが**最も重大**である。

dx=0.5 mm / depth=0.5 mm / vent 4個 × 13 cell / H2 滞留時定数 3600 s / N=1000 個体で計算すると:

```text
vent 10 mM :  消費/供給 = 2.03e-04
vent 200 µM:  消費/供給 = 2.69e-03
```

**生物は H2 を 0.02〜0.3% しか消費しない。** この世界では:

- H2 は枯渇しない
- 個体間で資源競争が起きない
- vent 周辺の H2 が減らないので、集まっても不利にならない
- density response も fair sharing も実質的に無効

つまり **Exp15 Phase A/B/C の科学的問い（「自然な環境圧へ生理・進化で応答するか」）に対して、そもそも環境圧が存在しない。**

§0 に書いたとおり、**濃度を下げてもこれは直らない**。比は

```text
消費/供給 = N · q_max · m_dry / (K · λ · V_vent)
```

で決まり、C は約分される。効くのは分子の `N · m_dry`（総バイオマス）と分母の `λ · V_vent`（供給の総量）だけである。

必要な総バイオマス:

| vent 濃度 | 現在の総 biomass | 枯渇成立に必要 | 不足倍率 |
|---|---|---|---|
| 10 mM | 0.00028 µgDW | 1.38 µgDW | 4921× |
| 200 µM | 0.00028 µgDW | 0.104 µgDW | 371× |

**変更提案**（優先順）:

### 提案 A（推奨）: 1 agent = 細胞集合体として意味を変える

```text
cells_per_agent = 1e3 〜 1e4   (S1 で確定)
dry_mass_agent  = cells_per_agent * 0.28 pg
```

- 新機構ではなく、**Matter/Energy 台帳へ線形に入る単なるスケール係数**である。保存則・決定性・遺伝子構造に一切影響しない。
- 「1 agent = 1 細胞」を捨てることになるが、**現在のモデルは元々そうではない**。40×40 grid・N=1000 で実細胞をシミュレートしているという解釈は最初から成立していない（dx=0.5 mm のセルに 1 細胞では 5000 cells/mL）。むしろ agent を「局所コロニー / マイクロコロニー」と明示するほうが、現行の空間解像度と整合する。
- `body_size` 遺伝子は「コロニー内の1細胞サイズ」ではなく「agent の総 dry mass」を指すことになる。S1/S3 でこの対応を明記する必要がある。

### 提案 B: H2 の滞留時間 λ を長くする

背景海洋の H2 損失を遅くする（τ を 1 h → 100 h 等）。物理的には、閉じた/循環の遅い水塊を仮定することになる。ただし τ を 371 倍にすると、拡散と合わせて H2 が世界全体へ均一に広がる時間（§M-3 参照: 24 h で 83 cell）よりはるかに長くなり、**空間勾配は消えたまま濃度だけが上がる**。単独では推奨しない。

### 提案 C: vent 数/面積を減らす

`V_vent` を減らす。4 vent × 13 cell = 52 cell（world の 3.25%）を 1 vent × 5 cell 等へ。ただし 371〜4921 倍は面積削減では届かない（最大でも 52 倍）。**A の補助としてのみ有効。**

**私の推奨は A を主、C を補助。** A だけで 371–4921 倍を吸収できる（`cells_per_agent = 1e3` で 371 倍条件はほぼ達成、`1e4` で 10 mM 条件も達成）。

## M-3. 格子長 dx が拡散安定条件で決まってしまう / 世界が 2 cm になる

`dt=10 s`、`D_H2=5e-9 m²/s`、2D 陽解法の安定条件 `D·dt/dx² ≤ 0.25` から:

```text
dx >= sqrt(4 * D * dt) = 0.447 mm
```

40×40 grid を維持するなら（dx=0.5 mm を採ると）:

```text
world      = 2.0 cm × 2.0 cm
depth      = 0.5 mm
volume     = 0.200 mL
N=1000     -> 5,000 cells/mL   (深海 ~1e4 /mL と同オーダー)
```

数値としては閉じるし、個体密度も妥当なオーダーになる。**ただし帰結が重い。**

分子拡散の到達距離:

```text
 1 h : 8.5 mm = 17.0 cell
24 h : 41.6 mm = 83.1 cell   (world 40 cell を超える)
```

**1日で H2 は世界全体に拡散し、空間勾配が消える。** vent からの距離バンド別の population/uptake（Exp15 Phase A の主要観測項目）は、初期の数時間しか意味を持たない。

また「熱水噴出孔まわりの生態系」という物語と、2 cm 四方・0.2 mL・厚さ 0.5 mm という実体は一致しない。これは vent field ではなく **vent 表面のごく狭い微小生息域**である。

**変更提案**:

1. **世界の位置づけを明文化する。** 「2 cm 四方の chimney 表面近傍の微小生息域」と書けば整合する。「熱水噴出孔生態系」と書くと読者を誤解させる。
2. **grid 40×40 を固定した前提を外すことを検討する。** dx=2 mm / 40 grid（world 8 cm）にすると 24 h 到達が 21 cell となり、勾配が世界内で維持される。dx=2 mm でも `D·dt/dx² = 0.0125` で安定。ただし voxel 体積が 64 倍になり M-2 の消費/供給比がさらに 64 倍悪化するため、**M-2 の提案 A と必ずセットで決める**。
3. **拡散を陽解法のまま使うかを決める。** 陰解法/ADI にすれば dx と dt が分離でき、S5 の dt 収束テストが可能になる（M-4 参照）。

**S2 は S5・M-2 と独立には決められない。** この3つは同時に決める必要がある。

## M-4. dt = 5/10/20 s の収束テストが、現在の設計では実行できない

Exp15 Phase 0 / 方針書 §7 S5 は `dt = 5/10/20 s` の比較を要求している。しかし dx を 0.5 mm に固定すると:

```text
dx=0.5 mm での上限 dt = 0.25 * dx^2 / D = 12.5 s

dt =  5 s -> D*dt/dx^2 = 0.100  OK
dt = 10 s -> D*dt/dx^2 = 0.200  OK
dt = 20 s -> D*dt/dx^2 = 0.400  *** 不安定 ***
```

**dt=20 s は陽解法拡散が発散する。** dt を変えるたびに dx も変えると、比較しているのが「時間刻みの影響」なのか「空間解像度と世界サイズの影響」なのか分離できない。

**変更提案**（いずれか）:

- (i) **拡散を半陰解法/ADI にする。** dx と dt が分離でき、`dt=5/10/20 s` を同一世界で比較できる。実装コストは中程度だが、S5 を本来の意味で実行できるのはこれだけである。
- (ii) **dt sweep の範囲を安定域内へ変更する** (`dt = 2.5 / 5 / 10 s`)。方針書の「10 s は physics ではなく standard numerical timestep」という位置づけと整合し、実装コストはゼロ。
- (iii) **拡散だけサブサイクルする**（1 生物 step 内で拡散を n 回回す）。物理的に正しく、実装も軽い。ただし決定性テストの step 数定義に注意。

**推奨は (ii) を Exp15 用の当面解、(iii) を実装上の恒久解。** (i) は将来 dx を大きく取りたくなったときに検討。

いずれにせよ **方針書 §7 S5 の `dt = 5/10/20 s` は現状の dx では実行不能なので、記述を修正する必要がある。**

## M-5. 遊泳速度が世界サイズを1日で超える

```text
遊泳 25 µm/s, dt=10 s -> 1 step 250 µm = 0.50 cell
1日 (8,640 step) の RMS 変位 = 46.5 cell   (world 40 cell)
```

ランダムウォークの RMS 変位だけで world を横断する。走化性でバイアスが掛かればさらに速い。**vent からの距離という空間構造が、1日で完全に混ざる。**

これは M-3（H2 が 1日で拡散し切る）と同じ結論に別経路から到達している。**現在の「dt=10 s / 40 grid / dx≈0.5 mm / 細菌の実遊泳速度」という組み合わせでは、空間生態が成立しない。**

**変更提案**:

- M-3 の提案 2（world を 8 cm へ広げる）を採れば RMS は 11.6 cell/day となり、空間構造が保たれる。
- または `speed_coef` を下げる。ただしこれは「現実オーダーを置く」という方針に反するので、下げるなら理由（表面への付着傾向、biofilm 化、コロニーとしての低移動性）を明記すべき。**M-2 提案 A で agent をコロニーと定義するなら、コロニーの移動速度が単細胞より遅いのはむしろ自然であり、両者は整合する。**

**S2 と S4 は独立に決められない。** M-3 と同じ結論。

# 3. SHOULD FIX

## S-1. 生存可能な濃度窓が vent reference より 2 桁下にある

```text
損益分岐濃度 : 19.2 µM   (これ以下では維持費を払えない)
飽和開始     : 600 µM
vent reference : 10,000 µM
```

`19.2 µM` は「max uptake power / maintenance = 32.3 倍」から出る。つまりこの生物は **vent 濃度の 1/500 でも生きられる。**

結果として、世界のどこにいても余裕で黒字になり、**vent へ寄る選択圧が生まれない**。Exp15 Phase A の「uniform random spawn から H2 halo / vent 周辺へ空間分布が形成されるか」は、この設定では否定的に出る（形成されない）。

これは M-2 と同根だが、独立の対策がある: **maintenance に対する余剰 32.3 倍が大きすぎる**。実際の貧栄養細菌は余剰がずっと小さい。q_max を下げるか、maintenance にコロニー由来の追加コスト（M-2 提案 A を採るなら storage upkeep / structural maintenance が細胞数に比例）を入れれば、損益分岐が上がって選択圧の窓が世界内に入る。

**変更提案**: physical scaling patch 後に、**「損益分岐濃度が world 内の実現濃度分布の中に入っているか」を Phase 0 の sanity 項目へ追加する。** 入っていなければ環境圧が存在しない。

## S-2. `memory_tau = 20 s` は dt=10 s に対して 2 step しかない

```text
memory_tau=20 s, dt=10 s -> 2.0 step/τ, EMA α = 0.393
V1.6 の実装             ->              α = 0.095
```

V1.6 の temporal biased random walk は α=0.095（≈10 tick）で調整されている。α=0.393 では記憶がほぼ 2 step で失われ、**走化性の挙動が V1.6 と質的に変わる**。しかも α は dt に依存するので、M-4 の dt sweep で走化性の性質自体が変わってしまう。

**変更提案**:

1. `memory_tau_seconds` を V1.6 相当の応答へ合わせるなら **50 s 程度**（α=0.181）以上。V1.6 の α=0.095 を厳密に再現するなら約 100 s。
2. いずれにせよ **α は `1 - exp(-dt/tau)` で毎 step 計算し、定数としてハードコードしない。** これで dt を変えても走化性の時定数が保存される（M-4 の前提条件）。
3. 20 s を採るなら「V1.6 より短い記憶を意図的に選んだ」ことを方針書へ明記する。現状は V1.6 からの変更であることが読み取れない。

## S-3. `q_H2_specific = min(k·C, q_max)` の折れ点

方針書 §3.3 の候補式は `min()` を使っている。これは C = q_max/k で微分不連続になり、

- dt 収束性が悪化する（M-4 のテストにノイズが乗る）
- 折れ点付近の個体で挙動が離散的に変わる

**変更提案**: Michaelis–Menten `q = q_max · C/(C+K)` を使う。`K = q_max/k` と置けば `C << K` で同じ一次挙動になり、上限も同じ `q_max` に漸近し、しかも全域で滑らか。文献の「600 µM まで一次」という報告とも矛盾しない（K を十分大きく取れば 600 µM まで概ね一次）。

**併せて用語の曖昧さを解消する必要がある**: 方針書は「450–600 µM まで飽和を示さない」と書いているが、これは **半飽和定数 K が 600 µM という意味ではない**。一次が 600 µM まで保たれるなら K は 600 µM より**かなり大きい**（K ≥ 3000 µM 程度）。私の検算スクリプトは保守側に倒して K=600 µM を使ったが、方針書はこの2つを区別して書くべきである。

## S-4. movement power は Stokes から置ける（そして支配しない）

方針書 §7 S4 は「現行 movement cost が total Energy budget を不自然に支配しないことを確認する」と書いている。SI で置けば確認できる。

```text
等価半径 0.62 µm, v = 25 µm/s
Stokes drag power = 6πηrv² = 7.31 aW
                  = maintenance (0.45 fW) の 1.62%
```

実測でも大腸菌の鞭毛モーターはエネルギー収支の約 1% 程度である。**よく一致している。**

**変更提案**: movement を「maintenance と同オーダーの独立コスト」として積み上げない。Stokes 由来の物理仕事（維持代謝の 1〜2%）＋モーター効率損失（1桁程度の割増）で置けば、実測オーダーに収まる。現行の `move_cost · M · v² / MOVE_EFF`（`evosim/physiology.py:59`）はこのオーダーへ校正し直すべき。

なお現行実装では wander 速度における移動コストが**サイズ非依存**になっていることを以前指摘した（`v ∝ 1/√M` が入るため M が約分される）。physical 化のタイミングで同時に整理するとよい。

## S-5. maintenance の内訳をどう切るか（方針書 Q6 への回答）

**変更提案**:

```text
total basal maintenance = 0.116 mmol ATP/(gDW h)  … ここに含める
    膜ポテンシャル維持
    タンパク質ターンオーバー
    センシング機構の維持
    storage capacity の upkeep

別 power として足す
    movement    … Stokes ベース (basal の 1〜2% オーダー)
    repair      … damage 駆動なので基礎代謝ではない
    growth      … Y_ATP 経由で biomass 合成へ（growth-associated、basal と分離）
```

理由: 文献の maintenance coefficient は「増殖に使われない全 ATP 消費」の**総和**として測定されている。個別機能を独立の arbitrary コストとして足し上げると、必ず二重計上になる。方針書 §5 の懸念（「movement/repair/sensing/membrane/storage upkeep を全て独立 arbitrary E/tick で足し上げない」）は正しく、上記の切り方がその実装形である。

`storage_capacity` の upkeep を basal に含めるのは重要。V1.9 の設計意図（storage にコストがある）は、**basal maintenance が dry mass ではなく「dry mass + storage 構造」に比例する**形で表現できる。独立の新コスト項を作る必要はない。

## S-6. Exp15 Phase A の判定基準が physical scaling 後に更新されていない

Exp15 計画 §5.4 は「A が安定 / 脆弱 / 即時 collapse」で分岐する。しかし M-2 が示すとおり、physical scaling 後の最も可能性の高い結果は **「A は安定だが、資源が枯渇せず選択圧が無いので Phase B で何も進化しない」** である。これは現在の分岐に無い。

**変更提案**: Phase A の判定へ「環境圧が存在するか」を明示的に追加する。

```text
[ ] realized H2 消費/供給 比 >= 0.1        (枯渇・競争が成立)
[ ] 損益分岐濃度が実現濃度分布の内側にある  (選択圧の窓が存在)
[ ] vent 距離バンド間で population 密度に有意差がある
```

これらが満たされない場合、Phase A は「PASS だが Phase B は無意味」であり、**Phase B へ進む前に環境設計へ戻る**という分岐を用意しておくべきである。結果が出てから判定基準を足すのは絶対原則13違反になる。**今のうちに書いておく。**

# 5. 方針書 §9 の質問への直接回答

## Q1. `dt=10 s` と秒単位 Config の設計は妥当か

**方向は妥当。ただし dt 単独では決められない。**

秒単位で意味を持たせる（gene の horizon、light cycle、memory_tau）のは正しく、これは dt から独立に定義されるべき値である。実装上は「秒で定義された量を毎 step dt から離散化する」形にする（S-2 の α 計算がその例）。

しかし `dt=10 s` は拡散安定条件を通じて dx を（したがって world サイズを）縛る（M-3）。**dt は S2 と同時にしか決められない。** また現在の dx 案では dt=20 s が不安定なので、S5 の記述と両立しない（M-4）。

## Q2. H2 uptake を first-order + upper cap へ変えるのは妥当か

**方向は妥当。式は Michaelis–Menten を推奨。**

first-order + cap は文献報告（低濃度で一次）と整合するが、`min()` の折れ点が数値的に不利（S-3）。MM なら低濃度で同じ一次挙動、高濃度で同じ上限、全域で滑らか。

加えて「一次が保たれる上端 600 µM」と「半飽和定数 K」を方針書が混同しないよう書き分けること。

## Q3. usable Energy [J/mol H2] をどう置くのが最小かつ自然か

**ΔG に効率係数を掛ける形にせず、ATP を経由する。**

```text
4 H2 -> 1 acetate,  ATP yield 0.3 mol ATP/mol acetate
-> 0.075 mol ATP / mol H2
-> ΔG_ATP(細胞内, -50 kJ/mol) を掛ける
-> usable = 3.75 kJ/mol H2
```

これは ΔG°' の 23.75 kJ/mol H2 に対して **15.8%**。旧 `h2_conversion_eff = 0.60` とは 4 倍近く違う。

この置き方の利点は、`h2_conversion_eff` という**自由に調整できる無次元パラメータを消せる**こと。効率は ATP 収量と ΔG_ATP から決まり、どちらも文献値である。方針書が「生存する値を探さない」と言っている以上、調整可能パラメータは1つでも減らすべきである。

なお ΔG_ATP は標準値 −30.5 kJ/mol ではなく細胞内実効値 −50 kJ/mol を使うのが妥当（細胞内の ATP/ADP 比が標準状態から大きくずれているため）。ここは方針書へ明記が必要。

## Q4. iLUCA reference cell size / dry mass として何を採るのが妥当か

**細胞としては 1 µm³ / dry density 280 g/L → 0.28 pg が妥当。**

これで maintenance が 0.45 fW/cell となり、Kempes et al. 2017 の 1 µm³ 級細菌 maintenance（1e-16 〜 1e-15 W）と一致する。**独立の文献と一致したのはこのアンカーだけ**であり、信頼度は高い。

**ただし S1 で同時に決めるべきことがある**: 1 agent = 1 cell なのか、1 agent = コロニー（O(1e3) cells）なのか。M-2 の分析から、**後者でないと生態が成立しない**。S1 の記述を「reference cell dry mass」だけでなく「cells per agent」まで含めるべきである。

## Q5. 40×40 grid を維持する場合の cell physical length / effective depth

**dt=10 s・陽解法なら `dx ≥ 0.447 mm` が HARD 制約。**

```text
dx    = 0.5 mm   (安定条件を満たす最小に近い値)
world = 2.0 cm
depth = 0.5 mm   (立方体 voxel が最も素直)
volume= 0.200 mL
```

これで N=1000 → 5,000 cells/mL となり深海の細胞密度と同オーダー。数値は閉じる。

**ただし帰結を受け入れられるかを先に決めるべき**: この世界は「熱水噴出孔生態系」ではなく「2 cm 四方・厚さ 0.5 mm の chimney 表面微小域」であり、H2 は 24 h で world 全体へ拡散し、生物は 1 日で world を横断する（M-3, M-5）。空間生態を残したいなら dx=2 mm / world 8 cm を検討すべきだが、それは M-2 を悪化させるので提案 A とセットになる。

## Q6. maintenance のどれを個別化し、どこを total へ含めるべきか

S-5 に詳述。要点:

```text
total basal maintenance へ含める : 膜維持 / ターンオーバー / センシング / storage upkeep
別 power として足す             : movement (Stokes, basal の 1-2%) / repair (damage駆動) / growth (Y_ATP経由)
```

文献の maintenance coefficient は非増殖 ATP 消費の**総和**なので、内訳を独立コストとして足すと二重計上になる。

## Q7. reference doubling time 4–8 h を sanity anchor にすることの妥当性

**sanity anchor として持つのは妥当。ただし固定アンカーにしてはいけない。**

M-1 のとおり、他の2つのアンカーからは 18.5 h が出る。ここで 4–8 h に合わせるために q_max を 3 倍すると、方針書 §1 の原則（「生存する値を探さない」）を破ることになる。

**推奨**: (a) uptake と (b) ATP yield を固定し、doubling time は導出・観測値とする。18.5 h という結果はそのまま記録し、「文献の 6.2 h と 3 倍以内のオーダー一致」と評価する。

**あわせて出典の確認が必要**: µ=0.112/h の引用元 PMC4551271 は CO 代謝の論文である（M-1）。H2+CO2 条件の値へ差し替えるか、由来を明記すること。

## Q8. Exp15 前に他に physical scaling 上の HARD STOP はないか

**ある。5つ。**

```text
(a) M-2  枯渇・競争が成立しない (消費/供給 = 1e-4〜1e-3)  ← 最重要
(b) M-1  3つのアンカーが相互に矛盾 (µ 2.99×)
(c) M-3  world 2 cm / H2 が 24 h で全域拡散 -> 空間勾配消失
(d) M-4  dt=20 s が dx=0.5 mm で拡散不安定 -> S5 が実行不能
(e) M-5  遊泳 25 µm/s で 1 日 RMS 46.5 cell > world 40 cell -> 空間構造消失
```

**特に (a) は、Exp15 の科学的問いそのものを無効化する。** 「自然な環境圧へ生理・進化で応答するか」を問う実験で、環境圧が存在しないなら Phase B/C は空振りになる。physical scaling patch を書き始める前に、M-2 の解（提案 A の `cells_per_agent`）を決めるべきである。

(c)(e) は同じ結論（空間構造が残らない）へ別経路で到達しており、S2・S4・S5 は独立には決められない。

```text
     |

     |
     +--> S3 Matter <-> biomass scale
     |

     |
     v

     |
```

**M-2 を最初に決めないと、他が全部やり直しになる。** `cells_per_agent` は voxel 体積・dry mass・消費/供給比・遊泳速度の解釈すべてに掛かる。

# 8. まとめ

**方針転換は正しい。SI で閉じる作業も正しい。しかし閉じてみると、単位ミスマッチとは別の問題が5つ出てきた。**

最重要は M-2 である。PR #67 の「餓死する」を直しても、その先に「生きられるが誰も競争しない」世界が待っている。Exp15 の科学的問いは後者では答えられない。

`cells_per_agent` を導入して agent を細胞集合体と定義し直すのが、新機構を足さずに（保存則・決定性・遺伝子構造に触らずに）これを解く最小の変更である。そのうえで world サイズ・dt・遊泳速度を M-3/M-4/M-5 に従って同時に決めれば、physical scaling patch は一度で書ける。

アンカーは3つのうち2つだけを固定し、doubling time は導出値として観測する。18.5 h が出たらそのまま記録する。**それが方針書 §1 が自ら定めたルールである。**
