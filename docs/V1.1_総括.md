## 1. Ver.1.1の位置づけ

Ver.1.1は、**当時のモデル設計下で**どのような進化方向と系統動態が生じるかを把握したbaseline版として保存する。

この世界では、**小型化 + 高光利用化への強い方向性選択**が観測された。一方で、同じような生態型へ収斂することと、単一祖先系統が人口の過半を占めるselective sweep（本プロジェクトで「転移」と呼ぶ現象）は別現象である。

Ver.1.1では、この転移が単一形質によるスイッチではなく、複数形質と高回転な繁殖・死亡動態が組み合わさる多因子現象であることまで確認した。

ただし、光利用型優勢を**他の一次Energy戦略との公平な競争結果**とは解釈しない。

**最終V1.1コードは `v1.1-final` ブランチとして保存する。**

## 2. Exp04 — 主要4形質アブレーション

### 実験条件

GitHub Actions / Ubuntu 24.04 上で、同一コード・同一数値実行環境のまま実行した。

- 5条件
  - baseline
  - `body_size = 1.0` 固定
  - `light_absorption = 0.3` 固定
  - `reproduction_investment = 0.4` 固定
  - `mutation_rate = 0.05` 固定
- seed 1〜40
- 40,000 tick
- 合計200 run
- 主判定: `top_lineage_frac >= 0.5`
- 感度解析: 0.3 / 0.5 / 0.7

健全性チェック:

- 各条件40 run、合計200 run
- 早期終了なし
- 固定遺伝子は全期間分散0
- 数値実行環境1種類
- git SHA 1種類

したがって5条件は直接比較可能。

### 40,000 tickまでの累積sweep発生率

| 条件 | sweep | 累積発生率 | baseline比の解釈 |
|---|---:|---:|---|
| baseline | 28/40 | **70.0%** | 基準 |
| reproduction_investment固定 | 20/40 | **50.0%** | 軽度〜中程度抑制 |
| light_absorption固定 | 15/40 | **37.5%** | 中程度抑制 |
| body_size固定 | 9/40 | **22.5%** | 強い抑制 |
| mutation_rate固定 | 1/40 | **2.5%** | 極めて強い抑制 |

重要なのは、**4形質のどれを固定してもsweepが完全には0にならなかった**こと。
したがって今回調べた4形質のいずれも、単独で「転移の絶対的必要条件」ではない。

### 同一seed対応比較

`baseline sweep / fixed sweep`, `baseline sweep / fixed no-sweep`, `baseline no-sweep / fixed sweep`, `baseline no-sweep / fixed no-sweep` の順。

| 固定条件 | sweep→sweep | sweep→no-sweep | no-sweep→sweep | no-sweep→no-sweep |
|---|---:|---:|---:|---:|
| body_size | 6 | **22** | 3 | 9 |
| light_absorption | 9 | **19** | 6 | 6 |
| mutation_rate | 1 | **27** | 0 | 12 |
| reproduction_investment | 15 | **13** | 5 | 7 |

同一seed対応でも、`mutation_rate`、`body_size`、`light_absorption`を固定するとbaselineで起きていたsweepが多数失われる。
`reproduction_investment`にも抑制方向は見えるが、前三者より弱い。

## 3. Exp04から得た転移像

### 3.1 単一トリガーではなく多因子現象

現時点で最も整合的なモデルは以下。

```text
小型化
 + 高光利用化
 + 繁殖戦略の変化
 + 突然変異供給の増加
 + その他の形質・局所的偶然
        ↓
V1.1の光利用環境内で系統の総合的な生存・繁殖優位が上昇
        ↓
多産多死の高回転状態
        ↓
出生/死亡均衡が何らかの理由で崩れる
        ↓
系統人口が急増
        ↓
selective sweep
```

「一定の条件が揃うと必ず転移する」という硬い閾値より、**複数要因がそれぞれ異なる強さでsweepのハザードを上げる**と考える方が結果に合う。

この像はV1.1という光利用優勢環境の内部機構として保持する。

### 3.2 mutation_rateは最重要だが、転移そのものではない

`mutation_rate`固定ではsweepが70% → 2.5%まで低下したため、今回の4形質中で影響は突出して大きい。

しかし1/40ではsweepが発生したため、高mutation_rate自体が絶対条件ではない。

またmutation_rate固定の未転移群では、40k時点でも小型化・高光利用化の進行がbaseline転移群より大幅に遅い。
したがってmutation_rateは直接的な生理的優位というより、**V1.1で有利な形質組合せを探索・供給する速度を上げる上流のアクセル**として働いた可能性が高い。

### 3.3 body_sizeとlight_absorptionには代替経路がある

- `body_size`固定でも9/40でsweep
  - sweep群では`light_absorption`が高くなる
- `light_absorption`固定でも15/40でsweep
  - sweep群では小型化が進む

したがって、V1.1内では小型化と高光利用化はどちらも強い促進因子だが、一方を封じても他形質の進化によって一部代償できる。

### 3.4 reproduction_investmentは促進方向だが相対的に弱い

固定でも20/40でsweepした。
baseline 70%から50%へ低下するため無関係ではないが、単独で転移を支配する形質ではない。

### 3.5 暫定的な影響度

「初期値に固定したとき40k以内のsweepをどれだけ抑えたか」という意味では、

```text
mutation_rate ≫ body_size > light_absorption > reproduction_investment
```

と整理する。

これは普遍的な生物学的重要度ランキングではなく、**Ver.1.1世界・40,000 tickという条件下でのsweep促進効果**である。

## 4. Exp03 / Issue #18と合わせたVer.1.1最終知見

### 観測事実として保持すること

1. V1.1では**小型化・高光利用化への強い方向性選択**が観測された。
2. 高光利用型への収斂とlineage selective sweepは別現象。
3. sweep予定系統はsweep前から高出生率だが、高死亡率も伴う**多産多死の高回転状態**を経る。
4. 当初の `繁殖優位 → 即人口増加 → 変異試行増加 → sweep` という単純モデルは不十分。
5. 実際には高回転状態で出生優位と死亡不利が長く相殺され、その後に均衡が崩れてsweepへ移る。
6. Exp04より、V1.1内の転移は単一形質ではなく複数形質の寄与が重なる多因子現象と考えるのが妥当。
7. `mutation_rate`は特に強い上流促進因子だが、絶対条件ではない。
8. 小型化・高光利用化には部分的な代償経路がある。

### Exp06により撤回する解釈

以下は支持されない。

- 光利用型が、十分成立可能なchemical利用型等との公平な競争に勝った
- 複数Energy戦略を自由に選べる中で光利用が最も高効率だったため優勢化した

理由:
- Exp06 positive controlのchemical型まで全滅
- 旧chemical source式が地質sourceのモデルとして不適切
- 光とchemicalの一次Energy供給構造が比較可能な状態ではなかった

したがってV1.1は、**当時のモデル設計で実質的に成立していた光利用進化経路の挙動を調べたbaseline**として扱う。
