# V1.10 総括 — C/N/P Matter & Resource Closure

更新: 2026-09-08  
状態: **CLOSED by human decision**

V1.10は、V1.9までのgeneric environmental `nutrient` / Matter stockを、今後の生態・代謝進化で意味を持つ最小の元素資源へ置換するversionである。

完了条件はearly Earth chemistryの完全再現ではなく、

> **C/N/Pを有限かつ独立した材料資源として扱い、biomass growth・death/recycling・元素収支を説明可能にし、fixed iLUCAがそのworldで成立すること。**

Exp17によりこの条件を満たしたため、既知の制約を残した上でV1.10をcloseする。

# 1. V1.10で確定した主要変更

## 1.1 generic environmental MatterをC/N/Pへ分解

明示資源:

```text
DIC / CO2-equivalent inorganic carbon
fixed nitrogen
phosphate phosphorus
```

`Organism.matter`はcell dry biomassとして維持する。

旧generic environmental `nutrient`はformal V1.10 CNP routeでは使用しない。

## 1.2 fixed biomass stoichiometry

working composition:

```text
C = 0.47 kg/kgDW
N = 0.11 kg/kgDW
P = 0.02 kg/kgDW
```

growth時は必要C/N/P量を同時に満たせる範囲だけbiomassを増やす。

## 1.3 元素ledger / recycling

C/N/Pを:

- environmental fields
- living biomass
- corpse biomass
- external in/out

まで追跡する。

corpse decay / waste等も固定stoichiometryでfieldへ戻す。

## 1.4 growth limiter observability

最低限:

```text
energy
kinetic
carbon
nitrogen
phosphorus
room
```

を区別して記録できるようにした。

## Phase 0

```text

5/5 survived

final N = 2945–3004
```

## Phase B

DIC / fixed N / phosphateをそれぞれ1/100へ下げたが、3日runでは対応C/N/P limiterは発動しなかった。

原因はC/N/P mechanismではなく、reference stockが現在のsimulation生物需要に対して大きすぎたこと。

また旧aggregateには、C=N=P=0でもC/N/P内だけの比較でtargetを「最大」と誤判定するbugがあり、旧auto-PASSは無効とする。

## Phase C1

background exchange OFFで、初期100個体の元素要求量を基準に10x / 30x / 50x / 100xを比較。

```text
30x  -> 約8.8日からCNP制約 / final N 約2190
50x  -> 10日CNP制約なし / 約15%残存 / final N 約2980
100x -> 10日CNP制約なし / 約58%残存 / final N 約2980
```

transitionは概ね30–50x。

# 3. V1.10 working baseline decision

人間判断により、細かな35/40/45x追加探索は行わない。

今後の暫定working reference:

```text
initial C/N/P stock
= initial 100-cell biomass elemental requirement x 50
```

現在のworldでは概ね:

```text
DIC       = 0.136958 uM
fixed N   = 0.0274863 uM
phosphate = 0.00225996 uM
```

これはearly Earthの真値ではなく、**現在の20 mm world / 1 agent = 1 cell scaleにおけるsimulation working reference**である。

50xを有限stockとして意味あるものにするため、C/N/P background exchangeは当面OFFをworking baselineとする。

将来、現実環境との比較や新しいworld ruleで不都合が出た場合は再校正する。C/N/P不足自体は、合理的な範囲なら進化圧として許容する。

# 4. V1.10で得た主要な教訓

## 4.1 現実の濃度とsimulation内の有効資源量は別問題

mM / uMとして現実的orderの濃度でも、20 mm world・100 agentsの需要に対しては巨大reservoirになり得る。

環境パラメータは物理的anchorだけでなく、world volume / agent biomass / consumption scaleとの整合を見る必要がある。

## 4.2 mechanism validationとecological calibrationを分ける

Phase 0で「仕組みが作動する」ことを確認し、Phase C1で「どの程度のstockなら生態圧になるか」を別に測ったことで、実装不良とscale mismatchを分離できた。

## 4.3 nutrient shortageは必ずしも失敗ではない

有限C/N/Pが不足すること自体は、生態系・進化シミュレーションでは自然な選択圧になり得る。

常に非律速になるよう環境を調整する必要はない。

## 4.4 gate実装も科学結果の一部として監査する

Phase Bのfalse PASSから、aggregateが緑でも科学的判定が正しいとは限らないことを再確認した。

# 5. V1.10 close時点の既知の制約 / 持越し

- C/N/P stoichiometryは全個体固定
- N speciation / N2 fixationなし
- phosphate chemistry / mineral precipitationなし
- pH / DIC speciationなし
- S / Fe / metalsはimplicit non-limiting
- C/N/P外部供給・海流・advectionは未モデル化
- 50x baselineはsimulation-scale working valueでありgeochemical truthではない
- Phase B旧判定bugは修正対象

これらはV1.10を延長して一度に解くより、必要な進化圧が明確になった段階で別world-ruleとして導入する。

# 6. V1.10 close判断

人間判断:

> **V1.10はCLOSED。**

理由:

- generic environmental MatterをC/N/Pへ置換できた
- C/N/P ledgerが閉じる
- C/N/Pを独立growth limiterとして作動させられる
- fixed iLUCAがC/N/P明示化後も複数世代成立する
- finite C/N/P stockが実際にgrowth制約・将来の進化圧として機能することを確認した
- working baselineを50 biomass-equivalentsとして置けた

細かな栄養濃度最適化より、次のworld-ruleへ進む価値が高い。
