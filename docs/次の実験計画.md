## 1. Exp10の最終判断

### 1.1 V1.6行動原理 — GO

Phase Aでは、temporal sensing が人工arenaで意図した方向へ偏りを作り、
一様場では偽biasを作らず、複数刺激を能力に応じて統合することを確認した。

正式Phase Bでは5条件 × control/treatment × seed1-20 × 10,000 tick = 200 runを
同一commit・同一数値環境・進化OFFで実行した。

主結果:

- B2 chemical-only treatment: **20/20生存**（重要停止条件18/20をクリア）
- treatmentは評価可能な全条件で high-Q側へ一貫して偏る
- ventを持つ全条件で treatment の vent滞在が増加
- B5 generalist は light / chemical の両方を行動へ統合
- Energy/Matter・供給側物理・固定表現型・実行環境の整合性は全てOK
- B4では空間選択が強まる一方populationが下がり、行動則が単純な適応度ボーナスに
  なっていないことも確認された

結論は「V1.6が常に個体数を増やす」ではなく、
**環境と表現型に応じて空間利用を変える行動原理として機能する**である。

### 1.2 `memory_tau=10` / `response_gain=64`

Exp10の候補格子と事前登録規則の中で選ばれ、正式Phase Bで機能確認された
**現行参照値**として使用できる。

ただし、あらゆる環境や進化状態に対する普遍的・進化的最適値とは結論しない。
必要なら将来、独立した1軸として検討する。

### 1.3 Phase C — deferred

Phase Cは「Phase A/BがGreenなら長時間へ延長する」頑健性確認として計画されていたが、
現時点では実施しない。

理由:
- Phase A/BでExp10が見たかった行動成立性は確認できた
- 10,000 tickから単にtickを延長しても、新しく答える問いが明確でない
- 計算資源は、次の未解決な世界ルールを切り分ける実験へ使う方が有益

長時間特有の異常や回帰が将来疑われた場合は、Phase Cを再開できるよう
**中止ではなく deferred** とする。

## 2. Exp10再トライアルの扱い

初回Phase Bでは、本来「進化OFF・固定表現型」の計画だったのに、
`light_absorption` / `chemical_absorption` 以外の12遺伝子が進化可能なままだった。
これは実装漏れであり、旧B1/B2は正式結果から除外した。

Phase 0 / Phase Aは有効なまま保持し、Phase Bだけ全14遺伝子固定へ修正して
正式200 runを最初から取り直した。

旧B1で観測された

- `body_size` 約1.0 → 約0.2
- population 約6,500まで増加
- Matter保存下で同じ総Matterが多数の小型個体へ分割

という現象は**Exp10の正式結果ではない**。
一方、現行世界に強い小型化選択圧が存在する可能性と、個体数増大による計算コスト問題を
示した exploratory な設計上の手掛かりとして保持する。

## 3. 小型化問題 — 再検討対象、具体策は未確定

V1.4時点では、`matter^(2/3)` の有効表面積則などから生じる小型化を自然な選択圧として
許容し、「小型化を止めるだけの人工的ペナルティは入れない」と判断していた。

この原則自体は維持する。

ただしExp10のexploratory runにより、極端な小型化が

1. 世界ルール上ほぼ一方向に有利になっている可能性
2. 個体数を大幅に増やし計算コストを悪化させること

が具体的な設計課題として見えたため、**小型・大型双方の物理的/生理的トレードオフを
改めて検討する価値がある**。

現時点では、次バージョン名、実装式、追加パラメータ、候補値、Exp番号、停止条件は
まだ決めない。結果を見てから後付けするのではなく、次の1軸として別途検討・事前登録する。

## 4. LUCA-inspired reference organism — 設計原則として採用

今後の祖先・基準生物の現実側アンカーとして
`docs/LUCA参照モデル方針.md` を採用する。

重要なのは **LUCAを再現しない** こと。

- LUCA復元研究から、初期地球生命として妥当な構造・因果・スケーリング・比率を参考にする
- シミュレーションのEnergy/Matter/tickを、校正なしにJoule/kg/secへ直結しない
- LUCAらしさに適応度を与えない
- 地球史どおりの進化結果を直接指定しない
- 祖先側へ現実的な根拠を与えた後の進化は自然選択へ任せる

この方針だけを先に固定し、個別パラメータ変更は各バージョン/実験で別途検証する。
