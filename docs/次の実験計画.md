## 0.1 V1.6着手前に解消が必要な2点 (レビュー結果)

`docs/V1.6_Exp10_レビュー.md` で実測から判明した、案の記述と実挙動のずれ。

### A-1. V1.5は実世界では既にほぼ動いていない

`sensory_range` の実現値は0.29〜0.55 (全1,201個体)。
感覚半径 = `sense_coef(25.0) × sensory_range` = 10.0〜13.7 wu で、
`cell_size` 20.0 wu を下回る。よって `cr = int(感覚半径/cell_size) = 0` となり、
走査対象は自セルのみ。最良セルが常に自セルなので `stay` となり移動しない。

Exp09実測では a / c / e が**全5,000 tickで移動量ゼロ**だった。

帰結:
- V1.6は「探索則の置き換え」ではなく**実質固着から遊泳への転換**
- Exp10の対照B (V1.5 WTA) が対照A (random walk) と別物にならない。
  診断用に `sensory_range` を大きく固定する条件設定が必要
- Exp09が検証したのは比較の算術であって走化性ではない
  (`docs/Exp09_結果考察.md` §5.8 に追記済み)

### A-2. 場が階段状で `ΔQ` がほぼ常に厳密0

light / chemical はセル単位の定数で、セル内は完全に一定。
wander速度 0.83 wu/tick に対し `cell_size` 20.0 wu なので**1セル横断に24.1 tick**。
同一セルにいる間 `Q_now - Q_past` は厳密に0になり、
memory time 1〜30 tickでは**約96%のtickで `ΔQ = 0`**。

対応候補は「知覚だけ双線形補間 (吸収はV1.4のままセル単位)」を推奨。
ただしこれは知覚モデルの変更なので、V1.6が
(i) 知覚の連続化 と (ii) 時間比較によるturn rate変調 の2変更を
不可分に含むことを設計案へ明記する必要がある。

## 3. 小型化の扱い — 修正しない

V1.4では吸収利益が表面積に近い`matter^(2/3)`、維持費の多くは身体量に強く依存するため、小型個体は単位身体量あたりの交換効率が高い。

現時点ではこれを自然な選択圧として許容する。

小型化を抑えるためだけの人工的コストは入れない。

将来、温度・熱損失・備蓄・防御・捕食などを物理的に追加した結果として大型化の利点が生じることを期待する。

## 5. V1.5 — 異種一次Energy刺激比較

V1.4行動では:

```text
ability × raw field value
```

で光とchemicalを直接比較している。

しかし光はflow、chemicalはstockで単位・数値範囲が違う。

V1.5では:

```text
response(x,K) = x / (x + K)
```

で各刺激を無次元受容器応答へ変換する。

事前登録default:

```text
light_stimulus_half = 1.2
chemical_stimulus_half = 12.3
```

実効刺激:

```text
light_score
= light_absorption × response(light, 1.2)

chemical_score
= chemical_absorption × response(chemical_stock, 12.3)
```

未来Energy収益の予測はしない。

新しい好み遺伝子もまだ追加せず、既存の`light_absorption` / `chemical_absorption`による個体差を使う。

詳細: `docs/V1.5_異種刺激比較仕様.md`

## 7. Exp09後 — 次の1軸を決める

Exp09はGreenなので、次の段階へ進める。ただしExp09が3つの論点を残した
(`docs/Exp09_結果考察.md` §7)。次の実験を事前登録する前に、
**どれを1軸として動かすかを先に決める**。

### 論点1: 感知stockと `chemical_stimulus_half` の乖離

`chemical_stimulus_half=12.3` は生物不在平衡基準の固定値。
実測の感知stockは混合条件0.02〜0.71 / chemical-only 1.25〜1.52 E/cellで1〜3桁低い。
chemical受容器は事実上ほぼ線形応答域しか使っていない。

現状維持のまま長期進化を回すか、先にスケールを見直すか。

### 論点2: 一次Energy候補と他刺激の尺度不整合

無次元化したのは光/chemicalの間だけで、栄養/死骸/捕食との比較は
旧尺度 (能力 × 生の刺激量) のまま。d/e条件では選択の2.9〜4.3%が
この境界で決まっていた。全刺激の共通尺度化は独立の1軸。

### 論点3: chemical bootstrap (Exp07の未解決課題)

祖先の `chemical_absorption` が0.303で止まり、黒字化に必要な約0.9へ届かない。
混合世界の長期実験に含めるか、別建てにするか。

### 候補1 (計画 §12の次実験): 長期混合進化

通常祖先を光+chemical混合世界へ置き、

- light専門化
- chemical専門化
- generalist
- 空間ニッチ分化

が自然に生じるかを見る。

条件はExp09結果を見てから別途事前登録する。
その事前登録では、**generalistの交差点3.69〜12.30に対し感知stockが2桁低い**
という現状 (論点1) を明示したうえで、切替挙動を観測できる設計かどうかを判断する。
