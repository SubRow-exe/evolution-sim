## 3. Exp06後の追加監査で判明した根本問題

旧chemical更新:

```text
regen = chem_regen * stock * (1 - stock / chem_capacity)
```

これはロジスティック増殖資源の式であり、熱水噴出孔等の地質由来sourceとして不適切。

生物がstockを減らすほど供給速度まで低下し、stock≈0では地質sourceまでほぼ停止する構造だった。

光は毎tick外部から継続供給される一方、chemicalは「食べるほどsource自体が弱まる」ため、意図しない構造的非対称が存在した。

単純な`chem_regen`増量スイープは行わない。式自体をV1.3で修正する。

## 4. V1.3 — chemical sourceモデル再定義

chemicalを、熱水噴出孔・冷湧水等から供給される還元性物質の利用可能化学自由Energyとして扱う。

新構造:

```text
地質sourceから一定flux S
          ↓
   局所chemical stock C
      ↓            ↓
生物吸収 U      環境損失 L
                (混合/流出/希釈/酸化等)
```

sourceは生物の消費や現在stockに依存しない。

1 tick:

```text
L = chem_loss_frac * C
C1 = C - L
C2 = C1 + chem_source_flux
その後、生物がC2から吸収
```

**stockに上限 (capacity) は置かない。** source全量が流入し、
一次損失だけでstockが有限化する。生物不在の平衡は `S / chem_loss_frac`。

capacityで上限クリップすると、world edgeで欠けたventや重複セルで
1セルあたりsourceが上がり、超過分がoverflowとして捨てられる。
seed 1-10の実配置で試算すると flux 64 では最大10.8%のsourceが
seed依存で失われ、探索上端で成立境界の判定を歪めるため廃止した。

詳細: `docs/V1.3_化学資源モデル仕様.md`

### V1.3で固定する主仕様

```text
chem_loss_frac = 0.10      # 暫定。Exp07では固定
chem_uptake = 0.5          # 維持
chem_vent_flux = 8.0       # 暫定default
n_vents = 4                # 維持
vent_radius_cells = 2      # 維持
```

旧 `chem_regen` / `chem_min_stock` / `chem_capacity` はConfigから削除する。

1 ventごとの総fluxを一定にし、端・重複によって世界総sourceがseed間で変わらないよう`chem_source_flux` fieldを作る。

初期stockは固定25 Eではなく、生物不在の平衡値:

```text
local_source / chem_loss_frac
```

から開始する。これは更新式の不動点なので、生物がいなければstockは動かない。

## 7. Exp07の判断順

### まずC
chemical生態そのものが長期成立するsource flux境界を求める。

### 次にB
Cが成立するfluxで通常祖先も成立すれば、chemical経路は進化的に到達可能。
Bだけ絶滅なら初期chemical_absorption/standing variation/変異幅等を次に診断。

祖先の収支から、chemical吸収だけで黒字化するには
`chemical_absorption ≈ 0.9` (実効1.0前後) が要る。初期値0.3の約3倍であり、
**Bの絶滅はsource flux不足の証拠にならない**。Bでは生存/絶滅の二値ではなく
`chemical_absorption >= 0.5 / 0.9 / 1.2 / 1.5 / 2.0` の到達seed数と初回tickを見る。

### 次にD
C成立・D絶滅なら、完成chemical型でもvent探索/空間accessがボトルネック。

高fluxでpopulationが`max_population_halt`へ達した場合は失敗ではなく供給過多側の科学結果とする。
