## 3. Exp09後に判明した制約

追加監査で、現行個体はほぼ移動していないことが判明した。

```text
sensory_range default = 0.4
sense radius = 25.0 × 0.4 = 10 wu
cell_size = 20 wu
cr = int(10 / 20) = 0
```

感知対象が自セルだけなので、一次Energy候補を選んでも`stay=True`となる。
したがってExp09が検証したのは比較算術であり、走光性・走化性という空間行動ではない。

またlight / chemical fieldはセル内一定なので、単純な時間差`ΔQ`は大半のtickで0になる。
このためV1.6では「知覚のみの連続化」と「temporal sensing」を不可分の1変更として導入する。

## 4. V1.6 — temporal biased random walk

一次Energy行動を、周囲の最良セルを直接探す方式から、現在位置で感じる刺激の時間変化で
random walkの曲がり方だけを変える方式へ変更する。

```text
light / chemicalを連続座標で双線形補間して知覚
→ 無次元response
→ ability加重平均Q
→ 短期記憶との差ΔQ
→ 改善中は直進しやすく、悪化中は曲がりやすくする
```

変更しないもの:

- light / chemicalの吸収・供給・損失
- V1.4の公平配分
- 移動速度
- nutrient / corpse / predationの既存行動
- 満腹時停止
- 未来Energy収益を予測しない原則

詳細は`docs/V1.6_行動則仕様.md`を正本とする。

## 5. Exp10 — 行動則診断・校正

Exp10は進化実験ではない。

### Phase 0

補間、Q、memory、turn変調、`response_gain=0`回帰、決定論、Energy/Matter保存を検証する。
1件でも失敗したらPhase Aへ進まない。

### Phase A

移動専用synthetic arenaでuniform、light-Y、chemical-X、orthogonal、conflictを診断する。

```text
memory_tau = 3 / 10 / 30
response_gain = 4 / 16 / 64 / 256
```

Green領域から「最小gain、同gainなら最短tau」で1候補を選ぶ。

### Phase B

選定した1候補だけをfull simulationへ持ち込む。

```text
5条件 × 2行動則 × 20 seed × 10,000 tick = 200 run
```

chemical-only treatmentは20 seed中18 seed以上の生存を停止条件とする。

### Phase C

Phase A/BがGreenの場合だけ、同じ最終候補を最大30,000〜50,000 tickへ延長する。
事後的にパラメータ候補を追加しない。

詳細は`docs/Exp10_実験計画.md`を正本とする。
