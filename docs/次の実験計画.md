## 1. 現在地

Ver.1.1 baseline は `v1.1-baseline` タグで凍結済み。

### Exp03までで確認できたこと

- 適応度関数なしで方向性選択が発生する
- 現行世界には**小型化・高光利用化への強い選択圧**がある
- Exp03では40,000 tickまでに主判定で **13/20 seed (65%)** が selective sweep に到達した
- 転移判定は `top_lineage_frac >= 0.5`、感度解析0.3/0.5/0.7で大筋不変
- 未転移seedでも `light_absorption` は上昇しており、**光利用型への収斂と単一系統の一掃は別現象として扱う**
- mutation_rate上昇は少なくともExp02ではヒッチハイクとして説明できる
- 同一数値実行環境では高速化前後の結果が完全一致する
- Windows/Linux等の数値実行環境差では同じseedでも結果が変わり得る

詳細: `experiments/exp03_20seeds_40k/NOTES.md`

### Exp03の表現上の注意

20 seedで17,120 tick以前に転移が0件だったことは、**初期に低ハザードの潜伏期があることを強く示唆する**。
ただし「15,000 tickまでは転移不可能」とまでは断定しない。

また、未転移7 seedすべてが高光利用方向へ進んでいたが、
**全seedが最終的に単一系統によるselective sweepへ至ることは未確認**である。

## 2. Ver.1.1で残す必須作業

### Step 1: Exp04 — 主要遺伝子アブレーション / Issue #4

**問い**: selective sweep にどの遺伝子の可変性が必要か。

baseline比較:
- seed 1〜20
- 40,000 tick
- 主判定 `top_lineage_frac >= 0.5`
- 感度解析 0.3 / 0.5 / 0.7

固定対象:
- `body_size`
- `light_absorption`
- `reproduction_investment`
- `mutation_rate`

```bash
for G in body_size reproduction_investment mutation_rate light_absorption; do
  uv run python tools/run_batch.py --seeds 1-20 --ticks 40000 --workers 14 \
    --fix-genes $G --out runs/exp04_fix_$G
done
```

判定:
- 固定しても転移が起きる → その遺伝子は必要条件ではない
- 累積発生率がbaseline 13/20から大きく低下 → 必要条件候補
- 差が小さければ「不明」とする

---

### Step 2: 転移トリガー解析 / Issue #18

**問い**: なぜ同じように小型・高光利用化する系統の中から、一系統だけが急速に席巻するのか。

有力仮説:

```text
繁殖上の小さな優位
→ 1個体あたり出生率上昇
→ 系統人口増加
→ 突然変異の試行回数増加
→ 追加の有利変異を得る機会増加
→ 正のフィードバック
→ selective sweep
```

最低限見るもの:
- lineage population
- lineage births / interval
- **per-capita birth rate**
- 世代更新速度
- body_size
- light_absorption
- reproduction_investment
- mutation_rate
- top_lineage_frac

代表seedで転移前後を相対時刻で揃えて比較する。
必要なら Issue #7 の祖先追跡を実装する。

詳細: [V1.1_転移トリガー解析項目.md](V1.1_転移トリガー解析項目.md)

## 5. Ver.1.2へ移行

V1.1終了後は Issue #19 を開始する。

### 目的

生物側の能力を「多様化させるため」に調整するのではなく、**世界側の情報量・環境差を少し増やす**。

### 原則

- 抽象的な環境ペナルティを安易に置かない
- 温度・光・資源など意味のある環境量にする
- 一度に1つの環境軸だけ追加する
- V1.1 baselineモードを残す
- 同一seed・同一数値実行環境でV1.1と比較する

### 第一候補

**時間的な光変動**。

V1.1で最も強い選択圧だった光が時間変動したとき、
小型・高光利用型への収斂やselective sweepがどこまで維持されるかを見る。

次候補:
- 温度場
- 資源の空間偏在/時間変動

詳細: [Ver1.2_環境更新候補.md](Ver1.2_環境更新候補.md)
