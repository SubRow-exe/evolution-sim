# 2. Exp13 light絶滅の現在解釈

単純なlight不足だけではない。

現象:

```text
昼: population急増
夜: starvation大量死
翌昼: 再増殖
翌夜: 再崩壊
```

主要仮説:

```text
continuous darkness duration
vs
available Energy reserve / night drain
```

現行繁殖がreserveを親子へ分配し、昼の余剰lightが夜越し貯蔵へ直接積み上がりにくい。

主要diagnostic:

```text
R_ref = night length / reference night survival ticks
```

R_refはsimulationへfeedbackしない分析専用量。
