## 3. V1.2で追加する世界ルール

### 高コントラストな静的光環境

V1.1では全セルに常時光があり、最低でも最大光量の30%が供給されていた。
V1.2では、明所から**ほぼ無光の暗部**までを含む高コントラストな静的光場を追加する。

目的は光利用型を人工的に弱体化することではなく、**高 `light_absorption` が世界のどこでも同じように有効ではない環境**を作り、V1.1の強い一方向選択を揺さぶること。

設計原則:
- 暗部では高 `light_absorption` の利益が小さくなる
- 明部では光利用型の優位を残す
- 光利用型への直接ペナルティは入れない
- まずは世界全体の総光供給量をV1.1と大きく変えず、主に空間分布を変える
- 光場は決定的に生成し、追加の乱数消費でvent配置や生物初期化系列を不用意に変えない
- V1.1 `vertical` 光場はbaseline互換として残す

実装候補:
- 新しい `light_pattern`（例: `high_contrast_vertical`）
- 明所から0〜数%程度の暗部まで連続勾配
- 必要なら明部側の光量を補正し、総光フラックスをV1.1と概ね同程度に保つ

### V1.2では変更しないもの

初回は因果を追いやすくするため以下をV1.1のまま維持する。

- INITIAL_GENOME
- 無性生殖
- 成熟年齢なし / 繁殖クールダウンなし
- 化学資源量・vent仕様
- 無機栄養構造
- 生理コスト式

これらはV1.2データを見た後、次の**世界ルール更新（V1.3以降）候補**とする。

## 4. V1.2.1で追加する機能 — Issue #23

世界ルールを変えない観測・可視化機能として追加する。

- 一定tickごとの個体分布PNG
- light / chemical / nutrient等の環境ヒートマップ
- PNG連番からGIF生成
- 系統ごとの占有セル数
- 系統重心
- 平均移動距離/tick
- 分布幅

**観測ON/OFFで乱数系列・シミュレーション結果を変えないことを必須とする。**

実装自体はV1.2比較実験より前に行ってもよいが、バージョン上は世界ルール変更とは分離して `V1.2.1` として扱う。

## 5. V1.2初回比較

少数seedでV1.1 baselineとV1.2を比較する。

確認項目:
- body_size / light_absorption / chemical_absorption
- population / total_biomass / n_lineages
- selective sweep発生・時期
- 明所/暗所の個体密度
- lineageごとの占有範囲・重心・移動量
- 化学噴出口周辺への定着
- light / chemical / nutrient / corpse / predation flows
- GIF上での空間分化・侵入・sweepの広がり

ここでは最終的な多様性を完成させることを要求しない。
**V1.1の単一的な進化圧を揺らしたとき、何が新しく起きるかを見る探索実験**とする。

---

## 6. V1.2データ後の世界ルール候補

結果を見て、次の小数点以下1桁更新で何を入れるか決める。

候補:
- 化学エネルギー供給量・配置の見直し
- 無機栄養の空間偏在 / 複数化
- 成熟期間 / 繁殖クールダウン等の生活史拡張
- 時間的光変動
- 温度等の新環境軸
- 初期ゲノムの到達距離バイアス再検討

有性生殖は変更規模が大きいため、少なくともV1.2では導入しない。
