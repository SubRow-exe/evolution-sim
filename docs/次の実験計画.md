## 1. 現在地

**Ver.1.1の必須解析は完了。V1.1はクローズ。**

Exp04はGitHub Actions / Ubuntu 24.04で、5条件 × 40 seed × 40,000 tick = 200 runを完遂した。

主判定 `top_lineage_frac >= 0.5`:

| 条件 | sweep |
|---|---:|
| baseline | **28/40 (70.0%)** |
| reproduction_investment固定 | **20/40 (50.0%)** |
| light_absorption固定 | **15/40 (37.5%)** |
| body_size固定 | **9/40 (22.5%)** |
| mutation_rate固定 | **1/40 (2.5%)** |

結論:

- 転移は単一形質のスイッチではなく、多因子現象
- mutation_rateは突出して強い上流促進因子だが絶対条件ではない
- body_size / light_absorptionも強い促進因子
- reproduction_investmentも影響するが相対的に弱い
- 小型化と高光利用化には部分的代償経路がある
- sweep前には多産多死の高回転状態がある
- 高回転の均衡が破れる直接原因は未解決のままBacklogへ残す

詳細は `docs/V1.1_総括.md`。

## 2. 次にやること — Ver.1.2追加要素の設計

V1.2の目的は、V1.1の小型・高光利用優位を人為的に弱めることではない。
**世界側の情報量・環境差・資源差を増やし、複数の戦略が自然に成立し得る条件を作ること。**

まだ最終仕様は固定しない。
以下を比較して、最小の追加要素を決める。

### 候補A: 空間的エネルギーニッチ

- 明所 / 薄暗い領域 / ほぼ無光領域
- 化学噴出口周辺の意味を強める
- 既存 `light_absorption` / `chemical_absorption` / movement / sensory_range で住み分けが起きるかを見る

### 候補B: 資源量・供給スケールの見直し

- 光と化学の公称供給量の差
- 実利用量・未利用量
- どの資源が本当に律速しているか
- 意図しない桁違い・スケール不整合がある場合のみ修正

### 候補C: 無機栄養素の構成・分布の複雑化

- 単一Matterではなく複数必須資源へ拡張する可能性
- 空間偏在
- 必要比率や吸収能力とのトレードオフ

単に資源種類を増やすだけでは新しい一律律速資源になる危険があるため、導入するなら設計を詰める。

### 候補D: 時間的環境変動

- 昼夜
- 光量変動
- 将来的な季節・災害

全世界一様な時間変動だけでは別の単一最適解へ収斂する可能性があるため、空間差との比較が必要。

## 3. V1.2ルール変更前に入れる観測基盤 — Issue #23

環境差を増やすほど、平均値だけでは何が起きているか分からなくなる。
そのためルール変更前に以下を実装する。

### 可視化
- 一定tickごとの空間分布PNG
- 背景にlight / chemical / nutrient等の環境ヒートマップ
- 個体をlineage / 生態型で描画
- PNG連番からGIFを後処理生成

### 空間・行動指標
- 系統ごとの占有セル数
- 系統重心
- 平均移動距離 / tick
- 系統全体の移動量
- 重心からの平均距離など簡易分布幅

将来:
- 行動圏面積
- 環境帯ごとの滞在割合
- niche overlap
- 環境選好

**観測ON/OFFでシミュレーションの乱数系列・結果を変えないことを必須とする。**

## 4. Stage 0 — 現行資源構造監査 / Issue #19

V1.2のパラメータを変更する前に、V1.1世界の資源構造を監査する。

最低限:

- 光の供給量 / 使用量 / 未利用量
- 化学エネルギーの供給量 / 使用量 / 未利用量
- 無機栄養 / Matterのストックと循環
- 空間的利用可能範囲
- 時期ごとの律速資源
- Exp04 `light_absorption`固定条件で代替資源経路が立ち上がったか

この監査結果を見て、候補A〜Dの優先順位を最終決定する。

## 5. V1.2設計原則

- 多様性を直接保護しない
- 特定生態型にボーナスを与えない
- V1.1の結果を「間違い」として消さない
- 抽象的な環境負荷より意味のある環境量を使う
- 一度に多数のルールを変更しない
- baselineモードを残す
- 同一seed・同一数値実行環境で変更前後を比較する
- 空間分布を数値と画像の両方で観察する
