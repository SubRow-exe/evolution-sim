Exp06で旧chemicalモデルはpositive controlまで全滅し、旧regen式が地質sourceとして不適切と判明した。

V1.3でchemicalを:

```text
一定地質source
   ↓

 ↓      ↓
生物   環境損失
```

へ変更。

したがってchemical環境そのものは成立可能。通常祖先からchemical型への進化bootstrapは未成立。

## 2. Exp07後監査で判明した生物側の設計課題

1. 光に個体ごとの吸収上限がなく、単独個体なら低`light_absorption`でもセル光をほぼ全取得
2. chemicalには明確な個体吸収上限があり、光との生物側ルールが非対称
3. chemicalはstock不足時に個体リスト順で先着有利
4. light/chemical/nutrientの環境直接吸収がmatter（体積）比例
5. 光は移動前、chemical/nutrientは移動後セルを参照
6. 光供給値とchemical stockをraw値で行動比較しており単位が異なる

V1.1の「光利用型が競争に勝った」という解釈は引き続き撤回/保留する。

## 3. V1.4 — 一次Energy/資源吸収則

正本: `docs/V1.4_一次エネルギー吸収仕様.md`

### 有効表面積

```text
A_eff = matter^(2/3)
```

light/chemical/nutrientの環境直接吸収へ共通適用。

### 光

```text
light_demand
= light_uptake_coef
× light_absorption
× A_eff
× health
```

Energy空き容量でcapし、セル供給不足時は需要比例配分。

暫定実装default:

```text
light_uptake_coef = 2.0
```

恒久defaultはExp08で決定。

### chemical

V1.3 source/stock/lossは維持。

```text
chemical_demand
= chem_uptake(0.5)
× chemical_absorption
× A_eff
× health
```

stock不足時は需要比例配分。個体順biasを廃止。

`chem_uptake=0.5`はExp08では変更しない。

### nutrient

同じsurface則へ変更。ただし公平配分前に:
- 取り込めるMatter余地
- 現在Energyで同化コストを払える量

でdemandをcapする。

### tick順

フル再構成ではなく最小限:

```text
環境更新
→ 全個体が従来原理で行動決定・移動
→ post-move hash再構築
→ light/chemical/nutrientをセル別公平配分
→ 以降は可能な限り現行逐次順
   corpse → predation → 生理/修復 → 死亡 → 繁殖
```

副作用としてcorpse/predationはpost-move hashを見るため遭遇率が変わり得る。V1.4世界境界として記録する。

## 4. 行動原則

未来Energy収益を予測する行動は導入しない。

> 現在感じる刺激へ反射的に反応する走光性/走化性

を維持する。

異種刺激のraw値直接比較は光+chemical混合前に無次元受容器応答へ再設計する。Exp08ではsource単独なのでまだ変更しない。

## 5. 光/chemicalの相対出力

`light_uptake_coef`と`chem_uptake`はどちらも「遺伝するabsorption能力を実吸収速度へ変換する世界係数」。ただし同じ値に強制しない。

matter0.8 / chemical_absorption=5なら`chem_uptake=0.5`でも個体ceilingは約2.15 E/tickで、V1.1明部光最大約1.2を超え得る。

したがってExp08前にchemical側を人工的にbuffしない。

chemical供給候補:

```text
chem_vent_flux = 8 / 16 / 24 E/tick/vent
```

16/24の根拠は「Exp08で8が不成立になるはず」ではなく、

```text
世界総量では光より小さい
vent近傍では光帯と同等〜より高い局所供給密度
```

という事前の環境設計目標。

## 6. Exp08 — V1.4校正

正本: `docs/Exp08_実験計画.md`

### Phase 0

決定論ベンチ:
- matter 0.5/0.8/1/2/4/8
- absorption 0.3/1/2/5
- light coef 1/1.5/2/3/4
- light/chemical個体ceilingを同一表に併記

- 1/5/20/100個体の公平配分
- nutrient同化Energy/Matter cap
- shuffleはSimulation.rngを消費しない

### Phase A — 光単独

L0:

```text
light_absorption≈0.3固定
light_uptake_coef = 1.0 / 1.5 / 2.0 / 3.0 / 4.0
5 × 10 seed = 50 run
```

L2 positive control:

```text
light_absorption=2.0固定
light_uptake_coef=2.0固定
10 seed = 10 run
```

L2を複数係数で振らない。高能力では多くのセルで供給律速となり判別力が低いため。

Phase A = 60 run × 60,000 tick。

光単独でも`n_vents=4`を維持し、`chem_vent_flux=0.0`でchemicalを無効化する。

### Phase B — chemical単独

```text
light=0
chemical_absorption=2.0固定 / vent
chem_uptake=0.5
chem_vent_flux=8/16/24
3 × 10 seed = 30 run
60,000 tick
```

合計90 run + Phase0。
