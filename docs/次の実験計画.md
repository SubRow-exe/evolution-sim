## 2. V1.2 — 高コントラスト静的光環境

### Control

既存 `vertical` を変更しない。
既定40×40 / `light_max=1.2`:

```text
総光供給量 = 1,248 E/tick
```

### Treatment

```text
light_pattern = high_contrast_vertical
light_hc_bright_frac = 0.20
light_hc_transition_frac = 0.50
light_hc_dark_floor = 0.0
light_hc_total_scale = 1.0
```

40行:

```text
北8行  (20%): 最大光量plateau
中20行 (50%): 最大 → 0 の線形遷移
南12行 (30%): 完全暗部
```

総光量はControlと同じ1,248 E/tickへ正規化する。
Treatmentの実効最大セル光量は約1.733 E/tick。

目的:
- 高光利用型が世界全域で同じように有利な構造を崩す
- 総エネルギー不足の影響を混ぜない
- 光利用型へ人工的なペナルティを与えない

V1.2ではINITIAL_GENOME、無性生殖、化学資源、無機栄養、生理式、繁殖仕様、突然変異仕様は変更しない。

## 5. Exp05後の光環境系列

V1.2以降は光環境を小刻みに振り、原因を切り分ける。

Exp05結果を見て、次は一度に1軸だけ変える。

### 候補A
**総光量を維持したまま、さらに偏在/勾配を強くする。**

### 候補B
**Exp05の20/50/30 shapeを固定し、総光量だけを変える。**

例:
```text
light_hc_total_scale = 0.75 / 1.00 / 1.25
```

shapeと総量を同時に変更しない。
