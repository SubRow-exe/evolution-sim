# 6. その後のmainstream候補

Opus5レビューを踏まえ、現時点の近未来順序を:

```text
V1.9   Origin Lock close
 -> V1.10 C/N/P Matter/resource closure
 -> V1.11 dynamic hydrothermal environment
 -> V1.12 physical phototrophy + habitat/light整合
 -> V1.13 cross-feeding / first biogenic resource niche
```

とする。

理由:
- C/N/Pを先に定義しないとpopulation growthの解釈が曖昧
- dynamic ventを先に入れるとstorage/starvation/dispersalへ自然な選択圧が出る
- phototrophyはlight physical scale化とhabitat整合が済んでから行う

Temperature / pH / chemiosmosisは捨てないがmainstream優先度を下げる。
