# 1. Exp11からExp12へ進む理由

Exp11の事前登録判定は、B1 `bmr_core=0` がsmall-size signal 5/8条件を満たさなかったため:

```text
SCIENTIFIC_VERDICT = NO_SELECTION / REVIEW
```

となった。

ただしB1の10k時点body_sizeは `bmr_core` とともに明瞭に大型側へシフトした。

問題は10,000 tick時点でもlate driftが大きく、そのシフトが:

```text
A. body_sizeの進化平衡そのものが大型側へ変わった
B. 世代交代・進化速度が遅くなっただけ
```

のどちらか判別できないこと。

Exp12はこの一点を長期runで識別する。

**Exp12は恒久bmr_core値を選ぶ実験ではない。**

# 7. 科学判定の骨格

## Tick-space

```text
W1 = 20–30k
W2 = 30–40k
W3 = 40–50k
```

10kあたり相対傾き `S1/S2/S3` を測定。

```text
|S3| <= 0.05 -> late stationary candidate
```

ただし、低下中でも傾きが順に弱まる場合は `CONVERGING_NOT_PROVEN` とし、delayへ誤分類しない。

## Generation-space

各snapshotの:

```text
generation median
Q90
max
```

を測定し、body_size vs median generationのlate slope `S_gen` を出す。

```text
|S_gen| <= 0.05 -> generation-space stationary candidate
S_gen < -0.05   -> 世代あたり小型化継続
```

## per-run

主分類:

```text
INTERIOR_EQUILIBRIUM
LOWER_BOUND_EQUILIBRIUM
DELAY_CONTINUES
CONVERGING_NOT_PROVEN
WINDOW_INSUFFICIENT
```

## per-bmr

B1 8 seed中6 seed以上を基本合意条件とする。

## 全体verdict

```text
EQUILIBRIUM_SHIFT_SUPPORTED
EQUILIBRIUM_SHIFT_SUPPORTED_WITH_ECOLOGICAL_COUPLING
DELAY_SUPPORTED
WINDOW_INSUFFICIENT / REVIEW
INVALID_OR_METHOD_REVIEW
```

結果を見て閾値を変更しない。
