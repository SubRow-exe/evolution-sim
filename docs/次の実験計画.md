## 3. Exp07後の監査で検出した新しい根本問題

### 3.1 光の個体吸収上限欠落

現行光は `light_absorption × matter × health` をセル光量の**分配比率**にしか使っていない。

そのためセルに1匹なら、低い `light_absorption` でもセル光をほぼ全量取得可能。

これは明確な設計ミス。

V1.1で光利用経路が人工的に容易だった原因の一部として扱う。

### 3.2 chemicalには吸収上限がある

chemicalは:

```text
chem_uptake × chemical_absorption × matter × health
```

で1個体/1 tickの吸収上限がある。

したがってV1.3でも生物側に光/chemicalの非対称が残っている。

### 3.3 chemicalの逐次処理順bias

stock不足時に先に処理された個体が有利。
V1.4でセル内全個体の要求量を先に計算し、需要比例配分へ変更する。

### 3.4 体積比例の直接吸収

光/chemical/無機栄養の直接吸収が概ね `matter` 比例。

形状未実装の現段階では:

```text
有効表面積 A_eff = matter^(2/3)
```

を第一近似に使う。

### 3.5 行動時の異種刺激比較

現行は光の供給量とchemical stockを生の値で比較しているため単位が異なる。

ただし「次tickに何Energy得られるか」を予測して移動する高度な行動則は採用しない。

原則:

> 生物は現在感じる光・chemical等の刺激へ反射的に反応する。

異種刺激の無次元化は最初の光+chemical同居実験前までに確定する。

## 4. V1.4 — 一次Energy吸収メカニズム再設計

正本: `docs/V1.4_一次エネルギー吸収仕様.md`

### 4.1 有効表面積

```text
A_eff = matter^(2/3)
```

### 4.2 光

個体最大要求量:

```text
light_uptake_coef
× light_absorption
× A_eff
× health
```

セル供給より総要求が小さければ未利用光は消失。
総要求が大きければ各個体の要求比で供給を配る。

これにより低能力の単独個体がセル光全量を得る問題を解消する。

`light_uptake_coef`の恒久defaultはExp08で校正する。
候補: 1.0 / 1.5 / 2.0。

現行祖先の静止維持費から概算したbreak-evenは約1.29。

### 4.3 chemical

V1.3のsource/stock/環境損失は変更しない。

吸収上限のみ:

```text
chem_uptake
× chemical_absorption
× A_eff
× health
```

へ変更。

stock不足時はセル内需要比例配分にし、個体リスト順依存を廃止。

### 4.4 無機栄養

直接環境吸収なので同様に `A_eff` を使用する。
Matter同化コスト・Matter保存は維持。

### 4.5 維持費

V1.4では変更しない。

利益側を表面積則へ変更した効果をまず単独観測する。
維持費まで同時に変更しない。

### 4.6 tick処理

全個体移動後に空間hashを再構築し、light/chemical/nutrientのセル別需要をまとめて配分する。

光だけ移動前、chemicalだけ移動後、のような参照時点差を残さない。

## 5. chemical絶対量

Exp07のV1.3 default `chem_vent_flux=8` でも完成chemical型は成立。

しかし目標とする自然環境の性格は:

```text
光        : 広域 / 世界総量大 / 個体出力は受光能力で律速
chemical  : 局所 / 世界総量小 / vent近傍では高密度
```

典型13セル/ventなら:

```text
flux8  ≈ 0.62 E/tick/cell
flux16 ≈ 1.23
flux24 ≈ 1.85
```

V1.1光は概ね0.4-1.2 E/tick/cell。

よって16-24 E/tick/ventを恒久default候補とするが、光吸収則変更後のExp08まで確定しない。

`chem_uptake=0.5`はExp08では固定する。

## 6. Exp08 — V1.4吸収則の校正

正本: `docs/Exp08_実験計画.md`

Exp08では光とchemicalをまだ同居させない。

### Phase 0

決定論的ベンチテスト:
- matter 0.5-8でsurface scaling
- light/chemical吸収能力別の最大獲得量
- 維持費との差
- 1/5/20/100個体の密度競争
- 個体リスト順を変えても結果不変

### Phase A 光単独

```text
light_uptake_coef = 1.0 / 1.5 / 2.0
vertical light
chemical=0
```

2条件:
- L0: 祖先 `light_absorption≈0.3` 固定
- L2: `light_absorption=2.0` 固定

```text
3 × 2 × 10 seed = 60 run
60,000 tick
```

### Phase B chemical単独

```text
light=0
chemical_absorption=2.0固定 / vent
chem_vent_flux = 8 / 16 / 24
```

```text
3 × 10 seed = 30 run
60,000 tick
```

合計90 run + ベンチテスト。

目的はdefault校正と実装健全性であり、光/chemicalの進化競争ではない。
