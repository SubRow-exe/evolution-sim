# 3. V1.8 close判断

V1.8ではday/nightと一次Energy density responseの機構実装には成功した。

しかし、light条件の崩壊を追う過程で、現行iLUCA側に:

- Energy残量に応じた恒常性がない
- reserve容量が進化不能
- reproduction thresholdが進化不能
- 初期祖先がすでにlight利用可能
- 初期祖先がすでにpredation可能
- chemical stockが基質ではなく直接Energy

という構造的問題が見つかった。

したがって「夜を短くする」「lightを増やす」「energy_capacityを増やす」等でV1.8を成立させる方向は採らない。

詳細は`docs/V1.8_総括.md`。

# 4. V1.9の目的

V1.9は:

> **chemical-firstで、内部状態へ応答し、貯蔵・繁殖戦略が進化可能な、より妥当なiLUCA baselineを作る。**

元の「chemical-first祖先からphototrophy創発」という目的も包含する。

主要変更:

```text
light_absorption initial = 0
predation_efficiency initial = 0
operational Energy + reserve
state-dependent homeostasis
reserve_capacity gene
reproduction_threshold gene
chemical Energy stock -> H2-like substrate -> usable Energy
zero-start abilityが実用的時間でmutationにより出現可能
```

V1.8のday/nightは残す。chemical-first祖先には直接影響せず、phototrophy出現後に自然な周期選択圧になることを狙う。

# 7. 恒久判断原則

環境parameterを生存のために調整する前に:

> **その環境が要求する応答を、生物側が現在または進化によって原理的に実現できるか**

を確認する。

固定祖先の絶滅だけで環境を不成立と判定しない。

```text
fixed ancestor -> baseline/mechanism sanity
evolution ON    -> adaptive rescue / selection pressure
```

を分けて評価する。
