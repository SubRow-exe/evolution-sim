## 3. 次にやること — V1.2へ進む

詳細監査を先に完遂する方針は採らない。
V1.1の偏りを実際に揺さぶる環境変更を入れ、比較データを増やしてから次の方針を決める。

### 最初のV1.2変更
**高コントラストな静的光環境**を追加する。

V1.1では全セルに常時光があり、最低でも最大光量の30%が供給されていた。
V1.2では、十分に暗い領域を持つ光場を追加する。

設計原則:
- 暗部では高 `light_absorption` の利益が小さくなる
- 明部では光利用型の優位を残す
- 光利用型への直接ペナルティは入れない
- まずは世界全体の総光供給量をV1.1と大きく変えず、主に空間分布を変える
- 光場は決定的に生成し、追加の乱数消費でvent配置や生物初期化系列を不用意に変えない
- V1.1 `vertical` 光場はbaseline互換として残す

実装候補:
- 新しい `light_pattern`（例: `high_contrast_vertical`）
- 明所から0〜数%程度の暗部まで連続勾配
- 必要なら明部側の光量を補正し、総光フラックスをV1.1と概ね同程度に保つ

## 4. 同時に入れる観測基盤 — Issue #23

空間差を入れるので、初回V1.2比較までに最低限以下を使える状態にする。

- 一定tickごとの個体分布PNG
- light / chemical / nutrient等の環境ヒートマップ
- PNG連番からGIF生成
- 系統ごとの占有セル数
- 系統重心
- 平均移動距離/tick
- 分布幅

**観測ON/OFFで乱数系列・シミュレーション結果を変えないことを必須とする。**

---

## 5. 最初のV1.2では変更しないもの

因果を追うため、初回は以下をV1.1のまま維持する。

- INITIAL_GENOME
- 無性生殖
- 成熟年齢なし / 繁殖クールダウンなし
- 化学資源量・vent仕様
- 無機栄養構造
- 生理コスト式

これらは初回V1.2データを見た後の次候補とする。

---

## 6. 初回比較

少数seedでV1.1 baselineとV1.2を比較する。

確認項目:
- body_size / light_absorption / chemical_absorption
- population / total_biomass / n_lineages
- selective sweep発生・時期
- 明所/暗所の個体密度
- lineageごとの占有範囲・重心・移動量
- 化学噴出口周辺への定着
- light / chemical / nutrient / corpse / predation flows
- GIF上での空間分化・侵入・sweepの広がり

ここでは最終的な多様性を完成させることを要求しない。
**V1.1の単一的な進化圧を揺らしたとき、何が新しく起きるかを見る探索実験**とする。

---

## 7. 初回V1.2データ後に決めること

結果を見て次の変更を選ぶ。

候補:
- 化学エネルギー供給量・配置の見直し
- 無機栄養の空間偏在 / 複数化
- 成熟期間 / 繁殖クールダウン等の生活史拡張
- 時間的光変動
- 温度等の新環境軸
- 初期ゲノムの到達距離バイアス再検討

有性生殖は変更規模が大きいため、少なくとも最初のV1.2では導入しない。
