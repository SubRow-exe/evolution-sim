## 2. 新たに発見した最優先懸念

Exp05では暗部にもchemical ventとnutrientが存在したが、持続的な別生態型は成立しなかった。

特に確認すべきこと:

> 現行モデルは「複数Energy戦略の中で光利用が勝つ世界」なのか、それとも「通常祖先から実質的に光利用経路しか進化可能でない世界」なのか。

後者ならモデル設計上の到達可能性の問題であり、V1.1の光利用優勢に関する解釈を修正する必要がある。

現行仕様上の非対称:
- nutrientはEnergy源ではない
- chemical ventは局所的
- 初期chemical_absorption=0.3
- 初期感覚距離≈10 wu < 1セル20 wu
- chemicalの持続供給規模は光より大幅に小さい

したがって、次の光総量0.75/0.50比較は一旦保留する。

## 3. 次はExp06 — chemical利用経路の成立性診断

正本: `docs/Exp06_実験計画.md`

全条件で光=0。

4条件:

```text
A Ancestor / Random
  現行祖先 + 通常ランダム配置

B Ancestor / Vent
  現行祖先 + 全個体vent上配置

C Chem-adapted / Vent
  chemical_absorption=2.0固定 + vent上配置

D Chem-adapted / Random
  chemical_absorption=2.0固定 + 通常ランダム配置
```

`chemical_absorption=2.0` は診断用のpositive controlであり、次期初期値候補ではない。

実行:

```text
seed 1-10
ticks 10,000
4条件 × 10 seed = 40 run
stats_interval=20
snapshot_interval=1000
GitHub Actions / 同一数値実行環境
```

結果が混在し診断不能な条件だけseed 11-20を追加することを事前規定する。

## 4. Exp06で切り分ける原因

### Cも絶滅
chemical生態そのものが現行資源量・供給・生理では成立しにくい。
→ chemical資源スケール / 生理収支を次実験で見直す。

### C生存、B絶滅
完成したchemical生態は成立するが、現行祖先0.3から到達できない進化上の谷が疑われる。
→ 初期chemical_absorption / 変異幅 / 収支曲線を次実験で見直す。

### B生存、A絶滅
祖先からchemical型へ進化可能だが、ventへの接触・探索がボトルネック。
→ sensory_range / vent密度 / 探索ルールを次実験で検討。

### C生存、D絶滅
十分なchemical能力があっても空間アクセスが主要問題。

### Aでも成立
chemical進化経路は閉じていない。Exp05暗部無人化は競争・人口動態・局所carrying capacity等を再検討する。
