## 2. V1.4恒久default — 決定済み

### `light_uptake_coef`（光吸収速度係数）

```text
2.0
```

低光能力個体が安定成立しつつ、高い`light_absorption`へ進化する価値が残る中間点として採用。

### `chem_vent_flux`（chemical噴出口1つが1 tickに供給するEnergy量）

```text
16.0 E/tick/vent
```

標準13セルventで約1.23 E/tick/cellとなり、光の最大1.2 E/tick/cellとほぼ同程度の局所供給密度。世界総量は光より小さいという設計も維持する。

### `chem_uptake`

```text
0.5
```

変更しない。

## 3. 小型化の扱い — 修正しない

V1.4では吸収利益が表面積に近い`matter^(2/3)`、維持費の多くは身体量に強く依存するため、小型個体は単位身体量あたりの交換効率が高い。

現時点ではこれを自然な選択圧として許容する。

小型化を抑えるためだけの人工的コストは入れない。

将来、温度・熱損失・備蓄・防御・捕食などを物理的に追加した結果として大型化の利点が生じることを期待する。

## 5. V1.5 — 異種一次Energy刺激比較

V1.4行動では:

```text
ability × raw field value
```

で光とchemicalを直接比較している。

しかし光はflow、chemicalはstockで単位・数値範囲が違う。

V1.5では:

```text
response(x,K) = x / (x + K)
```

で各刺激を無次元受容器応答へ変換する。

事前登録default:

```text
light_stimulus_half = 1.2
chemical_stimulus_half = 12.3
```

実効刺激:

```text
light_score
= light_absorption × response(light, 1.2)

chemical_score
= chemical_absorption × response(chemical_stock, 12.3)
```

未来Energy収益の予測はしない。

新しい好み遺伝子もまだ追加せず、既存の`light_absorption` / `chemical_absorption`による個体差を使う。

詳細: `docs/V1.5_異種刺激比較仕様.md`

## 6. Exp09 — V1.5比較則の診断

Exp09では進化競争をまだ見ない。

### Phase 0

- 無次元responseの算術
- half-response
- 単調性
- light-only / chemical-onlyでsource内target順位不変
- 等価刺激で同一score
- 能力差による選択切替
- tieでsource固定biasがない
- 未来収益をscoreへ入れていない
- Energy / Matter / RNG健全性

### Phase A

人工arenaで:

- light-only
- chemical-only
- 等価刺激
- light specialist
- chemical specialist
- generalistの環境依存切替

を直接診断する。

### Phase B

標準世界でvertical light + chemical ventを同居。

```text
Light-only control
Chemical-only control
Mixed / light specialist
Mixed / chemical specialist
Mixed / generalist
```

Pilotは各条件seed1、500〜1,000 tick。

本番候補は5条件 × seed1-5 × 5,000 tick = 25 run。

Exp09では生存率・最終populationで光/chemicalの優劣を判定しない。

行動選択回数、Energy flow、vent滞在、明暗帯滞在等から比較則そのものを確認する。

詳細: `docs/Exp09_実験計画.md`
