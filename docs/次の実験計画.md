# 3. Exp14で確定したこと

```text
116/116 run 最終絶滅
死亡原因はstarvation
Generation 2は一度も成立しない
```

支持された要因:

1. **連続nightは大きな負荷**
   - cycle OFFのA1で寿命がbaseline約150→約384 tickへ延長。
2. **Energy storage不足も存在**
   - capacity倍増で最初の夜越しが改善。
3. **tick1一斉繁殖は増悪因子**
   - 初期繁殖を抑えると寿命が改善。
4. **light_maxだけ2倍にしてもほぼ解決しない**
   - A3は約160 tick。
5. **R_refは一晩越しの診断には有効だが長期成立を説明できない。**

詳細は`docs/V1.8_現状総括_Exp14結果.md`。

# 5. Exp15 — 現在の設計目的

Exp15の主目的は**最適値探索ではなく原因切り分けとV1.8 working reference選定**。

まずV1.8で同時導入した2機構を独立比較する。

```text
cycle OFF / density OFF  -> V1.7型control
cycle OFF / density ON   -> density response単独
cycle ON  / density OFF  -> day/night単独
cycle ON  / density ON   -> V1.8 combined
```

目的:

1. 現在コードでV1.7型条件が長期成立することを再確認
2. density response単独のEnergy収支への寄与を測る
3. day/night単独の寄与を測る
4. combinedの相互作用を測る
5. その結果を使い、必要最低限の粗いparameter調整でV1.8のworking referenceを決める

判定で重視するのは:

- 複数世代の継続
- starvation即死にならない
- 昼夜とdensity responseがどちらも意味のある圧として残る
- 一因子が生死をほぼ完全支配しない
- 1点だけでなく周辺でも成立する

唯一の最適値・正確な相転移点・細密なthresholdは求めない。

正式なPhase構成・light_max水準・seed数・tick数は人間合意後に事前登録する。

中心観測量:

```text
realized light gain / organism-tick
maintenance + movement + repair / organism-tick
net Energy balance
Energy/capacity distribution
birth timing
population
survival/extinction
generation depth
```

# 6. 次に決めるparameter

Exp15の切り分け後、必要最低限のみ粗調整する候補:

- `light_max` — V1.8仕様上の主校正軸
- `light_cycle_period_ticks` — 昼夜負荷が過度な場合のみ
- `energy_capacity` — storageが依然bottleneckの場合のみ
- initial/reproduction条件 — 初期条件artifactが支配的な場合のみ

`light_uptake_half=0.6`はV1.8仕様上、現行light scaleの初期固定値であり、まず`light_max`を主校正軸とする。
同時多軸sweepは避ける。
