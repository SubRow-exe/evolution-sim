## 3. V1.2 — 最初の世界ルール変更

### 高コントラストな静的光環境

V1.1では全セルに常時光があり、最低でも最大光量の30%が供給されていた。
V1.2では、**明所からほぼ無光の暗部までを持つ高コントラスト光場**を追加する。

設計原則:
- 暗部では高 `light_absorption` の利益が小さくなる
- 明部では光利用型の優位を残す
- 光利用型への直接ペナルティは入れない
- 世界全体の総光供給量をV1.1と大きく変えず、主に空間分布を変える
- 光場は静的・決定的に生成し、追加乱数消費を避ける
- V1.1の `vertical` 光場はControl用に残す

実装候補:
- `light_pattern=high_contrast_vertical`
- 明所〜0〜数%程度の暗部まで連続勾配
- 必要なら明部側を補正し、総光フラックスをV1.1と概ね同程度に保つ

### V1.2で変更しないもの

- INITIAL_GENOME
- 無性生殖
- 成熟年齢なし / 繁殖クールダウンなし
- 化学資源量・vent仕様
- 無機栄養構造
- 生理コスト式
- 突然変異仕様

最初は光環境1軸だけを変え、因果を切り分ける。

## 5. Exp05 — V1.1互換光場 vs V1.2光場

正本: `docs/Exp05_実験計画.md`
Issue: #24

### 比較条件

同一のV1.2.1コード上で光場だけを変更する。

| 条件 | light_pattern |
|---|---|
| Control | `vertical` |
| V1.2 | `high_contrast_vertical` |

### 本番条件

- seed: **1–20**
- ticks: **40,000**
- 2条件 × 20 seed = **40 run**
- GitHub Actions / 同一数値実行環境
- 同一seed対応比較
- 主sweep判定: `top_lineage_frac >= 0.5`

### 本番前パイロット

少数seed（目安3 seed）・短時間runで、以下の健全性だけ確認する。

- クラッシュしない
- 即時全滅しない
- 光場が意図した空間分布
- PNG/GIF/空間指標が出力される
- ControlがV1.1互換として動く

パイロット結果を見て本番のseed数・40k tick・比較条件・評価項目を変更しない。
光場の調整は「望む生態型を出すため」ではなく、明所/暗所という環境条件が成立するための健全性調整に限定する。

### 主解析

- 進化: body_size / light_absorption / chemical_absorption / mutation_rate / reproduction_investment
- lineage: top_lineage_frac / n_lineages / sweep率 / sweep tick
- 資源: light / chemical / nutrient / corpse / predation / total_biomass
- 空間: 明所/暗所密度 / 占有セル / 重心 / 移動量 / 分布幅 / vent定着
- 目視: PNG / GIFで侵入・住み分け・sweepの広がりを確認

**多様性が増えること自体を成功条件にしない。**
暗部が無人でも、高光利用型が暗部まで席巻しても、住み分けが起きても、すべて次の世界設計の材料とする。

## 6. Exp05後

Exp05の数値・空間指標・GIFをレビューし、次の**世界ルール変更 V1.3**を決める。

候補:
- 化学エネルギー供給量・配置
- 無機栄養の空間偏在 / 複数化
- 成熟期間 / 繁殖クールダウン
- 時間的光変動
- 温度等の新環境軸
- 初期ゲノムの到達距離バイアス

有性生殖は変更規模が大きいため後段候補とする。
