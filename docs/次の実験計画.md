## 1. Exp10の最終判断

V1.6 temporal biased random walk は採用（GO）。

Phase Aでは人工arenaで局所応答・偽biasなし・複数刺激統合を確認し、
正式Phase Bでは5条件 × control/treatment × seed1-20 × 10,000 tick = 200 runを
同一commit・同一数値環境・進化OFFで完走した。

主結果:

- B2 chemical-only treatment 20/20生存（重要停止条件18/20をクリア）
- treatmentは評価可能な全条件でhigh-Q側へ一貫して偏る
- ventを持つ全条件でtreatmentのvent滞在が増加
- B5 generalistはlight/chemical双方を行動へ統合
- Energy/Matter・供給側物理・固定表現型・実行環境の整合性は全てOK
- B4では空間選択が強まる一方populationが下がり、行動則が単純な適応度ボーナスではない

結論は、**環境と表現型に応じて空間利用を変える行動原理として機能する**である。

現行参照値:

```text
memory_tau    = 10
response_gain = 64
```

普遍的最適値とは結論しない。

Phase C（単なる長時間延長）は、新しく答える問いが明確でないためdeferred。
Exp10はPhase Bをもって完了扱い。

## 2. Exp10 exploratory runで見えた小型化

進化OFF実装漏れの旧Phase Bは正式結果ではないが、旧B1では:

```text
mean_body_size 約1.0 -> 約0.226
population     約300 -> 約6,500
```

となった。Matterは厳密保存されており、同じ総Matterが多数の小型個体へ分割された。

これは正式Exp10の結論には使わないが、

1. 現行世界に強い小型化選択圧がある可能性
2. 小型多数化が計算コストを大きく増やす

という次の設計課題を示した exploratory evidence として保持する。

## 3. 次世界ルール候補 — V1.7 core maintenance

小型化を止めるためにbody_size下限やpopulation制御を直接変更しない。

`docs/LUCA参照モデル方針.md` に従い、生命1個体として存在するために縮小しきれない
基礎維持代謝を導入する案を次の1軸とする。

候補式:

```text
BMR = C_core + (0.3 - C_core) * M^0.75
```

性質:

- `C_core=0` でV1.6と完全一致
- `M=1` では全候補でBMR=0.3のまま
- 小型化してもBMRが0へ近づききらない
- 大型側ではcoreを大きな身体で償却できる
- 強すぎるとbody_size上限10への張り付きがあり得るため、上下境界を両方検証する

`C_core` は遺伝子ではなく世界側の共通生理ルールとする。

温度・body_size上下限・繁殖・吸収・行動・捕食等はV1.7では変えない。

詳細: `docs/V1.7_基礎維持代謝仕様案.md`

## 4. Exp11 — 15候補を途中判断なしで一括評価

候補:

```text
0.000, 0.005, 0.010, 0.015, 0.020,
0.025, 0.030, 0.040, 0.050, 0.060,
0.075, 0.100, 0.150, 0.200, 0.300
```

Phase 0:
- 式・境界・illegal Config
- `C_core=0`のV1.6完全回帰
- Energy/Matter/RNG
- body_size以外13遺伝子の固定Config検証

Phase A:
- M=0.2〜10のmaintenance landscapeを決定論計算
- 出産直後の親子Energy/Matter/maintenanceを監査
- **Phase A結果で候補を削らない**

Phase B:

```text
B1 light-only / light specialist : 15 × seed1-8 = 120 run
B2 chemical-only / chem specialist: 15 × seed1-4 = 60 run
B3 mixed / generalist             : 15 × seed1-4 = 60 run
合計                                240 run
```

全条件:

```text
10,000 tick
body_sizeのみ進化ON
他13遺伝子固定
memory_tau=10 / response_gain=64
max_population_halt=10,000
```

240 runはActions matrix 256以内。20並列、旧最悪実績40分/runを全runへ当てても約8時間で、
10時間枠に約2時間の余裕を持たせる。

### 選定原則

Light-onlyで:
- 8 seed中7以上が10,000 tick完走
- extinction / population haltはいずれも1/8以下
- body_size下限0.2の5%以内 (`<=0.21`) が25%未満のrunを7/8以上
- body_size上限10の5%以内 (`>=9.5`) が25%未満のrunを7/8以上

を満たした候補を主Greenとする。

さらにchemical-only / mixedで重大な絶滅・population halt・上限大型化がないことをveto確認し、
**全条件を初めて満たす最小C_core**を恒久値候補とする。

平均body_size=1.0や最小populationは選定条件にしない。

詳細: `docs/Exp11_実験計画案.md`
