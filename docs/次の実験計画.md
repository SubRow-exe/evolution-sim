## 3. V1.2 — 高コントラスト静的光環境

### Control

既存 `vertical` を変更しない。

既定40×40 / `light_max=1.2`:

```text
総光供給量 = 1,248 E/tick
```

### Treatment

```text
light_pattern = high_contrast_vertical
light_hc_bright_frac = 0.50
light_hc_transition_frac = 0.30
light_hc_dark_floor = 0.0
```

40行:

```text
北20行: full light
中12行: full → zero の線形遷移
南8行: zero light
```

Treatmentも:

```text
総光供給量 = 1,248 E/tick
```

したがってExp05では**総量ではなく空間分布だけが異なる**。

光場生成に追加乱数を使わない。
同一seedでvent配置等を変えない。

V1.2で他の世界ルールは変更しない。

## 5. Exp05 — 事前登録済み

### Pilot

```text
seed 1,2,3
Control + Treatment
5,000 tick
6 run
```

実装健全性だけ確認する。
生物学的な結果を見て都合よくパラメータ調整しない。

### 本番

```text
Control: vertical
Treatment: high_contrast_vertical
seed: 1-20
ticks: 40,000
2条件 × 20 seed = 40 run
GitHub Actions
同一seed対応比較
主sweep判定: top_lineage_frac >= 0.5
```

主解析:
- body_size / light_absorption / chemical_absorption
- mutation_rate / reproduction_investment
- population / biomass / lineage diversity
- sweep率 / sweep tick
- resource flows
- North/Middle/South帯の分布
- lineage空間・行動指標
- PNG/GIF

多様性増加を成功条件にしない。
