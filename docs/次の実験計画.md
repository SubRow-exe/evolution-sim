## 1. 現在地

Ver.1.1 baseline は `v1.1-baseline` タグで凍結済み。

### Exp03まで

- 現行世界には**小型化・高光利用化への強い方向性選択**がある
- 40,000 tickまでに `top_lineage_frac >= 0.5` へ到達: **13/20 seed**
- 0.3 / 0.5 / 0.7 の感度解析で大筋不変
- 未転移seedでも高光利用化は進むため、**生態型への収斂と単一系統sweepは別現象**
- 17,120 tick以前にsweepが無かったことは初期低ハザード期を強く示唆するが、「それ以前は不可能」とは断定しない
- mutation_rate上昇は少なくともExp02ではヒッチハイクとして説明できる

### Issue #18 転移トリガー一次解析 ✅ 完了

Exp03の `events.csv` を再解析。13転移seedで共通して:

- 支配予定系統はsweepの6,000〜2,000 tick前から出生率が集団平均より高い（出生比中央値**1.25**）
- 高出生のseedほど死亡も高い傾向があり、出生優位が長期間人口増加へ直結しない
- `出生比 / 死亡比` の相対均衡指標は中央値 **1.02**、13 seed中11 seedで0.98〜1.13
- sweepではこの均衡が破れるが、内訳はseedごとに異なる
  - 死亡率が下がる型
  - 死亡も増えるが出生がさらに伸びる型

したがって、旧仮説

```text
繁殖優位 → そのまま人口増加 → 変異試行増加 → sweep
```

は**部分的に支持、要修正**。

現時点のより正確な像:

```text
高回転（多産多死）系統が成立
        ↓
出生優位と死亡不利が長期間ほぼ相殺
        ↓
何らかの内的/外的要因で均衡が崩れる
        ↓
純増が正になり、系統シェアが急増
        ↓
selective sweep
```

未解決: **なぜこの均衡が破れるか**。完全な因果同定はV1.1終了条件にしない。

## 2. 残る本番: Exp04 / Issue #4

### 最終実行方針

**4条件 × seed 1〜20 × 40,000 tick を同じ事前固定設計で完遂する。**

過去に検討した「`body_size` 1条件を先行し、結果を見て残り3条件を決める案」は**不採用**。
事前3 seed × 10kで4条件とも集団成立を確認済みなので、追加パイロットは行わない。
途中結果を見てseed数・tick数・閾値・固定対象を変更しない。

詳細な事前チェック・実行中ルール・解析手順は **`docs/Exp04_実行手順.md` を必ず参照する。**

### 目的

主要4形質の**初期値からの進化**を1つずつ封じ、40,000 tick以内のselective sweepに対して

- 必須に近い
- 促進する
- 非必須

のどれに近いかを切り分ける。

40,000 tickの打ち切り実験なので「永遠の必要条件」は主張しない。

### 条件

| 固定遺伝子 | 固定値 | 主な役割 |
|---|---:|---|
| `body_size` | 1.0 | 維持費・Matter要求・繁殖閾値・身体スケール |
| `light_absorption` | 0.3 | 主エネルギー獲得 + 維持費 |
| `reproduction_investment` | 0.4 | 親子Energy配分・生活史 |
| `mutation_rate` | 0.05 | 進化探索速度（直接の生理収支ではない） |

今回は4形質の一次スクリーニングに限定する。
損傷死が少なくても膜・耐性・修復はEnergy支出を通じて餓死へ間接影響し得るため「無関係」とはしない。必要なら後の局所感度解析へ回す。

### 実行前の最低チェック

```bash
git pull --ff-only
git status --short
git rev-parse HEAD
uv sync --frozen
uv run pytest tests
```

- `git status --short` が空であること
- 4条件の途中でコードを変更しないこと
- Exp03と同じWindows実行マシンを使うこと
- 条件同士を外側から同時実行しないこと（各条件内のみworkers=14）
- 本番専用の新規出力ディレクトリを使うこと

### 本番出力先

古いパイロットrunとの混在を防ぐため、親ディレクトリ名を以下に固定する。

```text
runs/exp04_20seeds_40k_fix_body_size
runs/exp04_20seeds_40k_fix_reproduction_investment
runs/exp04_20seeds_40k_fix_mutation_rate
runs/exp04_20seeds_40k_fix_light_absorption
```

同名ディレクトリが既に存在する場合は追記しない。

### 実行

```bash
for G in body_size reproduction_investment mutation_rate light_absorption; do
  uv run python tools/run_batch.py --seeds 1-20 --ticks 40000 --workers 14 \
    --fix-genes $G --out runs/exp04_20seeds_40k_fix_$G
done
```

実行後:

```bash
uv run python tools/check_env.py \
  runs/exp04_20seeds_40k_fix_body_size \
  runs/exp04_20seeds_40k_fix_reproduction_investment \
  runs/exp04_20seeds_40k_fix_mutation_rate \
  runs/exp04_20seeds_40k_fix_light_absorption
```

## 3. Exp04の解析ルール（結果を見る前に固定）

### 主解析1: 累積発生率

- 主閾値: `top_lineage_frac >= 0.5`
- 感度: 0.3 / 0.5 / 0.7
- 40,000 tickまでの累積発生率曲線・転移tickをbaselineと比較

### 主解析2: 同一seed対応表

単純な「baseline 13/20 vs fixed x/20」だけでなく、各条件でseedを対応させる。

| baseline | fixed | 意味 |
|---|---|---|
| sweep | sweep | そのseedでは当該形質の進化なしでもsweep可能 |
| sweep | no sweep | 固定でsweepが失われた |
| no sweep | sweep | 固定により別経路が開いた/時期が変わった |
| no sweep | no sweep | 40kでは両方未到達 |

この2×2表を必ず保存する。

### 判定

- **固定条件で1 seedでもsweep** → 当該形質の進化は厳密な必要条件ではない
- **0/20** → 「40k以内のsweepに強く必要な候補」。絶対的必要条件とは断定しない
- **非ゼロだが明瞭に減少/遅延** → 必須ではないが促進因子候補
- **同程度/増加** → 主要な必要条件ではない
- 20 seedで曖昧なら**不明**とする

### 副解析

- population / total_biomass / n_lineages / mean_age
- births / deaths / death causes
- light / chemical / nutrient / corpse / predation resource flows
- 固定対象以外の遺伝子平均・分散による代償進化
- `light_absorption`固定時のchemical / corpse等への代替

sweepが起きた固定条件には:

```bash
uv run python tools/analyze_trigger.py runs/exp04_20seeds_40k_fix_<gene> --batch
```

を適用し、Issue #18の高回転状態と均衡崩壊が残るかを見る。

## 5. Ver.1.2へ進む前のStage 0: 資源構造監査

いきなり「昼夜を入れる」等の機能実装をしない。
まずV1.1の世界が、どの資源をどの規模・空間範囲で提供しているかを数値で整理する。

現行Configの公称値では:

- 40×40 = 1,600セル
- 光: 全域供給、`light_floor=0.3`
- 平均光フラックス約0.78 E/tick/cell → **世界全体 約1,248 E/tick**
- 化学: 4噴出口、半径2セル。重複/端欠け無しの理論最大再生でも約 **32.5 E/tick**
- 初期無機栄養: 2.0 M/cell → **3,200 M**（閉鎖物質プール）

光と化学には公称供給規模だけでも大きな非対称がある。
これは直ちに「設定ミス」を意味しないが、V1.2設計前に意図した世界か確認する。

監査するもの:
- 公称供給量/ストック量
- 実際の利用量と未利用量
- 空間的な利用可能範囲
- 時系列で何が律速になるか
- Exp04でlight進化を封じた場合に代替経路が出るか

**資源量は“多様性を増やすため”に調整しない。**
明らかなスケール不整合・意図しない資源独占が見つかった場合のみ、世界設計として見直す。

## 6. Ver.1.2の第一候補

Stage 0監査後の第一候補は、現時点では**空間的なエネルギーニッチの強化**。

例:
- 明所
- 薄暗い領域
- ほぼ無光の領域
- 化学噴出口周辺

既存の `light_absorption` / `chemical_absorption` / movement / sensory_range だけで、異なる戦略が自然に分かれるかを見る。

「時間的な光変動」は候補として残すが、多様性を生む第一手というより**高光利用戦略の頑健性テスト**として位置づける。

複数無機栄養素は有望だが、生物側の必要比率・吸収戦略まで設計しないと単なる新しい律速資源になりやすいため、最初の小規模更新より後段を基本とする。
