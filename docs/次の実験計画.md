# 3. 現在の原因仮説

Exp14で分離する:

```text
H1: 平均light総量不足
H2: 100 tick連続の完全暗期が生体時間スケールに対して長すぎる
H3: 昼の急速繁殖がreserve Energyを分配し、夜越し能力を壊す
```

現時点ではH2/H3の寄与が強く疑われるが、H1も否定しない。

理由:
- light=4.0では昼に500近くまで増殖できる
- 夜にstarvationで急減する
- lightを増やしても生存時間が単調改善しない例がある
- 初期Energy=50は現reproduction thresholdで開始直後の繁殖を起こしやすい
- surviving fewも次の昼に再繁殖し、次の夜に再崩壊する

詳細: `docs/Exp13_結果考察_中間.md`
