# 2. Exp12の閉じ方

B1（light-only / light specialist）では:

```text
bmr_core 0.00〜0.10 -> lower-bound equilibrium
bmr_core 0.15       -> interior equilibrium 8/8
bmr_core 0.20       -> interior equilibrium 7/8 + converging 1
bmr_core 0.30       -> interior equilibrium 6/8 + converging 2
```

`DELAY_CONTINUES` はB1で0 run。

したがって `bmr_core` は単に世代交代を遅くするだけでなく、小型側平衡を内部へ動かす機能を持つと判断する。

```text

```

理由は「下限張り付きを明瞭に解除した最小側の試験値」。

# 3. V1.8のテーマ

V1.8は一次Energy源を生態的に非対称化する。

```text
light
= 広域 / renewable flow / 低い平均瞬間収益 / 昼夜 / 表面積・光強度依存

chemical
= 局所stock / 高い瞬間収益 / 消費で減る / 競争 / vent sourceから再供給
```

重要:
- lightへ人工的penaltyを付けない
- chemicalへ固定bonusを付けない
- movementを光型だけ強制OFFしない
- chloroplast/cyanobacteria classをまだ追加しない

共通飽和式:

```text
H(x,K)=x/(x+K)
```

をlight/chemical吸収へ入れ、field強度・stock濃度が個体の最大吸収要求量に効くようにする。

lightにはhalf-sine day/night cycleを導入する。

詳細はV1.8正本を読む。

# 5. Exp13概要

Exp13は2段階。

## Phase A — 進化OFF校正

目的:
- light day/night世界が成立するか
- chemicalが高burst/depletable resourceになるか
- chemical max処理速度 `chem_uptake` を選ぶ

light:

```text
light_max=1.2を最初に試す
不成立なら事前登録rescue ladder = 1.5 -> 1.8 -> 2.4
4/5以上成立する最小値
```

chemical:

```text
chem_uptake = 1.0, 2.0, 4.0
```

から、事前条件を満たす最小値を選ぶ。

主条件:
- vent specialist 4/5以上成立
- chemical burst / daylight light gain のgroup median >= 2
- 4/5 seed以上でratio>=1.5
- vent stockが明瞭にdeplete

Phase AがPASSしなければPhase Bへ進まない。

## Phase B — 生態的成立確認

```text
B1 light-only specialist      8 seed × 20k
B2 chemical-only specialist   8 seed × 20k
B3 mixed 2-gene evolution    12 seed × 30k
```

B3は探索的。二峰性や共存が出なくてもV1.8を失敗としない。

V1.8採用の主条件はsource物理・生理の非対称が成立し、B1/B2が6/8以上成立すること。
