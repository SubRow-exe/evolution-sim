# 開発ロードマップ: 原始生命世界から形態進化・惑星進化まで

## 0. プロジェクトの基本思想

本プロジェクトの最終目標は、設計者が「この生物を作る」と結果を直接指定するのではなく、
**世界の物理・化学・環境・遺伝ルールを与えた結果として、予想していなかった生命形態・生態・繁殖戦略・多様性が創発すること**である。

そのため、以下を原則とする。

- 多様性を増やしたいから種数を直接増やさない
- 個体数を抑えたいから強制死亡を入れない
- mutator hitchhiking を嫌って mutation_rate を直接抑えない
- 捕食者・植物・分解者などの完成した役割を最初から種として作らない
- 有性生殖を完成形の `sexual=True` として突然追加しない
- 可能な限り、環境・身体・生理・遺伝の相互作用から結果を生じさせる

一方で、科学的再現性のため、単純化・近似・人工的制約を使う場合は明示し、baselineとの比較を可能にする。

# 1. バージョン方針

## Ver.1系 = 原始生命・単細胞的世界

現在のような原始生命・微生物的生命が中心である限り、世界ルールを拡張しても原則 Ver.1.x とする。

Ver.1系で扱う候補:

- 現在の無性生殖原始生命
- DNA交換・組換えの原始的機構
- 原始的な有性生殖への移行
- 環境の複雑化
- 複数栄養素
- 温度・水・大気・日照変化
- 災害・大量絶滅
- 重力の簡易導入
- ニッチ分化
- 原始生命レベルでの多様化
- 生態型・収斂進化の分類

つまり、**「微生物世界をどこまで豊かにできるか」がVer.1のテーマ**。

## Ver.2系 = 身体構造そのものの進化

明確な身体パーツ・器官・形態が進化し、見た目にも異なる生命が生じる段階を Ver.2 の大きな境界とする。

例:

- 複数の身体パーツ
- 運動器官
- 関節
- 感覚器
- 防御構造
- 口器
- 左右対称性・放射対称性などの形態差
- 身体構造と物理性能の連動

## Ver.3以降 = 高度生命・多細胞化・神経・社会

候補:

- 多細胞化
- 細胞分化
- 神経系
- 学習
- 社会性
- 文化
- 高度な生態系

※番号は今後の開発規模に応じて調整可能。重要なのは「何を境界にしたか」を残すこと。

# 2. 現在地: Ver.1.1 baseline

Ver.1.1 は `v1.1-baseline` として凍結済み。

現在すでに観察されている代表現象:

- 適応度関数なしで方向性選択が発生
- 小型・高光利用系統による人口急増
- selective sweep（選択的一掃）
- mutator hitchhiking
- 系統多様性の急減
- 未利用光エネルギーの新規利用
- 同一世界条件でもSeedにより転移の有無が分岐

現状は「単純な微生物世界として何が起きるか」を理解する段階であり、すぐに世界ルールを変更しない。

この段階では、baseline世界の生態ルールは変えない。

# 4. 多様性をどう生み出すか

## 現状の問題意識

現在の世界では光が広く利用可能であり、高い `light_absorption` を獲得した小型系統が非常に強い。
その結果、一つの優秀系統が世界を広く占有し、selective sweepによって多様性が失われる場合がある。

これは必ずしもバグではなく、現在の単純な世界において合理的な進化である。

## 多様性を増やす基本方針

**多様性そのものを保護するルールは原則入れない。**

代わりに、「一種類の戦略だけでは世界全体を最適利用できない」環境を作る。

候補:

- 空間的な環境差
- 複数のエネルギー源
- 複数の必須栄養素
- 温度差
- 水分差
- 光量差
- 光周期差
- 化学環境差
- 資源の局所性
- 障害物・地形による隔離
- 捕食・被食
- 寄生・共生
- 頻度依存選択
- 季節変動
- 環境変動
- 遺伝子組換え

目標は、

```text
環境A → 戦略Aが有利
環境B → 戦略Bが有利
環境C → 戦略Cが有利
```

となり、複数の生態型が同時に成立すること。

# 5. Seedを越えた「生物タイプ」の記録・分類

今後の重要機能として、個々のlineageとは別に**生態型 / phenotype / ecotype の分類**を導入する。

目的:

> 「このSeedでも、前のSeedとほぼ同じタイプの生物が独立に進化した」

ことを検出する。

これは収斂進化を観察するために重要。

## 保存候補

各代表生物について:

- genome平均・分布
- body_size
- 資源利用比率
- 移動量
- 生息域
- 繁殖戦略
- 修復・寿命傾向
- 捕食 / 光利用 / 化学利用 / 分解の割合
- 将来は身体形態特徴

## 類似度

複数特徴から距離を計算し、クラスタリングする。

例:

- 「小型高光利用型」
- 「大型低代謝型」
- 「化学噴出口特化型」
- 「死骸分解型」
- 「捕食型」

名称は人間が付けてもよい。
将来的には、同型が別Seedで出現した場合に、

> `Photomicrobe-A型に近い生物がSeed 17でも独立出現`

のように表示する。

重要: これは**分類・観察機能**であり、生物側にSpeciesラベルを与えて進化へ影響させない。

# 6. Ver.1.x: 可視化・GUI強化

進化シミュレーションとしての精度と同時に、「眺めて面白い世界」を重視する。

## 環境レイヤー表示

現在は光・無機栄養・化学エネルギーが背景色に重なっており分かりにくい。

将来:

- `L`: 光
- `N`: 無機栄養
- `C`: 化学エネルギー
- `T`: 温度
- `W`: 水分 / 水域
- `A`: 合成表示

などの切替を検討。

色相も原則分離する。

## 生物の見た目

Ver.1の段階でも、遺伝子・生態戦略を外見へ反映できる。

例:

- body_size → 大きさ
- membrane_strength → 外縁・殻
- light_absorption → 色素・表面表現
- predation_efficiency → 口器 / トゲの簡易表現
- corpse_digestion → 分解者的色調
- movement_power → 形状の細長さ等

この段階では見た目がシミュレーション性能を直接決めなくてもよい。
Ver.2で「形が機能を決める」方式へ移行する。

# 7. Ver.1.x: 原始的な遺伝子交換・有性生殖への道

現在は無性生殖しか存在せず、異なる個体の遺伝子を混ぜる仕組みがないため、有性生殖は原理的に創発しない。

完成した有性生殖を直接追加するのではなく、段階的な機構を検討する。

## Stage Sex-1: DNA断片交換

- 接触した個体間でゲノム断片を交換可能
- 交換傾向・交換量を遺伝可能にする
- コストを持たせる

細菌的な水平遺伝子伝達に近い段階。

## Stage Sex-2: 組換え

- 他個体由来のゲノムと自分のゲノムを組み合わせる
- recombination_rateを進化可能にする

観察テーマ:

- mutator hitchhikingが弱まるか
- selective sweepが変化するか
- 有害変異の除去効率
- 適応速度
- 多様性維持

## Stage Sex-3: 細胞融合・二親性繁殖

- 2個体の接触
- 繁殖コスト
- パートナー探索
- 遺伝子混合

ここで初めて「有性生殖」に近づく。

## Stage Sex-4: 配偶型・性の分化

さらに後の研究テーマ。

- 同型配偶子
- 異型配偶子
- 大小配偶子
- 性選択

「オス・メス」は最初から実装しない。

# 8. Ver.1.x: 災害・大量絶滅

## 基本方針

大量絶滅は多様性を人工的に作るための装置として常時使わない。

用途を2つに分ける。

### A. 実験としての災害

特定tickで意図的に発生させ、進化過程を比較する。

例:

- selective sweep直前
- sweep進行中
- sweep後

現在の `--disaster-at` はこの用途。

### B. 世界ルールとしての自然災害

将来的には確率過程・環境変動として自然発生させる。

## 災害タイプ

### 無差別型

- 隕石
- 超巨大噴火
- 局所衝突

能力と無関係、または位置のみで死亡。
遺伝的浮動・ボトルネックを生む。

### 選択圧型

直接「耐性の低い個体を殺す」のではなく環境を変える。

- 寒冷化
- 温暖化
- 日照量低下
- 長期曇天 / 火山冬
- 乾燥
- 酸素低下
- 海水面変化
- 栄養塩変化

例:

```text
隕石
↓
大気中ダスト増加
↓
日照量低下
↓
光利用生物のEnergy取得低下
↓
生態系変化
```

## 定期的な大量絶滅について

「長期実験だから1万tickごとに90%殺す」をbaselineの標準仕様にはしない。

理由:

- 人工的周期が進化へ強いバイアスを与える
- 大量絶滅に適した戦略ばかりを選択してしまう

ただし、**実験シナリオとして周期災害を設定することは有用**。

例:

- 災害なし
- 10,000 tick周期
- Poisson型ランダム災害
- 徐々に変化する気候

を比較する。

# 9. Ver.1.x: 環境の複雑化

## 9.1 温度

優先度: 高

- 空間分布
- 季節変動
- 災害による変化

個体への影響は、直接死亡ではなく代謝・修復・膜安定性などへつなげる。

## 9.2 水の概念

優先度: 高〜中

初期段階では:

- 水域 / 非水域
- 拡散速度
- 移動抵抗
- 物質輸送

程度から開始。

Ver.2以降:

- 浮力
- 流体抵抗
- 遊泳構造
- 陸上進出

へ発展。

## 9.3 大気 / 空気

優先度: 中

初期候補:

- 気体組成を抽象的な濃度場として持つ
- 酸化剤 / 還元剤
- CO2的資源
- 酸素的高効率代謝資源

地球大気をそのままコピーする必要はなく、まず「複数の気相資源」として扱う。

## 9.4 昼夜・日照方向

優先度: 中〜低（V1初期には必須ではない）

現在の原始生命だけなら、平均日照量だけでも基本的な自然選択は成立する。

ただし将来は非常に面白い。

段階:

1. 全世界共通の昼夜周期
2. 緯度による昼夜差
3. 季節
4. 太陽方向
5. 遮蔽物・影

これにより:

- Energy貯蔵
- 夜間休眠
- 日周移動
- 光源方向への配向

などの選択圧を作れる。

# 10. 重力 — 長期的に重要な惑星パラメータ

個人的に重要視するテーマとして、重力を将来の主要パラメータにする。

## Ver.1での簡易導入

原始生命では重力の意味は限定的なので、最初は簡易モデルでよい。

候補:

- 大型化に伴う支持コスト
- 移動Energyコスト
- 沈降 / 浮上傾向
- 水中と陸上で影響を分ける

## Ver.2以降

身体構造と物理が導入された段階で本格化。

観察テーマ:

### 高重力惑星

- 小型化するか
- 扁平化するか
- 支持構造が太くなるか
- 移動を減らすか
- 地表固定型が増えるか

### 低重力惑星

- 大型化するか
- 細長い身体が成立するか
- 跳躍が有利になるか
- 滑空・飛行へ進出しやすくなるか

最終的には「同じ祖先生命を重力だけ違う惑星に置いたら、形態進化がどう分岐するか」を比較したい。

# 11. 栄養素・化学資源の複雑化

現在のMatterは一種類であり、身体構築資源を非常に抽象化している。

将来的には複数資源化する。

例:

```text
Matter-A: 構造材料
Matter-B: 膜・外殻材料
Matter-C: 触媒 / 微量必須元素
Energy source-X
Energy source-Y
```

重要なのは、単純に資源数を増やすことではなく、**異なる生物が異なる資源組合せへ特化できること**。

例えば:

- A豊富/B不足環境
- B豊富/A不足環境
- 特定資源を他生物からしか得られない

などがニッチ分化を生む。

将来的には化学量論（必要比率）の概念も検討する。

# 12. 地球とは異なる惑星生命

これは最終的な重要研究テーマだが、科学的不確実性が非常に大きい。

## 実現可能なこと

「地球生命をコピーしない抽象生命化学」を作ることは可能。

例えば世界に:

- solvent（溶媒）
- energy carrier
- structural resource
- catalyst resource
- environmental temperature
- pressure
- redox gradient

などの一般化パラメータを持たせる。

生命はこれらを利用して自己維持・複製する。

これなら「水以外の溶媒を使う世界」を**抽象モデルとして**比較できる。

## 難しいこと

「本当にアンモニア生命・メタン生命・シリコン生命がこう進化する」と科学的に高精度で予測することは、現在の知識では困難。

したがって、将来このテーマを扱う際は:

- 地球外生命の予言とは言わない
- 仮想的な化学法則の下での進化実験と位置づける
- 仮定を明示する

## 無機生命について

「無機生命」という完成カテゴリを作るのではなく、

- 自己複製
- エネルギー利用
- 構造維持
- 変異
- 遺伝

を満たす一般化生命モデルを作り、使用材料を固定しない方向が望ましい。

これはかなり長期の研究テーマ。

# 18. 開発判断の原則

新しい要素を思いついた際は以下で判定する。

1. **その機能がなければ原理的に創発不可能か**
   - DNA交換機構がなければ有性生殖は生じない
   - 身体パーツ生成機構がなければ脚は生じない

2. **完成形を直接実装せず、より原始的な部品へ分解できないか**

3. **多様性を直接保護していないか**
   - 多様な環境を作るのは良い
   - 「種数が減ったら弱い種を救済」は避ける

4. **環境変化は個体を直接選別せず、生理・物理条件を変えているか**

5. **baselineとの比較ができるか**

6. **SeedとConfigから再現可能か**

7. **性能コストを測定できるか**

8. **見た目にも結果が理解できるか**

9. **科学的に不確実なテーマでは仮定を明示しているか**

# 19. 最終ビジョン

同じ原始生命を異なる惑星条件へ投入し、

```text
惑星A: 地球型重力・水・安定した恒星
惑星B: 高重力・寒冷
惑星C: 低重力・厚い大気
惑星D: 別の溶媒・異なる化学資源
```

で長期間進化させる。

その結果、設計者が身体形態や生態を指定していないにもかかわらず、

- 惑星ごとに異なる形態
- 異なる繁殖戦略
- 異なるエネルギー利用
- 異なる運動様式
- 独立したSeedで繰り返し出現する収斂型

が生まれることを最終目標とする。

**「地球の生物を別惑星に置く」のではなく、「世界のルールから、その世界なりの生命が出てくる」シミュレーションを目指す。**
