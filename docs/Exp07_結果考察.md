## 1. Exp07の目的

Exp06では、光0の世界で完成chemical利用型 (`chemical_absorption=2.0`) をvent上へ置いたpositive controlまで全滅した。

監査により旧chemical資源が自己増殖資源型のロジスティック回復式になっており、熱水噴出孔等の地質sourceとして不適切だったため、V1.3で以下へ変更した。

```text
一定の地質source
      ↓
局所chemical stock
 ↓           ↓
生物吸収    環境損失
```

Exp07は、新sourceモデル単独で:
1. chemical生態そのものが成立可能か
2. 通常祖先からchemical利用型へ進化可能か
3. 完成chemical型がrandom配置からventへ定着可能か

を切り分ける診断実験である。

## 2. 条件

全run light=0。

`chem_vent_flux`（1つの噴出口が1 tickに世界へ供給するEnergy）:

```text
4, 8, 12, 16, 24, 32, 48, 64 E/tick/vent
```

4 ventsなので世界総chemical供給:

```text
16, 32, 48, 64, 96, 128, 192, 256 E/tick
```

各供給量で:

```text
C: chemical_absorption=2.0固定 / vent配置
B: 通常祖先 / vent配置
D: chemical_absorption=2.0固定 / random配置
```

`*`:

- flux8 Dは10/10で120k到達したが、最終個体数20未満が4 seedあり、成立境界付近として扱う

### 3.2 C — 完成chemical型 / vent

flux8以上では10/10で120kまで長期維持した。

代表的な最終個体数の中央値は概ね供給量に追従して増加した。

```text
flux8   : 約53
flux12  : 約83
flux16  : 約106
flux24  : 約161
flux32  : 約219
flux48  : 約332
flux64  : 約443
```

flux8のsource利用率は多くのseedで約0.91-0.99、flux12以上でも高い利用率を示した。

**結論:**

> V1.3の地質source + 局所stock + 環境損失モデルでは、完成chemical利用型だけで持続可能な生態系を成立させられる。

Exp06でCまで全滅した主因は、chemical Energyの存在そのものではなく、旧stock依存regen式の構造不整合だったと強く支持される。

### 3.3 B — 通常祖先 / vent

全8供給量 × 10 seed = **80/80で絶滅**。

絶滅はほぼ150 tick前後で、供給量を4→64へ16倍にしても大きく改善しなかった。

また、絶滅までに:

```text
chemical_absorption >= 0.5 : 0/80
chemical_absorption >= 0.9 : 0/80
chemical_absorption >= 1.2 : 0/80
```

であり、chemical利用能力を高める進化が始まる前に個体群が消滅している。

高fluxほどchemical stockは大量に残るため、これは「環境にEnergyが足りない」現象ではない。

**結論:**

> V1.3でchemical生態そのものは成立可能になったが、現行共通祖先 `chemical_absorption≈0.3` からchemical依存型へ進むbootstrap経路は依然閉じている。

したがって次に初期chemical_absorptionを恒久的に変更するのではなく、まず一次Energy吸収則全体の非対称を再監査する。

### 3.4 D — 完成chemical型 / random

flux8以上で10/10が120kへ到達した。

最終時点では多くのrunで個体の90%以上がvent cellに存在し、完成chemical利用型はrandom配置からchemical nicheへ定着可能だった。

一方、source利用率がseedごとに約0.25 / 0.50 / 0.75 / 1.00付近へ分かれる傾向がある。4 ventsのうち1/2/3/4個程度へ局所集団が成立した結果と整合する。

**結論:**

> 少なくとも1つのventへ到達・定着する能力はある。ただしvent間を積極的に探索して全ニッチを占有する能力は弱い可能性がある。

これは現行行動則が局所定着型・植物/微生物マット型の生態を作りやすいことと整合する。

## 4. Exp07後の設計監査で新たに確定した問題

Exp07によりchemical供給モデルは成立したため、光との比較へ進む前に一次Energy獲得式を監査した。その結果、V1.1以来の光利用に重大な非対称が残っていることが判明した。

### 4.1 光に個体ごとの吸収上限がない

現行の光は同じセルの個体について:

```text
light_absorption × matter × health
```

を「セル光量の分配比率」として使う。

そのためセルに1個体しかいなければ、`light_absorption`が低くてもセルの光をほぼ全量取得できる。

これは `light_absorption` が実際の吸収・変換能力を律速しておらず、光利用への進化経路を人工的に容易にしていた設計ミスである。

V1.1-Exp05で光利用型が非常に強かった原因の一部として扱う。

### 4.2 chemicalには吸収速度上限がある

chemicalは現行でも:

```text
chem_uptake × chemical_absorption × matter × health
```

で1個体/1 tickの最大吸収量が制限される。

したがってV1.3時点でも:

```text
光: 能力が低くても単独なら大量取得可能
chemical: 能力が低ければstockが大量でも取得不能
```

という生物側の非対称が残っている。

Exp07 Bが供給量を増やしても救済されない理由とも直接関係する。

### 4.3 chemical吸収は個体処理順に依存する

現行chemicalは個体リスト順にstockから吸収する。

stock不足時には先に処理された個体が有利になるため、物理的競争ではなくプログラム上の順番が適応度へ影響し得る。

V1.4で廃止する。

### 4.4 光/chemicalの身体サイズ依存

現行は両方とも概ね `matter` に比例して吸収能力が増える。

しかし原始的な直接吸収生物を想定するなら、環境との交換は体積ではなく表面積に強く制約される。

同形状の3次元物体を粗視化すると:

```text
体積・matter ∝ 長さ^3
表面積       ∝ 長さ^2
```

なので有効表面積を:

```text
A_eff = matter^(2/3)
```

と置くのが単純な第一近似として妥当。

これは形状進化をまだ持たない現行モデルの暫定則であり、将来形状を実装したら差し替える。

### 4.5 行動時の異種資源比較

現行行動では光の「1 tick当たり供給」とchemicalの「現在stock」を同じ刺激スコアで直接比較している。

単位・物理的意味が異なるため、混合世界では不自然。

ただし「その場所で将来何Energy得られるか」を計算して行動させる方式も採用しない。これは原生生物として高度すぎる。

V1.4では原則:

> 現在感じる光強度・chemical濃度等に対する反射的な走光性/走化性

を維持し、将来収益の予測は導入しない。

異種感覚刺激をどのように無次元化して比較するかは、光+chemical混合実験の前に解決する。

## 5. 現時点のchemical絶対量の扱い

Exp07から、`chem_vent_flux=8`（世界総32 E/tick）でも完成chemical型は長期成立する。

しかし自然界との対応を意識すると、chemicalを:

> 世界全体では光より少ないが、vent周辺では高密度

な一次Energy sourceにしたい。

現行ventが典型的に約13セルなら:

```text
flux8  → 約0.62 E/tick/cell
flux16 → 約1.23 E/tick/cell
flux24 → 約1.85 E/tick/cell
```

V1.1光は概ね0.4-1.2 E/tick/cell。

したがって恒久default候補として **16-24 E/tick/vent** は有力だが、光の吸収上限を修正すると実際の生物獲得量が変わるため、Exp08前には確定しない。
