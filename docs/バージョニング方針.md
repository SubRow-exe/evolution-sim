# バージョニング方針

更新: 2026-08-31

## 基本ルール

本プロジェクトでは、進化・生態・環境結果を変えうる世界ルール変更と、結果不変の機能追加をバージョン番号で分離する。

### 小数点以下1桁: 世界ルール変更

例: `V1.1 → V1.2 → V1.3 → V1.4`

対象例:
- 環境場・資源構造変更
- 光/化学/栄養の供給・吸収則変更
- 生理コスト・繁殖・移動等の力学変更
- 新しい遺伝子/形質
- 生殖方式変更

### 小数点以下2桁: 結果不変の機能・観測追加

例: `V1.2 → V1.2.1 → V1.2.2`

対象例:
- PNG/GIF
- GUI
- 観測指標
- CSV/解析ツール
- CI/Actions
- 結果不変の性能改善
- ドキュメント

## 世界バージョン境界の手順

1. 直前バージョン最終コードを `vX.Y-final` branchへ保存
2. 直前バージョンの重要な実験NOTES/結果docがmainに存在することを確認
3. `tests/golden_state.json` を `tests/golden_state_vX.Y.json` へ履歴保存
4. 新世界ルールを実装
5. 新バージョン最初の意図的結果変更コミットをCIの結果不変性基準refへ設定
6. 以後、新バージョン内での結果不変変更をCIで監視

## CI基準ref履歴

| 世界バージョン | 基準ref |
|---|---|
| V1.1 - V1.2.2 | `18137b5` |
| V1.3 | `ea78125` |
| V1.4 | `5aca88e` → `226a926` (Exp08 default確定 = `v1.4-final`) |

V1.4実装時はV1.3との差異が意図的なので、V1.3基準refとの結果不一致は異常ではない。

`5aca88e` はV1.4吸収則の最初の実装コミット。Exp08の校正結果として恒久default
(`light_uptake_coef=2.0` / `chem_vent_flux=16.0`) を確定した `226a926` で
default Configの結果が意図的に変わったため、基準refを `226a926` (= `v1.4-final`)
へ移した。以後のCIは「V1.4内で結果が変わっていないか」を検証する。V1.3の再現には `v1.3-final` を使う。
V1.3では `tests/golden_state.json` に指紋を記録しないまま境界を越えたため、
履歴ファイルは `tests/golden_state_v1.2.json` までしかない。

## V1.4特記事項

V1.4では以下が結果を変えるため世界境界として扱う。

- `effective_surface = matter^(2/3)`
- 光個体吸収上限
- light/chemical/nutrientの需要比例配分
- chemicalの個体処理順bias廃止
- light/chemical/nutrientのpost-moveセル参照統一
- 最小限のtick再構成
- corpse/predationがpost-move hashを見る副次的変更

死亡/繁殖まで全面フェーズ化することはV1.4の必須仕様ではない。

## 補足

バグ修正で結果が変わる場合も世界ルール変更に準じて扱う。
結果不変の内部修正のみ小数点以下2桁側で扱う。
