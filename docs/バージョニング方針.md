# バージョニング方針

更新: 2026-09-01

## 基本ルール

本プロジェクトでは、進化・生態・環境結果を変えうる世界ルール変更と、結果不変の機能追加をバージョン番号で分離する。

### 小数点以下1桁: 世界ルール変更

例: `V1.1 → V1.2 → V1.3 → V1.4`

対象例:
- 環境場・資源構造変更
- 光/化学/栄養の供給・吸収則変更
- 生理コスト・繁殖・移動等の力学変更
- 新しい遺伝子/形質
- 生殖方式変更

### 小数点以下2桁: 結果不変の機能・観測追加

例: `V1.2 → V1.2.1 → V1.2.2`

対象例:
- PNG/GIF
- GUI
- 観測指標
- CSV/解析ツール
- CI/Actions
- 結果不変の性能改善
- ドキュメント

## V1.6を閉じてV1.7へ進む前の処理

Exp10では

```text
memory_tau = 10
response_gain = 64
```

を現行参照値として採用した。一方、2026-09-01時点の通常Config defaultは
`response_gain=16` のまま残っている。

V1.7の変更軸へ混ぜず、V1.6確定処理として先に:

1. `response_gain` defaultを64へ反映
2. 全test / Energy / Matter / RNG確認
3. default結果変更に伴いCI基準refを更新
4. `v1.6-final` branchを保存
5. その後にV1.7実装へ進む

とする。

## 世界バージョン境界の手順

1. 直前バージョン最終コードを `vX.Y-final` branchへ保存
2. 直前バージョンの重要な実験NOTES/結果docがmainに存在することを確認
3. `tests/golden_state.json` を必要に応じて `tests/golden_state_vX.Y.json` へ履歴保存
4. 新世界ルールを実装
5. 新バージョン最初の意図的結果変更コミットをCIの結果不変性基準refへ設定
6. 以後、新バージョン内での結果不変変更をCIで監視

## 過去境界の補足

V1.4実装時はV1.3との差異が意図的なので、V1.3基準refとの結果不一致は異常ではない。

`5aca88e` はV1.4吸収則の最初の実装コミット。Exp08の校正結果として恒久default
(`light_uptake_coef=2.0` / `chem_vent_flux=16.0`) を確定した `226a926` で
default Configの結果が意図的に変わったため、基準refを `226a926` (= `v1.4-final`)
へ移した。さらにV1.5で結果が変わるため、基準refを `8b064ee` へ移した。

V1.5はlightとchemicalの異種比較だけを変えるため、単独source世界ではV1.4と完全一致することを
別途検証した。V1.6は一次Energy行動原理そのものを変更したため、CI基準refを
V1.6最初の実装 `e15ee67` へ移した。

## V1.7特記事項（計画案）

V1.7候補は:

```text
BMR = C_core + (bmr_coef - C_core) * M^0.75
```

という生理コスト変更なので、世界ルール変更として小数点以下1桁を上げる。

実装直後は `C_core=0` を暫定defaultとしてV1.6-final完全回帰を保ち、Exp11で候補を校正する。
Exp11で恒久値を選定した場合、そのdefault反映commitで結果が意図的に変わるため、
V1.7のCI基準refをその確定状態へ更新する。

## 補足

バグ修正で結果が変わる場合も世界ルール変更に準じて扱う。
結果不変の内部修正のみ小数点以下2桁側で扱う。
