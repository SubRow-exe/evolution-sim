# バージョニング方針

更新: 2026-09-04

## 基本ルール

本プロジェクトでは、進化・生態・環境結果を変えうる世界ルール変更と、結果不変機能追加を分離する。

### 小数点以下1桁: 世界ルール変更

例:
- 環境場・資源構造
- 供給・吸収則
- 生理コスト・繁殖・移動
- 新遺伝子/形質
- 生殖方式
- Energy / Matter state model

### 小数点以下2桁: 結果不変機能

例:
- PNG/GIF/GUI
- 観測指標/CSV/解析
- CI/Actions
- 結果不変性能改善
- ドキュメント

# 世界version境界の手順

1. 直前version最終コード/refを固定
2. 直前versionの総括/主要実験結果がmainにあることを確認
3. 必要なgolden履歴を保存
4. 新世界ルールを実装
5. 新version最初の意図的結果変更commitを基準refへ設定
6. 以後同version内の結果不変変更を監視

# V1.8 close

V1.8で実装した世界ルール:

```text
non-normalized half-sine day/night
actual effective light flux
light/chemical primary Energy density response
actual light supply ledger
```

Exp13/14を通じ、light-dependent固定表現型の崩壊を確認した。
Exp14には表現型provenance mismatchがあり、恒久parameter選定には使わない。

さらに正しい表現型での短期probeとコード監査から、iLUCA側に:

```text
内部状態依存homeostasisなし
reserve容量がworld constant
reproduction thresholdがworld constant
祖先がlight/predation能力を既に持つ
chemicalが基質でなく直接Energy
```

という構造的問題が判明した。

人間判断:

> V1.8のworking parameterを生存優先で追わず、祖先モデルをV1.9で再設計する。

したがって:

```text
original Exp15        SUPERSEDED / DO NOT DISPATCH
light working value   NOT SELECTED BY DESIGN
chemical working value NOT SELECTED BY DESIGN
V1.8 scientific phase CLOSED
```

詳細: `docs/V1.8_総括.md`

V1.8コード自体はV1.9実装前に最終refを固定する。
