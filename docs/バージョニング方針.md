# バージョニング方針

更新: 2026-09-03

## 基本ルール

本プロジェクトでは、進化・生態・環境結果を変えうる世界ルール変更と、結果不変の機能追加を分離する。

### 小数点以下1桁: 世界ルール変更

例:
- 環境場・資源構造
- 光/化学/栄養の供給・吸収則
- 生理コスト・繁殖・移動
- 新遺伝子/形質
- 生殖方式

### 小数点以下2桁: 結果不変機能

例:
- PNG/GIF/GUI
- 観測指標/CSV/解析
- CI/Actions
- 結果不変性能改善
- ドキュメント

# 世界バージョン境界の手順

1. 直前version最終コードを`vX.Y-final`へ保存
2. 直前versionの総括/主要実験結果がmainにあることを確認
3. golden履歴を必要に応じ保存
4. 新世界ルール実装
5. 新version最初の意図的結果変更commitをCI結果不変性基準refへ設定
6. 以後同version内の結果不変変更を監視

# V1.7確定

```text
BMR = bmr_core + (bmr_coef - bmr_core) * M^0.75
bmr_core = 0.15
```

Exp11 10kでは平衡未到達だったためExp12 50kへ延長。

Exp12 B1:

```text
0.00〜0.10 -> lower-bound equilibrium
0.15       -> interior equilibrium 8/8
0.20       -> interior 7/8 + converging 1
0.30       -> interior 6/8 + converging 2
```

事前登録機械verdictはB2 method gate未達により`INVALID_OR_METHOD_REVIEW`。

人間判断ではB2を既知stationary controlとした前提が不成立と判断し、B1結果から0.15を採用。

0.15は物理的相転移点ではなく事前sentinelを最初に超えた試験格子点。

詳細: `docs/V1.7_総括.md` / `docs/Exp12_結果考察.md`。

V1.7 close:
1. default .15
2. tests/conservation/determinism/CI
3. V1.7 ref更新
4. `v1.7-final`
5. その後V1.8

# V1.8境界

世界ルール変更:
- non-normalized half-sine day/night
- effective light flux時間変化
- light uptake intensity response
- chemical uptake stock response
- chemical `K` / uptake working values再校正
- actual light supply ledger

Exp13選定前feature flagsはOFFでV1.7回帰を守る。

Exp13 sweep:

```text
light_max = 0.8,1.2,1.5,1.8,2.1,2.4,3.0,4.0
chemical_uptake_half = 0.5,1.5,3.0,6.15
chem_uptake = 0.5,1.0,2.0,4.0
```

選定値は自然界の普遍定数ではなく、**現在の世界ルールのworking reference**。

Exp13終了後の人間判断で採用する場合のみ:

```text
primary_energy_density_response=True
light_cycle_enabled=True
selected light_max
selected chemical_uptake_half
selected chem_uptake
```

を恒久defaultへ反映。

そのcommitをV1.8基準refとし、tests/CI後`v1.8-final`保存。

# 過去境界の補足

旧世界再現には各`vX.Y-final`を使う。

バグ修正で科学結果が変わる場合も世界ルール境界に準じる。
結果不変の内部修正のみpatch側で扱う。
