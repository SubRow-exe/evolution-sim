# バージョニング方針

更新: 2026-09-03

## 基本ルール

本プロジェクトでは、進化・生態・環境結果を変えうる世界ルール変更と、結果不変の機能追加をバージョン番号で分離する。

### 小数点以下1桁: 世界ルール変更

対象例:
- 環境場・資源構造変更
- 光/化学/栄養の供給・吸収則変更
- 生理コスト・繁殖・移動等の力学変更
- 新しい遺伝子/形質
- 生殖方式変更

### 小数点以下2桁: 結果不変の機能・観測追加

対象例:
- PNG/GIF / GUI
- 観測指標 / CSV / 解析ツール
- CI/Actions
- 結果不変の性能改善
- ドキュメント

# 世界バージョン境界の手順

1. 直前バージョン最終コードを `vX.Y-final` branchへ保存
2. 直前バージョンの重要な実験NOTES/結果docがmainに存在することを確認
3. `tests/golden_state.json` を必要に応じて `tests/golden_state_vX.Y.json` へ履歴保存
4. 新世界ルールを実装
5. 新バージョン最初の意図的結果変更コミットをCI結果不変性基準refへ設定
6. 以後、新バージョン内での結果不変変更をCIで監視

# V1.7確定事項

仕様:

```text
BMR = bmr_core + (bmr_coef - bmr_core) * M^0.75
0 <= bmr_core <= bmr_coef
```

Exp11だけでは長期平衡か遅延か判定できなかったためExp12へ延長。

Exp12 B1では:

```text
0.00〜0.10 -> lower-bound equilibrium
0.15       -> interior equilibrium 8/8
0.20       -> interior 7/8 + converging 1
0.30       -> interior 6/8 + converging 2
```

よって:

```text
bmr_core = 0.15
```

を恒久値とする。

理由は「下限張り付きを解除した最小側の試験値」。

V1.7確定手順:
1. default `0.0 -> 0.15`
2. tests / conservation / determinism / CI
3. V1.7 CI基準ref更新
4. `v1.7-final` branch保存
5. その後V1.8開始

詳細は `docs/Exp12_結果考察.md`。

# V1.8境界

V1.8は以下を変更するため世界ルール変更:

- light day/night cycle
- light実効fluxの時間変化
- light吸収への局所光強度response
- chemical吸収への局所stock濃度response
- chemical最大処理速度の再校正
- light Energy台帳の実効供給積算

Exp13選定前はfeature flags OFFでV1.7回帰を守る。

Exp13 ACCEPT後に:

```text
primary_energy_density_response = True
light_cycle_enabled = True
selected chem_uptake
selected light_max（rescueが必要なら）
```

を恒久defaultへ反映し、そのcommitをV1.8基準refとする。

その後 `v1.8-final` を保存する。

# 過去境界の補足

V1.4 default確定、V1.5刺激比較、V1.6行動変更はいずれも意図的結果変更としてCI基準refを更新した。

旧世界再現には各 `vX.Y-final` を使う。

バグ修正で結果が変わる場合も世界ルール変更に準じて扱う。
結果不変の内部修正のみ小数点以下2桁側で扱う。
