# バージョニング方針

更新: 2026-08-30

## 基本ルール

本プロジェクトでは、**進化・生態・環境の結果そのものを変えうる世界ルール変更**と、**結果を変えない機能追加**をバージョン番号で分離する。

### 小数点以下1桁: 世界ルール変更

例: `V1.1 → V1.2 → V1.3`

以下のような、シミュレーションの進化力学・資源収支・生理・生活史を変える変更を含む。

- 新しい環境パラメータや環境場の追加
- 光・化学・栄養など資源構造の変更
- 生理コスト式・吸収式・繁殖式の変更
- 新しい遺伝子や形質の追加
- 成熟期間・繁殖クールダウン等の生活史ルール追加
- 生殖方式の変更
- 捕食・損傷・移動など世界内の相互作用ルール変更

これらは同一seedでも結果が変わり得るため、比較実験の境界として扱う。

### 小数点以下2桁: 機能・観測・解析の追加

例: `V1.2 → V1.2.1 → V1.2.2`

世界ルールを変えず、同一条件・同一seedでシミュレーション結果を不変に保つ変更を含む。

- PNG / GIF可視化
- GUI改善
- 空間分布・行動範囲などの観測指標追加
- CSV / レポート出力追加
- 解析ツール追加
- CI / Actions / 実行基盤改善
- 性能最適化（結果不変性を検証できるもの）
- ドキュメント改善

観測ON/OFFや機能追加前後で乱数系列・シミュレーション結果が変わらないことを原則とする。

## 現在の適用

- `V1.1`: 小型・高光利用型への強い方向性選択を持つbaseline世界。最終版は `v1.1-final` ブランチで保存。
- `V1.2`: 最初の世界ルール変更として、高コントラストな静的光環境を追加する。
- `V1.2.1`: 空間分布・行動範囲・PNG/GIF等の観測/可視化機能を追加する。

実装順は必ずしも番号順である必要はないが、リリース/記録上は世界ルール変更と機能追加を区別する。

## 補足

バグ修正で結果が変わる場合は、単なる機能修正ではなく世界ルール変更に準じて扱う。
結果不変の内部実装修正は小数点以下2桁側で扱う。
