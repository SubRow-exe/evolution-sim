## 2. 主結果

| 指標 | Control | Treatment |
|---|---:|---:|
| sweep >=0.5 | 12/20 (60%) | 13/20 (65%) |
| sweep tick 中央値 | 25,810 | 22,200 |
| 最終population 中央値 | 3,100 | 1,801 |
| 最終body_size 中央値 | 0.484 | 0.926 |
| 最終light_absorption 中央値 | 2.88 | 4.04 |
| 最終lineage数 中央値 | 54 | 23.5 |

同一seedでもsweepする/しないが多数反転し、光の空間配置だけで進化史が大きく変わった。

### 重要な解釈

- 高光利用化はTreatmentでも維持され、光利用への強い方向性は崩れなかった。
- 小型化は大きく弱まり、局所的に光が豊富な場所では大型化が許容された。
- Treatmentでは完全暗部30%が早期に無人化し、生物は明部〜遷移帯に圧縮された。
- 暗部でchemical利用型が新たに成立する現象は確認されなかった。

## 3. 光量帯とサイズ

Treatmentの複数seedの最終snapshotを確認すると、明部ほど `matter` / `body_size` が大きい傾向がある。

10 seed確認時点:
- matter: 7/10 seedで明部 > 遷移帯
- body_size: 9/10 seedで明部 > 遷移帯

優占系統内に限定しても同傾向が残るため、単なる系統構成差だけではなく、局所光量によるサイズ選別が起きている可能性がある。

## 4. seed12空間挙動

Treatment seed12では完全暗部はtick 100時点で0個体となり、その後40,000 tickまで無人。
最終個体群は明部と遷移帯に分布する。

現行の感覚距離では大多数の個体が隣接セルの光量を比較できないため、これは主にactive phototaxisではなく、

1. 暗所個体の早期淘汰
2. 明るいセルほど良いエネルギー収支と出生
3. 親近傍への局所繁殖
4. 一部の移動 / ランダムウォーク

による demographic sorting と解釈する。

## 5. 新たに発見した重大な懸念: 化学利用経路の進化可能性

Exp05の完全暗部には化学噴出口と無機栄養が存在したにもかかわらず、別の持続的な生態型は成立しなかった。

seed12では完全暗部にも化学噴出口セルが存在し、終盤まで化学ストックがほぼ満タンで残っていた。したがって「暗部に代替資源が存在しなかった」わけではない。

ただし現行仕様では:

- 無機栄養はEnergy源ではなくMatter源であり、吸収にはEnergyコストが必要
- 持続的な外部Energy源は光と化学噴出口
- 初期chemical_absorptionは0.3
- 初期感覚範囲は隣接セルを十分探索できない
- 化学噴出口は局所的
- 化学の持続的供給規模は光より大幅に小さい

という非対称がある。

このため、現在の祖先が暗部でchemical利用型へ到達する前に個体群が消滅する「進化経路の断絶」が存在する可能性がある。

### これは未確定

現時点では以下を区別できていない。

1. 化学利用生態そのものが現行資源量・生理式では成立できない
2. 化学利用生態は成立可能だが、初期chemical_absorptionが低くbootstrapできない
3. 能力は足りるが、ventを発見・占有できない
4. 1〜3の複合

したがって、V1.1/V1.2について「複数エネルギー戦略の競争の結果、光利用型が勝った」と結論するのは保留する。

観測事実（高光利用化、小型化、sweep機構、空間配置によるbody_size変化等）は有効だが、**光利用の優位性の原因解釈はExp06完了まで暫定扱い**とする。
