# 2. V1.11 — Physical Phototrophy / Energy Strategy Diversification

目的:

> H2 chemical-first祖先から、光を利用する新しいEnergy戦略が自然に成立可能な世界へ拡張する。

必要実装:

- lightをphysical fluxへ接続 (`W/m2` またはphoton flux)
- absorption / conversionをJ/sへ接続
- depth / attenuationまたは空間的light gradient
- H2 habitatとlight habitatが同一world内で意味を持つgeometry
- phototrophy structural innovationを再開

候補実験:

- innovation OFF control
- rare phototrophy innovation
- H2-only / mixed / light-favored habitat比較
- day/nightとのinteraction

# 3. V1.12 — Biogenic Resource / Cross-feeding

第一候補: **acetate field**。

目的:

> 生物が作った物質が、別の生物の資源になる最初の生態系フィードバックを作る。

候補:

- acetogenesis productとしてacetateを明示
- acetate production ledger
- acetate uptake capability
- producer / consumer niche
- waste / corpse由来resourceとの区別

ここから単一producer型生態からcross-feeding生態へ進む。
