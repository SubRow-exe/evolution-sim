# 2. V1.11 — Primitive H2-coupled Phototrophy

正本:

- `docs/V1.11_原始Phototrophy_実装仕様.md`

目的:

> H2依存chemical-first祖先から、光を補助Energy源として利用する原始的なanoxygenic phototrophyがstructural innovationで自然発生可能な世界へ拡張する。

V1.11では「色素だけ生じて効果0」の独立段階は実装しない。

最初のmacro-innovationを:

```text
pigment + primitive reaction center + membrane coupling
```

が最低限機能し始めた段階として粗視化する。

重要な制約:

```text
H2 only                 -> 現行Energy獲得
H2 + light + phototrophy -> H2利用効率上昇
light only              -> V1.11ではusable Energy 0
```

つまり初期phototrophはH2依存を維持する。

必要実装:

- photon fluxをphysical quantity (`umol photons/m2/s`) としてworldへ追加
- `light_absorption` をphysical absorptanceへmapping
- incident photons -> radiant power -> usable photo bonusをJ/sへ接続
- photo bonusを独立Energy uptakeではなくphysical H2 uptakeへcouple
- `phototrophy` capability bit / structural innovationを既存V1.9構造から再利用
- phototrophy OFFのiLUCAを初期祖先として維持
- capability獲得時は弱いseed absorptionから開始
- light machineryの維持costは既存organ upkeepを利用し、人工fitness penaltyを置かない
- Energy / H2 ledgerへphoto Energyを明示

V1.11では未実装:

- oxygen production
- water splitting
- H2S / Fe2+等の代替electron donor
- Type I / Type II RCの明示分化
- chlorosome等の高性能antenna
- rhodopsinをchlorophyll系の前駆段階として強制

候補実験（Exp20）:

- dark / H2-zero / light-positive mechanical controls
- forced primitive phototrophでphoton-flux sensitivity
- natural structural innovation OFF vs ON
- H2 uptake量 / photo Energy fraction / lineage persistenceの比較

本格的なoxygenic photosynthesisはV1.17候補まで持ち越す。
