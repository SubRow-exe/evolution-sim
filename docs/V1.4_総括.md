## 1. V1.4で解決したこと

V1.3後の監査で、一次Energy/資源吸収に以下の非対称があった。

- 光は単独個体なら低い`light_absorption`でもセル光をほぼ全取得できた
- chemicalには個体吸収上限があった
- chemicalはstock不足時に個体処理順の先着biasがあった
- light / chemical / nutrientの直接吸収が概ねmatter比例だった
- 光だけ移動前セル、chemical/nutrientは移動後セルを参照していた

V1.4では環境との直接交換を有効表面積

```text
A_eff = matter^(2/3)
```

で律速し、light / chemical / nutrientを需要比例による公平配分へ統一した。

光には個体吸収上限を新設し、chemicalの先着biasを廃止。3資源とも移動後セルから吸収するよう統一した。

## 3. V1.4恒久defaultの判断

### 光吸収速度係数

```text
light_uptake_coef = 2.0
```

理由:
- 修復込みの成立境界（約1.4）から十分離れている
- 低光利用能力でも安定成立する
- 完成光型との個体群サイズ差が大きく、`light_absorption`を高める進化価値が残る
- 3.0〜4.0ほど高密度化・小型化・seed間ばらつきを強くしない
- 明部では個体吸収能力、暗部では環境供給量が律速になり得て、個体側と環境側の両方に意味が残る

### chemical噴出口供給量

```text
chem_vent_flux = 16.0 E/tick/vent
```

理由:
- 標準13セルventなら局所供給密度は約1.23 E/tick/cell
- 現行光の最大約1.2 E/tick/cellとほぼ同程度
- 世界全体では光より小さいが、vent近傍では高密度という設計目標に合う
- source利用率96.1%で十分利用されている
- 24まで上げてchemicalを意図的に光より強くする根拠は現時点ではない

### chemical個体吸収速度係数

```text
chem_uptake = 0.5
```

今回は変更しない。`chemical_absorption`が高くなれば個体吸収上限も十分増えるため、光との競争結果を作る目的で人工的に引き上げない。

## 4. 小型化についての判断

V1.4では環境との直接吸収利益が概ね`matter^(2/3)`、維持費の多くは身体量`matter`に強く依存する。

したがって小型個体は単位身体量あたりの表面積が大きく、現環境では資源交換上有利になり得る。

これは現時点では**修正対象ではなく、自然な選択圧として許容する**。

理由:
- 表面積/体積比による小型個体の交換効率上昇は物理的に自然
- 特定の体サイズへ誘導する人工的なペナルティを入れないという原則に合う
- 将来、温度・熱損失・Energy備蓄・防御・捕食等を物理的に追加すれば大型化側の利点も自然に生じ得る

ただし、将来まったく異なる環境でも常に`body_size`下限へ張り付く場合は、構造的biasとして再監査する。

## 5. V1.4で未解決のこと

V1.4の行動は、光とchemicalの刺激を

```text
ability × raw field value
```

で比較している。

しかし光のフロー量とchemicalのstockは単位も数値範囲も異なるため、光+chemical混合世界では直接比較に意味がない。

したがってV1.4では混合世界の進化的優劣を評価しない。

## 6. V1.5への移行理由

V1.5では、光とchemicalを**比較可能な無次元の受容器応答**へ変換し、そのうえで個体固有の能力を掛けて反射的に行動させる。

これは行動結果を変える世界ルール変更なので`V1.4 → V1.5`とする。

未来のEnergy収益を予測する最適化行動は導入しない。
