# V1.2.2 結果プレビュー

## 目的

GitHub Actions Artifact を毎回ダウンロードしなくても、実験の主要プロットと代表GIFを `experiments/` から直接閲覧できるようにする。

V1.2.2は**観測・結果閲覧機能のみ**で、世界ルール・科学状態・RNG・実験結果には影響しない。

## 保存の二層化

### 生データ（正本）
- Actions artifact
- 外部ストレージ
- stats / lineages / snapshots / environment / full-resolution GIF 等

### GitHub閲覧用
`experiments/<experiment>_results/`

- README.md
- aggregate plots
- 代表seedの軽量GIF preview

生データをGitへ恒久保存しない。

## GIF preview既定値

```text
最大辺: 480 px
frame stride: 2
palette: 128 colors
```

Exp05のfull GIFは1本約1.5–2 MB程度だったため、代表seedのみpreview化する。既定seedは `1,12`。workflow入力で変更可能。

## 既存runからの発行

`.github/workflows/publish_experiment_previews.yml` を手動実行する。

入力:

```text
source_run_id   元の科学実験Actions run ID
experiment      exp05 など
conditions      control,treatment
preview_seeds   1,12
 target_branch   main
```

workflowは元runの個別artifactを取得し、

1. 条件ごとのrun群を再構成
2. aggregate plotを再生成
3. 代表GIFを軽量化
4. `experiments/<experiment>_results/` を生成
5. target branchへcommit

する。

## 重要

- 本workflowは科学run完了後の後処理。
- preview生成失敗で科学実験を無効にしない。
- previewは目視用であり、定量解析の正本ではない。
- 定量値を再解析する場合は生データを使用する。
