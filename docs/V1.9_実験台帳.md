## Exp16 — V1.9 environment robustness

実装/実験commit:
- `4d5a9cdd8c7948f037f8890ab977917421dc0524`

Actions run:
- `33873209494`

目的:
- Exp15 Attempt 2 iLUCAを変更せず、H2環境のどの範囲で維持・成長・世代交代が成立するか確認。

設計:
- 11 conditions
- 5 seeds / condition
- 10 physical days / run
- total 55 runs
- adaptive tuningなし

状態:
- **55/55 runs COMPLETE**
- workflow success
- conservation failureなし

主要結果:

```text
h2_1mM              : 5/5 extinction
h2_3mM              : 5/5 extinction
h2_6mM              : 5/5 survive, median final N 386, generation 2
baseline_10mM       : 5/5 survive, median final N 2981, generation 5
h2_15mM             : 5/5 survive, median final N 4876, generation 6

exchange_fast_300s  : 5/5 extinction
exchange_slow_3600s : 5/5 hit N=5000 halt cap

diffusion_low       : 5/5 extinction after limited reproduction
diffusion_high      : 5/5 survive, median final N 4937, generation 6

layout_cross        : 5/5 survive to day 10, median final N 43
layout_cluster      : 5/5 extinction after local reproduction
```

主要解釈:
- H2 source濃度だけでなく、利用可能H2領域の面積・連結性・遭遇可能性が成立性を支配
- `h2_exchange_tau_s` は供給速度ではなくenvironmental removal timescale
- biological H2 uptake/source influxは1e-6–1e-5 orderで、H2 depletion competitionよりpatch accessが主要圧
- high-growth側ではgeneric environmental Matter stockがcarrying capacityを強く支配
- 10日runはfinite-time robustnessであり平衡測定ではない

Opus5再解析:
- reference iLUCA maintenance break-even H2 ≈ 248 µM
- その濃度以上のworld面積割合（habitability fraction）が55 runの生存/絶滅を非常によく分離
- 今後の環境追加時のpre-screen指標候補

判断:
- V1.9 physical environment + LUCA-like proxyは今後のoriginとして成立
- baseline 10 mM / D=5e-9 / loss tau=900 s / distributed 4-sourceを維持
- Exp16結果を使ってbaselineを最適化し直さない

詳細:
- `docs/Exp16_V1.9_結果考察.md`
