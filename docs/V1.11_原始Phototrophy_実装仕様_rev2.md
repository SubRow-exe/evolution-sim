# 1. 生物学的な粗視化

V1.11で表現するのは、完成したphotoautotrophではなく、H2依存chemolithotrophから生じた最初期のanoxygenic phototrophyである。

```text
祖先:
H2 -> reducing power + chemical Energy
CO2 + N + P -> biomass

primitive phototroph:
light -> cyclic photophosphorylation -> ATP/PMF -> maintenance/activity補助
H2    -> reducing power + chemical Energy
CO2 + N + P + reducing power -> biomass
```

anoxygenic purple bacteria等では、cyclic electron flowで光からPMF/ATPを作ることができる一方、CO2固定には外部電子供与体由来の還元力が必要である。

V1.11はこれを次のHARD RULEへ落とす。

### HARD RULE P1

```text
phototrophy OFF -> V1.10.1 baselineへ回帰
```

### HARD RULE P2

```text
light = 0 -> photo contribution = 0
```

### HARD RULE P3

```text
H2 = 0 + light > 0
-> maintenance/activityは光で一部または全部維持可能
-> ただしlightだけでEnergy storageを継続充填しない
-> lightだけで持続的なnet biomass growthを成立させない
```

### HARD RULE P4

```text
water oxidation / O2 productionはV1.11では絶対に起こらない
```

### HARD RULE P5

```text
H2S / Fe2+ / organics等の別electron donorはV1.11では使わない
```

# 4. photon -> usable photo power

既存 `physical_radius_m()` を用いる。

```text
r             = physical_radius_m(matter)
A_projected   = pi * r^2
photon_energy = h*c/lambda
photon_rate   = flux_umol * 1e-6 * N_A * A_projected
P_incident    = photon_rate * photon_energy
```

## 4.1 light_absorption mapping

維持:

```text
absorptance = 1 - exp(-light_absorption_effective)
```

`light_absorption` を直接%として使わない。

```text
0.01 -> 0.995%
0.1  -> 9.52%
1.0  -> 63.2%
```

## 4.2 usable photophosphorylation power

```text
P_absorbed  = P_incident * absorptance
P_photo_max = P_absorbed * phototrophy_radiant_to_usable_eff
```

working:

```text
phototrophy_radiant_to_usable_eff = 0.10
```

これは祖先RCの精密量子収率ではなく、absorbed radiant Energy -> cellular ATP/PMFのcoarse-grained efficiency。

# 7. phototrophyのN構造コスト

既存physical basalの `organ` costだけではphototrophy investment costとして弱すぎる。

V1.11では、V1.10で導入したfixed N poolへphototrophic machineryを接続する。

## 7.1 BChl optical cross-sectionから最低pigment量を求める

BChl aを代表pigmentとし、800 nm付近のmolar extinction coefficientをworking reference:

```text
bchl_extinction_mM_cm = 213
```

とする。

これはB800 BChl aに報告された約213 mM^-1 cm^-1を使う。

molar extinction -> molecule absorption cross-section:

```text
sigma_BChl_m2 = epsilon_M_cm * ln(10) * 1000 / N_A * 1e-4
```

注意:

```text
213 mM^-1 cm^-1 = 213000 M^-1 cm^-1
```

したがってworking sigmaは約 `8.1e-20 m2 / molecule`。

`absorptance = 1-exp(-a)` の `a` はoptical depthと解釈できるため、必要BChl molecule数の最低量を:

```text
N_BChl_min = light_absorption_effective * A_projected / sigma_BChl
```

とする。

BChl tetrapyrroleは4 N atomsを持つ。

```text
photo_pigment_n_mol_min = N_BChl_min * 4 / N_A
```

## 7.2 RC / antenna proteinを含める

実際のphototrophy apparatusはBChlだけではなく、reaction-center / light-harvesting membrane proteins、quinones等を必要とする。

pigment Nだけをcostにすると過小評価になるため:

```text
photo_apparatus_n_multiplier = 10.0
```

をworking coarse-grained multiplierとする。

```text
photo_n_target_mol = photo_pigment_n_mol_min * photo_apparatus_n_multiplier
```

`10` は歴史的初期RCの真値ではない。現生purple-bacterial pigment-protein complexでpigment以外のprotein massが大きいことを踏まえ、pigment-only costを最低量として拡張するworking prior。

formal resultを見て倍率を調整してはいけない。必要なら別sensitivityで 5 / 10 / 20 を比較する。

## 7.3 explicit structural N pool

`Organism`へ:

```text
photo_structural_n_mol: float
```

を追加する。

機能するeffective optical depth:

```text
assembly_fraction = min(1, photo_structural_n_mol / photo_n_target_mol)
light_absorption_effective = genome[LIGHT_ABS] * assembly_fraction
```

Nを用意できていないphototrophは遺伝的capabilityがONでも完全性能を発揮しない。

### assembly

phototrophy ON個体は、local fixed-N fieldからtargetまで不足しているNを取り込める。

```text
n_need = max(0, photo_n_target - photo_structural_n)
```

初版ではassembly専用kinetic geneは追加しない。

1 tickでlocal available Nの範囲まで不足分を埋めてよい。

取得Nはenvironment -> organism structural poolの内部移転であり、N ledgerへ含める。

### growth

matter増加でprojected areaが増えtargetも増えるため、追加Nが必要になる。

### division

`photo_structural_n_mol` をdaughter biomass ratioに応じて分割し、総量保存。

### death

corpseにも `photo_structural_n_mol` を持たせるか、death時に明示的にfixed-Nへ戻す。

**silent lossは禁止。N ledgerを必ず閉じること。**

### capability loss

loss時はstructural machineryを分解したと粗視化し、保持していたextra Nをlocal fixed-N fieldへ戻す。

# 16. 文献・根拠

- LUCA proxy baseline: `experiments/luca_proxy/run_luca_proxy.py`
- Overmann et al. 2005, Black Sea green sulfur bacteria: photosynthetic CO2 fixation down to ~0.015 umol quanta m^-2 s^-1.
- purple bacterial anoxygenic photosynthesis: cyclic electron flow creates proton motive force / ATP; external electron donors are required for net autotrophic carbon reduction.
- BChl a / LH2: B800 extinction coefficient reported around 213 mM^-1 cm^-1 per BChl.
- chlorophyll/bacteriochlorophyll tetrapyrrole contains four N atoms coordinated around Mg.
- photosynthetic apparatus consists of pigment plus substantial membrane protein machinery; pigment-only N is therefore a lower bound.

この仕様は、歴史的に唯一のphototrophy進化経路を主張するものではない。V1.11では「H2依存祖先からanoxygenic cyclic photophosphorylationが生じる最初の生態的効果」を最小限の物理モデルで表現する。
