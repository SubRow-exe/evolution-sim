## 3. Exp09後に残った論点

### 3.1 chemical刺激基準と実測stock

`chemical_stimulus_half=12.3`は典型13セルventの生物不在平衡を基準にした固定値。

実際に生物がいる世界ではchemical stockが大きく下がり、chemical受容器応答は主に弱刺激のほぼ線形域で使われている。

これは現時点ではバグ扱いしない。光はflow型、chemicalはstock型であり、利用によってchemical刺激が低下すること自体は自然な物理差として許容している。

ただし長期進化実験前には、この感覚スケールをそのまま世界仕様として維持するか改めて判断する必要がある。

### 3.2 一次Energyと他刺激の比較尺度

V1.5で無次元化したのはlight vs chemicalだけ。

nutrient / corpse / predationとの比較はまだlegacy score（能力 × raw刺激量）を使っている。

全刺激を共通尺度へ変換するかは、次の独立した世界ルール変更候補。

### 3.3 chemical bootstrap

通常祖先からchemical利用型へ進化できるかというExp07以来のbootstrap問題は未解決。

Exp09は行動比較則の診断なので、この問題には答えていない。

## 4. 次チャットで最初に検討する設計思想

ユーザーとの直近の合意・方向性:

### A. Energy源への反応はすべて無次元量へ統一する方向

今後Energy源が増えても、刺激強度は原則として比較可能な無次元受容器応答へ変換する。

ただし「同じ数値なら同じEnergy収益」という意味ではなく、各刺激に対する現在の感覚応答を共通尺度で表す。

### B. winner-take-all行動を再検討する

現行V1.5は

```text
light scoreとchemical scoreを比較
→ 強い方を1つ選ぶ
→ そのsourceへ方向付け
```

というwinner-take-all型。

実世界の微生物・原始的生命を参考にすると、複数刺激を同時に統合し、刺激が移動方向を完全決定するのではなくランダム運動へ偏りを与える方が自然な可能性が高い。

候補思想:

```text
各Energy刺激を無次元応答へ変換
→ 個体能力を掛ける
→ 複数刺激を統合して「現在の環境の良さ / 変化」を表す
→ 基本はrandom walk
→ 良くなる方向では直進しやすく、悪くなると方向転換しやすくする
```

実世界の細菌のrun-and-tumble / biased random walkに近い発想。

重要:
- 将来Energy収益を予測させない
- 最適地点を計算させない
- 刺激は行動確率を偏らせるだけ
- 複数Energy源が同時に存在すれば、利用能力があればその場で両方を吸収できる構造を維持する

### C. 専門化とgeneralistのトレードオフは行動則とは分離する

将来的には、光利用装置・chemical利用装置などが有限の膜表面積や細胞資源を奪い合う物理的制約を入れる案がある。

例:

```text
A_light + A_chemical + A_nutrient + ... <= A_eff
A_eff = matter^(2/3)
```

これにより、両能力を無コストで最大化するより、specialist / generalistの自然なトレードオフが生まれる可能性がある。

ただしこれは行動則とは別軸なので、同時に実装しない。

## 5. 推奨する次の順序

1. Exp09結果をmainへ正式反映してV1.5比較則を閉じる
2. 次のチャットで実世界の微生物行動を参考に、winner-take-allから複数刺激統合型のbiased random walkへ変更するか設計を詰める
3. 変更する場合は新しい世界バージョンとして事前登録・単独診断を行う
4. 行動則が妥当になってから、有限表面積/代謝装置コストなど専門化トレードオフを別軸で検討する
5. その後に通常祖先からの長期光+chemical混合進化実験へ進む
