# V1.6 行動則設計案 — 複数刺激統合型 temporal biased random walk

更新: 2026-08-31
状態: **Claudeレビュー待ち / 未実装 / V1.6候補**

## 1. 位置づけ

V1.5では light と chemical を無次元受容器応答へ変換し、異種刺激を直接 raw 値で比較しない仕組みを導入した。
Exp09でこの比較則は Green となった。

一方、V1.5の移動判断は依然として winner-take-all 型である。

```text
light score と chemical score を比較
→ 強い方を1つ選ぶ
→ その source へ方向付け
```

V1.6候補ではこれを廃止し、複数刺激を同時に統合した **temporal biased random walk** へ変更する。

この変更は単なるパラメータ調整ではなく、個体の移動原理そのものを変える世界ルール変更なので、実装時点で V1.6 とする。

## 2. 用語

- **無次元受容器応答**
  刺激量を `response(x, K) = x / (x + K)` により 0以上1未満へ写像した値。異なる単位を持つ刺激を共通尺度で扱うために用いる。

- **統合環境評価値 Q**
  現在地点がその個体にとってどの程度好条件かを表す内部評価値。各刺激の無次元受容器応答と、その刺激を利用する能力を統合して作る。正確な式はExp10前に確定する。

- **時間比較 / temporal sensing**
  現在の刺激と少し前の刺激を比較し、環境が改善したか悪化したかを判断する方式。周囲の全セルを直接見て最適方向を計算する方式ではない。

- **biased random walk**
  基本はランダム移動だが、環境変化によって直進・方向転換の確率だけが偏る移動方式。

- **turn rate**
  個体が現在の進行方向をやめ、別方向へ切り替える確率。V1.6候補では Q の時間変化によって変化させる。

- **memory time**
  現在と比較する過去刺激の時間幅。単純な1 tick前比較、移動平均、指数移動平均など候補がある。

## 3. 基本原則

V1.6候補では以下を原則とする。

1. 個体に未来の Energy 収益を予測させない。
2. 周囲のセルを走査して最適地点・最適方向を直接計算させない。
3. 刺激は移動方向を決定せず、移動確率を偏らせるだけにする。
4. 複数の Energy 刺激は winner-take-all にせず同時に統合する。
5. その場に複数の利用可能 Energy 源が存在する場合、利用能力があれば従来どおり同時吸収可能とする。
6. 吸収物理はV1.4/V1.5から変更せず、今回変更するのは行動則のみとする。

## 4. 候補アルゴリズム

各 tick で、各一次Energy刺激について無次元応答を求める。

```text
R_light = response(light, light_stimulus_half)
R_chem  = response(chemical_stock, chemical_stimulus_half)
```

個体の利用能力を加味して統合する。

```text
Q = integrate(
    light_absorption × R_light,
    chemical_absorption × R_chem
)
```

`integrate()` の正確な形式は未確定。最初の候補は単純加算である。

```text
Q = light_absorption × R_light
  + chemical_absorption × R_chem
```

その後、現在値と短期記憶を比較する。

```text
ΔQ = Q_now - Q_past
```

そして、

```text
ΔQ > 0  → 現在方向を維持しやすくする
ΔQ ≈ 0 → baseline の方向転換率
ΔQ < 0  → 方向転換しやすくする
```

とする。

重要なのは `ΔQ` から「どちらへ行くべきか」を求めないこと。
方向転換した後の方向は基本的にランダムに選ぶ。

## 5. 現時点で未確定の設計値

Exp10で校正・確認する対象として、以下はまだ固定しない。

### 5.1 memory time

候補例:

```text
1 / 3 / 10 / 30 tick
```

1 tick前との単純比較にするか、過去数tickの平均を持つかもレビュー対象。

### 5.2 baseline turn rate

刺激変化がないときの基本方向転換確率。

低すぎると直進主体、高すぎると拡散主体になる。

### 5.3 response gain

`ΔQ` が turn rate をどの程度変化させるかを決める係数。

### 5.4 ΔQ → turn rate の関数形

最低条件:

- 単調である
- 確率が 0〜1 に収まる
- `ΔQ = 0` で baseline に戻る
- 極端な値でも数値不安定にならない

線形clamp、sigmoid等を候補とする。

### 5.5 Q の統合式

最初の候補は能力加重した無次元応答の単純加算。
ただし、刺激数が将来増えたときのスケール依存や、複数能力を同時に最大化する generalist の優位は別途考慮が必要。

専門化コストは今回の行動則には混ぜない。

## 6. 生物学的な位置づけ

小型の遊泳細菌では、体の左右で空間勾配を直接比較するより、移動中の刺激の時間変化を利用する run-and-tumble / temporal sensing が代表的である。

一方、実世界には空間比較や方向直接検知を行う生物も存在する。

将来的には、

- temporal sensing
- spatial sensing
- directional sensing

を別の進化可能な感覚能力として導入できる構造を目指す。

ただし V1.6では temporal sensing を基礎行動として採用し、感覚能力そのものの進化は実装しない。

## 7. 将来拡張時の注意

空間比較能力を追加する場合、個体へ周囲の全セル値を無料で与えて最大値方向へ移動させない。

将来は例えば、

```text
有限距離の左右センサー
+ 測定ノイズ
+ センサー維持コスト
```

のように、生物側の能力として表現する。

また、temporal / spatial / directional の全能力を無コストで最大化できると万能型へ収束しやすい。
将来的な能力多様性には Energy、matter、膜面積、受容体資源などのトレードオフが必要になる可能性が高い。

## 8. V1.5との互換性

V1.6候補では単独source世界でも移動原理そのものが変わる。
そのため V1.4/V1.5との bit 完全一致は要求しない。

維持すべきもの:

- light / chemical の吸収式
- V1.4で確定した吸収パラメータ
- chemical field の供給・拡散・消費物理
- seed固定時のV1.6内部決定論

V1.6実装後は、V1.6の基準commitを新たな回帰基準とする。

## 9. 実装前の採否条件

V1.6実装へ進む前にClaudeレビューで少なくとも以下を確認する。

1. Q の意味と単位・無次元性が一貫しているか
2. 時間比較だけで現在のworld geometryに十分な選択圧が生じるか
3. `ΔQ → turn rate` の関数が不自然な最適化を生まないか
4. individual state に必要な記憶量が最小限か
5. seed決定論を壊さないか
6. 将来 spatial / directional sensing を追加しやすい構造か
7. Exp10の観測量だけで行動則の成立性を判定できるか
